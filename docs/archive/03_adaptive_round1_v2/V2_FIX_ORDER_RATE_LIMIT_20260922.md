```
弧长 ≈ 当前半径 × angle(hold_direction, capture_direction) × Δc
```

## 2. 改法（具体到函数，不需要你重新设计）

在 `_limit_task_state` 里，**在现有的两轴分别限幅之后**，加一层参考位移上界：

1. 现有逻辑照旧算出候选增量 `(Δρ, Δc)`；
2. 计算候选参考 `p_cand = _v2_reference(ρ+Δρ, c+Δc)` 与当前已施加参考 `p_now`；
3. 若 `‖p_cand − p_now‖ > v2_reference_step_max_m`，对 **λ ∈ [0, 1]** 二分，
   令 `(λΔρ, λΔc)` 恰好落在上界内，取最大可行 λ；
4. 用 `λ` 缩放后的增量更新任务状态。

**为什么用二分而不是直接按比例缩**：参考对 `(ρ, c)` 是非线性的（slerp + 半径乘积），
一次比例缩放不保证落回界内。8 次二分给 1/256 精度。

**关键：二分只调用参考映射（slerp + 标量乘），是纯几何，不解 MPC。
所以零额外在线求解，不碰算力预算。** 这条必须守住。

新增配置项 `v2_reference_step_max_m`，放在 `PrecaptureHybridConfig`，
`__post_init__` 里校验为正。
