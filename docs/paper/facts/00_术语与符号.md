# 00 术语与符号

全文用词以本表为准，括号内是建议的英文写法。

## 方法与对比方法

| 中文 | 英文 | 说明 |
|---|---|---|
| 执行反馈闭环协同（ECC） | execution-feedback closed-loop coordination (ECC) | 本文主方法：执行机会协调 + 在协调闭环上的 SAC 学习 |
| 旋转同步窗口引导（RWG） | rotation-synchronized window guidance (RWG) | 面向翻滚目标的引导与入口：扫掠锥阶段意图 + 动态入口 + 入口重定时 |
| SAC–MPC | SAC–MPC | 同一执行链与观测，没有执行机会协调（正文主基线） |
| TD3–MPC | TD3–MPC | 同上，学习器换成 TD3 |
| MPC | MPC only | 同一近场 MPC 单独执行，没有高层与阶段层 |

## 符号

| 符号 | 含义 |
|---|---|
| x | 完整决策状态：相对位姿与速度、目标姿态与角速度、时间、已用 Δv、任务参数，以及执行层的内部状态（执行模式、保持参考、上一阶段记录） |
| o | 观测（17 项，策略与评价器共用） |
| a = (a_p, a_z) ∈ [−1, 1]² | 阶段意图：接近分量、沿扫掠分量 |
| 𝒞(x, a) | 协调后执行的对象：一个阶段意图，或一次直接入口 |
| m ∈ {S, H, E, D} | 执行模式：阶段飞行、保持、入口转移、末段下降 |
| h = 16 s | 名义阶段时长 |
| Δt = 0.1 s | 控制周期 |
| γ_d = 0.999⁸ | 每次高层决策的折扣 |
| T_d | 任务期限 |
| Δ_d = 45 s | 末段余量 |
| L = T_d − Δ_d | 最晚可接受的入口到达时刻 |
| B_max | 燃料预算（3.0 m/s） |
| ŝ、ω、P = 2π/‖ω‖ | 自旋轴、目标角速度、自旋周期 |
| β | 端口锥半角（端口方向与自旋轴的夹角） |
| λ | 视线极角（视线与自旋轴的夹角） |
| Δλ = λ − β | 纬向偏差 |
| φ | 端口转到视线子午面还需扫过的相位 |
| e_r、e_pol、e_az | 视线方向、指向自旋轴方向、迎着端口转来的方向 |
| θ_g = 35° | 入口夹角门限 |
| 𝒯 = {15, 20, 25, 30, 40, 50, 60} s | 入口到达时刻候选 |
| 𝔅 | 3 × 3 候选意图（动作盒网格 {−1, 0, 1}²） |
| H_p = 48 s | 模式预测时域（3 个阶段） |
| (ê, τ̂, Δv̂)(x, b) | 对意图 b 的模式预测：是否发生模式事件、发生时刻、所需燃料 |
| 𝒯_L | 直接入口的到达时刻候选 |
| P_ℰ、P_𝒞 | 执行层宏转移核、含协调的闭环宏转移核 |
| Φ、T_go | 机会可达性势函数；最早可兑现入口的到达时间 |
