# ECC 最后一轮：执行修正的策略反馈（规格与判据）

**状态（2026-11-18）：** 用户定方向：最后一轮针对性开发，不再扩展研究分支。本文件先于实现和结果入库。`GATE0.md` 的选项价值学习方向停止，第 0 关的已有结果作为记录保留。

**范围：**

- 原 ECC（`ECC_CERT_LOOP`）完整冻结，作为对照；
- 执行器、RWG、规划器、MPC、执行机会认证 𝒞、SAC 的评价器学习都不变；
- 只在策略（actor）更新中加入一项反馈，并补齐所需的数据接口。

## 1. 问题

训练时，经验池存的是策略的提议 a，实际飞行的是认证后的意图 b = 𝒞(x, a)。评价器从真实后果中学到"提议 a 的价值"，但策略没有任何机制去学"执行器修正后真正起作用的意图"。

所以：

- 评价器在被修正的区域里近似平坦（见第 2 节性质 2），策略在那里得不到梯度方向；
- 训练末期每个紧急回合仍有 0.62–0.94 次修正（第一轮 ECC 三个种子，`evidence/FORMAL/ROUND1_READOUT/TRAINING_CURVES.csv`），策略对认证的依赖没有明显减少。

## 2. 动作执行等价（严格成立的部分）

记 𝔅_c(x) 为可认证候选集。认证规则：原意图自己会触发事件，或没有可认证候选时，执行原意图；否则执行 𝔅_c(x) 中离原意图最近的候选。

- **性质 1（幂等）：** 𝒞(x, 𝒞(x, a)) = 𝒞(x, a)。

  证明：若 b = 𝒞(x, a) ≠ a，则 b ∈ 𝔅_c(x)，它在执行器模型下自己会触发事件，所以 𝒞(x, b) = b。若 b = a，结论显然。模式预测是状态的确定函数，所以性质对完整状态 x 精确成立。
- **性质 2（等价类）：** 对任意 a，提议 a 与提议 b = 𝒞(x, a) 的闭环转移相同，因此对任意后续策略 π，Q_𝒞^π(x, a) = Q_𝒞^π(x, b)。
- **性质 3（被修正状态上闭环中性）：** 如果新策略只在被修正的状态 x 上把提议从 a 改成 b，在 x 处的闭环结果不变。

  所以，**在被修正状态本身，学 b 不会带来任何回报提升**。反馈的作用只可能来自函数逼近的迁移：
  - (i) 修正之后的下一、二次决策：策略自己沿着事件轨道走，不再被拉离、也不再需要再次修正；
  - (ii) 认证不介入的状态：原意图自带一个更晚、更差的事件时，认证会放行；窗口不关键时，认证也不介入。

  这两点是本设计要在实验中证明的内容，不是推论。
- **性质 4（自足）：** 在策略提议已等于 b 的状态，有 𝒞(x, π(x)) = π(x)，去掉认证不改变执行。"减少对认证的依赖"用评估时的修正率来度量。

## 3. 算法：执行修正的策略反馈

### 3.1 数据接口（补齐）

- **采集进程：** 每次决策回传执行意图 b_k 和修正标志 c_k = 1[b_k ≠ a_k]（来自环境 step 信息里的认证记录）。
- **学习进程：** 按采集进程分别缓存当前回合的 (o_k, a_k, b_k, c_k, r̃_k)。回合结束时，从后往前计算塑形回报的折扣累计 G_k = Σ_{j≥k} γ_d^{j−k} r̃_j（终局后为 0），记下终局结局 e。
- **修正池 𝒟_C：** 只放 c_k = 1 的决策 (o_k, b_k, G_k, e)，先进先出，容量 1000。
- **主经验池不变：** 加入时机、内容、更新次数都与原 ECC 相同。

### 3.2 样本筛选与优势（只用真实后果）

更新时，对修正池里的样本计算

- 基线 V̄(o_k) = (1/K) Σ_{i=1..K} min_j Q̄_j(o_k, ã_i)，ã_i ~ π_θ(·|o_k)，K = 4，Q̄ 为目标评价器；
- 真实执行优势 Â_k = G_k − V̄(o_k)。

一个修正样本被吸收，当且仅当：

1. 该回合以捕获结束（e = success）；
2. Â_k > 0：修正后的真实执行，比当前策略在该状态的预期做得更好。

权重 w_k = min(1, Â_k / A₀)，A₀ = 25（捕获奖励的 1/4，事先固定）。

- G_k 来自真实轨迹，执行器预测不进入任何学习目标；
- V̄ 只作为比较基线；评价器的学习目标不变。

### 3.3 反馈项与有界更新

- **反馈损失：** 从修正池取 64 个样本，

  L_F(θ) = Σ_k w_k ‖μ_θ(o_k) − b_k‖² / Σ_k w_k

  其中 μ_θ(o) = tanh(m_θ(o)) 是策略的确定性均值。用均值回归，不用对数似然：候选在动作盒的角点上，对数似然在边界发散。
- **梯度冲突控制（每次策略更新）：**
  1. 分别求原 SAC 策略损失的梯度 g_S 和反馈梯度 g_F（策略网络参数）；
  2. 冲突时投影：若 ⟨g_F, g_S⟩ < 0，令 g_F ← g_F − (⟨g_F, g_S⟩ / ‖g_S‖²) g_S；
  3. 限幅：λ = min(1, ρ ‖g_S‖ / ‖g_F‖)，ρ = 0.5；
  4. 送入优化器的梯度为 g = g_S + λ g_F。
- **性质 5（一阶相容，严格）：** ⟨g, g_S⟩ ≥ ‖g_S‖²，且 ‖λ g_F‖ ≤ ρ ‖g_S‖。也就是说，送入优化器的梯度始终是原 SAC 策略损失的下降方向，反馈只占有界的比例。

  说明：这条性质针对送入优化器的梯度；Adam 的逐参数缩放之后不再严格保持，所以训练中记录投影比例和 λ 的分布作为实测。
- **启动条件：** 修正池中合格样本 ≥ 128 后才启用反馈；此前与原 ECC 完全相同。

### 3.4 参数（事先固定，开发验证中不调）

K = 4，A₀ = 25，ρ = 0.5，修正池容量 1000，反馈批量 64，启动阈值 128。

### 3.5 与历史失败方案的区别

| 历史方案 | 区别 |
|---|---|
| 反事实或模型价值标签（D39–D43） | 不产生任何 Q 标签；评价器学习完全不变；优势只用真实累计回报减基线 |
| 动作梯度修正（D41） | 它用模型融合的优势修正动作梯度；这里的目标动作是真实执行过的修正，样本按真实结局筛选；冲突时投影，并且限幅 |
| 训练时执行执行器的动作（D36） | 行为策略不变，执行仍是"提议 + 认证"，和原 ECC 一样；只改策略的更新 |
| 执行机会调节器（D45） | 不新增任何执行规则 |
| 优势加权回归、AWAC | 不对整个经验池做加权回归；只在执行器修正过的决策上、以修正意图为目标，并且有冲突投影和限幅。论文的创新点在"把执行修正转化为可验证的策略改进"，不在加权回归本身 |

## 4. 开发验证（唯一一轮）

- **组别（都从零训练）：**
  - 新 ECC：原 ECC 加执行修正的策略反馈；
  - 原 ECC：`ECC_CERT_LOOP`；
  - SAC + 原认证器：`SAC_CERT_LOOP`，评价器不读执行反馈。
- **训练：**
  - 开发种子 2、3（从未用过；训练初始条件流与正式种子不重叠）；
  - 每组训练到 8000 次高层决策，其余设置与第一轮相同（2 个采集进程，紧急 3/4 的训练任务分布）；
  - 检查点 1000–7000 只画学习曲线（验证初始条件 294800–294847，48 个，紧急任务），最终模型固定取 8000，不挑检查点。
- **评估：** 开发初始条件 294500–294691（192 个，紧急任务），确定性策略，认证开，审计记录开。经济任务只评估 96 个（294700–294795），只观察。
- **读数：**
  1. 紧急任务捕获、真实回报、不安全次数（配对，按种子分层的自助法）；
  2. **原始动作的有效性：** 评估时每回合的修正次数；关键窗口决策中，原始提议自带事件的比例；
  3. **迁移的证据：** 修正后下一次决策仍需修正的比例；认证放行但原意图事件更晚的决策比例；
  4. 训练中反馈的启用比例、冲突投影的比例、λ 的分布；
  5. 学习曲线（训练与验证）。
- **验收（事先固定）：**
  - 新 ECC 对原 ECC 的紧急任务配对捕获差，两个种子都为正；
  - 合并差 ≥ +5 个百分点，且 95% 区间下界 > 0；
  - 不安全次数不多于原 ECC + 1；
  - 评估时修正率低于原 ECC。

  通过：用新种子和独立初始条件做确认轮。不通过（方向不一致或增益小于阈值）：停止，论文按原 ECC 和第一轮结果组织，不再迭代。
- **成本估计：** 6 条训练 × 8000 次决策 = 48,000 次决策，按第一轮吞吐约 1.5–2 晚（视并行数而定）；评估约 3 小时。
