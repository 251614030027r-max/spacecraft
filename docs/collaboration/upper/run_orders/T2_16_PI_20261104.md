## 方法：EACC，执行一致的策略改进

- **critic：** 完全是 `e_priv` 的。训练期读执行器判断，只用真实转移，不回归任何模型值。
- **执行器预测：** 每个决策，执行器用同一套处理预测各候选意图，**也预测策略此刻自己的确定性意图**（参照），使用共同随机数。
- **两种优势与融合：**
  - 两个优势估计：执行器优势 A_E（候选相对参照）、critic 优势 A_Q（同一对动作的 critic 值之差）；
  - 按逆方差加权融合：A_mix = A_Q + ρ(A_E − A_Q)，其中 ρ = σ²/(σ² + ε²)，σ 为 critic 的 TD 误差尺度，ε 为模型在已执行转移上的误差；
  - 修正场 ρ(A_E − A_Q) 在参照附近的斜率，只加在策略的动作梯度上。斜率是带截距的中心化拟合，策略意图本身作为修正为 0 的参照点，所有点共有的误差不产生方向；点太少或不分散时不修正；
  - 反馈行取自最近 256 条转移，保证参照意图就是当前策略的意图；
  - 信赖域：修正幅度不超过 critic 自身动作梯度的尺度，且只在策略均值仍靠近参照时生效；
  - 没有证据时，更新与 `e_priv` 完全相同。
- **两种证据：**
  - `e_pi`：用全部候选，包括阶段末与终局；
  - `e_pit`：只用执行器能算到终局的候选。证据稀疏，覆盖检查中只有约 3% 的反馈行生效；它主要检验"同样的终局证据，放在策略侧是否不再有害"，不预期有大的增益。

## A 的预先登记门槛（事后不改；`experiments.t2_direction summary`）

**做法：** 每个策略在每个开局上确定性地飞完整个回合（接口与 `e_pi` 训练相同：8 个候选、一段、候选间隔 0.01 m/s、策略意图作参照，校准由 `CAL.json` 预热后随回合更新）。每个阶段决策：
- 用学习器自己的代码（`_actor_correction`，FB_* 常数）算出执行器修正的斜率 g，以及 critic 在策略意图处的动作梯度 gq；
- 从决策前的状态分三条真值支路，意图分别移动 0.25：沿 critic 方向（Q）、沿 6.1 的修正后方向（M = gq + 截断后的 g）、沿执行器方向（E）。然后同一策略确定性地飞到回合结束，记录从该决策起的真实回报。

**只看"修正把方向转了"的决策**（M 与 Q 的夹角余弦 < 0.9，约 26°），因为只有这些地方 6.1 与 `e_priv` 的更新不同：

| 项 | 标准 |
|---|---|
| D 数据 | 有效决策（R_M 与 R_Q 相差 > 1）≥ 20 个 |
| P1 胜率 | 有效决策中 R_M > R_Q 的比例 ≥ 60% |
| P2 均值 | 这些决策上 R_M − R_Q 的均值 > 0 |
| S 安全 | M 支路的 unsafe 结局数 ≤ Q 支路 |

**结果：** 全部满足为 `pass`；D 不满足为 `insufficient`（补第二批一次，仍不满足就不训练）；其余为 `fail`（不训练）。
