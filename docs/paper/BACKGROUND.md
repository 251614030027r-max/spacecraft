# 背景、问题与贡献（引言素材）

引言与问题陈述的事实材料：背景、两个问题、贡献、研究问题。名称与术语以 `facts/00_术语与符号.md` 为准。

## 1. 研究背景与目标

### 1.1 背景

- **预捕获：** 在轨服务（维修、补给、失效航天器处置）中，服务航天器在捕获前要先安全接近目标，并建立满足捕获要求的相对位置、姿态和速度。
- **非合作目标无法配合：** 捕获接口随目标本体运动，追踪器必须同时协调相对位置与姿态。
- **多重约束：** 安全距离、接近走廊、视场、相对速度与执行器能力。

### 1.2 快速翻滚带来的难点

1. 捕获接口持续运动：面对的是运动的捕获位置，不是固定目标点；
2. 捕获窗口与相遇时机需要协调：端口周期性转动，过早或过晚都会错失机会；
3. 多重约束随翻滚状态变化。

**核心难点：** 可行捕获窗口随时间变化。追踪器不仅要满足局部运动约束，还要在有限时间与燃料下选择接近速度和捕获时机。

### 1.3 能力边界与融合方式

- **MPC：** 约束处理强，但预测时域有限，长期性能依赖参考与终端设计（Xu 等 2026，`References/南航.pdf`）。
- **RL：** 能学习长期、状态相关的策略，但依赖数据，复杂约束下探索效率与执行可靠性不足（Yang 等 2025，`References/哈工大.pdf`）。
- **RL–MPC 的融合方式**（Reiter 等 2026 综述，`References/RL-MPC综述.pdf`）：学习系统模型、学习代价与长期价值、学习任务参考、状态相关策略协调。本文属于"学习任务参考"一类，即 RL 生成阶段目标、MPC 执行。

### 1.4 两个问题（论文主线）

| | 理论问题（主） | 场景问题（副） |
|---|---|---|
| 表述 | **长期策略决策与短时约束执行如何有效协同？** 高层决策的预期收益不一定等于约束执行后的实际长期效果 | **快速翻滚目标的动态捕获窗口如何被有效利用？** 端口位置与法向持续变化，局部可行不代表最终能捕获 |
| 对应不足 | 不足 2：RL 的长期价值判断与实际约束执行存在偏差，高层意图未必能及时兑现，缺少兼顾执行反馈学习与动作协调的闭环机制 | 不足 1：动态捕获窗口利用困难；不足 3：旋转条件下阶段引导与入口规划困难 |
| 对应机制 | **ECC** | **RWG** |
| 对应目标 | 目标 2：执行感知的分层协同决策 | 目标 3：旋转感知的捕获窗口引导；目标 1（六自由度动态捕获建模）是两者的验证基础 |

### 1.5 论文中深化后的具体科学问题

**理论问题深化为"决策–执行失配"的三个方面：**
1. **信息失配：** 执行层知道某意图能否、何时进入入口 / 下降模式，学习层只能从稀疏的终局回报间接推断；
2. **时间尺度失配：** 高层每 16 s 决策一次，入口机会每个自旋周期（约 133–171 s）只出现一次，每次持续约 26–33 s；
3. **后果失配：** 机会稀缺时，相近意图的后果可能是捕获与超时之别。价值在动作空间出现由执行器规则决定的断崖，学习层难以从回报中学到。

**场景问题深化为：**
- 捕获端口在扫掠锥上周期性经过视线，入口可行性同时取决于纬向偏差、相位与相对速度；
- 时间与燃料预算决定了"现在接近还是等下一圈"的取舍；
- 已建立的入口在执行偏差下可能失效，需要在同一窗口内恢复。

### 1.6 研究问题（实验章节逐一回答）

- **RQ1：** 在限时捕获任务上，执行机会协调能否在同一执行链上提高捕获率（ECC 对 SAC–MPC，另与 TD3–MPC、MPC 比较）？
- **RQ2：** RWG 的旋转同步意图与入口重定时是否有效？
- **RQ3：** 协调在闭环中如何起作用（训练中的适应、期限分层、案例）？

### 1.7 贡献

1. **ECC（主）：** 面向长期决策与短时约束执行失配的执行机会协调闭环。执行层在每次决策处预测可兑现的入口机会（意图触发的短程入口、末次经过的直接入口），按一条规则在保持、修正、启动之间选择；SAC 在协调后的真实闭环上学习，经验存策略的提议。执行层不生成价值标签。
2. **RWG（副）：** 利用端口扫掠锥几何构造旋转同步的二维阶段意图（纬向调节使窗口可用，沿扫掠速度调整经过时机），以动态入口与入口重定时利用捕获窗口。
3. **验证：** 含 J2 与重力梯度的六自由度高保真仿真中，对限时约束下快速翻滚目标的预捕获做配对蒙特卡洛验证。建模是基础，不作为创新点。
