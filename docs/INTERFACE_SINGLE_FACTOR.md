# 头条主张的单因子验证：动作参数化决定耦合能否学起来（2026-09-12）

上层在本机从两批训练的 manifest 与 monitor 直接复算，不引用任何报告。

---

## 1. 两批训练只差一个因子

| | V4（旧接口） | V2（新接口） |
|---|---|---|
| 动作参数化 | **`radial_local`（4D）** | **`arrival_condition`（2D）** |
| 观测 | 31D（24D 核心 + 目标相位 6D + 剩余时间） | **31D，同上** |
| 反馈通道 | 无 | 无（V2 关闭） |
| MPC 时域 / 决策周期 | 20 / 20 | 20 / 20 |
| 学习率 / batch / gamma | 1e-4 / 256 / 0.99 | 1e-4 / 256 / 0.99 |
| `ent_coef` / `tau` / `learning_starts` | 0.005 / 0.001 / 2000 | 0.005 / 0.001 / 2000 |
| 网络 | (256, 256, 256, 256) | (256, 256, 256, 256) |
| 任务、奖励、动力学、约束 | 冻结 | 冻结，同一份 |

**逐字段核对后，两批之间只有动作参数化不同。** 这是一个合格的单因子对比，
不是"换了一整套设置"。

## 2. 对齐预算下的结果

V4 三个种子实际各跑到约 25.7k 决策后停止，所以对比取**前 25,697 决策**这个共同预算。

| 批次 | 种子 | 回合 | 完成 | 完成率 |
|---|---|---|---|---|
| **V4 `radial_local`** | 262100 | 443 | **0** | 0% |
| | 262101 | 432 | **0** | 0% |
| | 262102 | 433 | **0** | 0% |
| | **合计** | **1308** | **0** | **0%** |
| **V2 `arrival_condition`** | 262200 | 285 | **55** | **19.3%** |

## 3. 该怎么写，以及不能写什么

**可以写**：在同一任务、同一下层、同一奖励、同一观测和同一组超参数下，
仅改变上层动作的参数化，就把"从未完成"变成"最高 19.3% 完成"。
这支撑论文的第一条结论——**上层的表达方式本身是决定性的**，
不是"再多训练一会儿"或"再多给一些观测"能替代的。

对照证据：V3→V4 那一轮已经单独试过**加观测**（目标绝对姿态 + 剩余时间），
结果与 V3 无差别，仍是 0 完成。所以信息不是瓶颈，**表达才是**。

**不能写**：

- 不能说"新接口解决了种子分化"——**两批都各有一半种子学不会**，
  V2/262201 与 V3/262301 全程零完成。
- 不能说"新接口 75% 完成"而不注明那是**训练回合成功率**、
  在探索策略与持续更新的模型下测得，不是固定策略的独立评估成绩。
- V4 只有 3 个种子、新接口只有 4 个（每版 2 个），
  **都低于本项目 ≥3 训练种子的口径**，结论按分布报，不报最好种子。

## 4. 复算方式

```powershell
# V4 三个种子
logs\hybrid\sac_mpc_hybrid_v4_phase_time_2621{00,01,02}\{manifest.json,train.monitor.csv}
# V2/V3 四个种子
logs\t7_retry1_20260911\*\{manifest.json,train.monitor.csv}
```

manifest 的 `hybrid.waypoint_parametrization`、
`hybrid.include_target_phase_and_time_observation`、
`hybrid.include_execution_feedback_observation` 与 `hyperparameters` 区块逐字段比对；
monitor 按 `l` 列累加决策数截到共同预算，`completed` 列计完成。
