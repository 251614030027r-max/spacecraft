## 3. 终局标签真值检验（`脚本/term_probe.py` → `探针/`、`输出/TERM_PROBE_SUMMARY.json`）

**做法：**
- 开局：19 个紧急审计开局（2,910,000–2,910,039），143 个决策，1144 个候选，0 个错误；
- 第二段意图：本决策已执行的意图，作为策略确定性意图的替身；
- 真值分支：候选飞一个决策；没有终局、也没进入口时，再用同一个第二段意图飞一个决策；进入口的飞到终止；
- 沙箱容器中途重启过一次，探针跳过已完成开局续跑，日志见 `run_part1.log` / `run_part2.log`。

| 读数 | 第一段 | 第二段 |
|---|---|---|
| 终局判断：真 / 误 / 漏 | 65 / 5 / 1 | 149 / 6 / 26 |
| 判对时的标签误差：均方根 / 均值 / 绝对值中位 / P90 | 1.14 / −0.41 / 0.14 / 1.77 | 10.35 / −2.94 / 0.19 / 2.99 |

**怎么读：**
- **误判 11 处（第一段 5、第二段 6）全是同一种情形：** 真值进了入口但丢失、回到阶段重试。标签给的是回放期望终局（均值 +22.9），两决策深度的真值只看到中途（均值 −4.3），最终结局未知。按终局标签计，误判约占 5%（11 / 225），是本方法偏乐观的主要来源；
- **第二段的均方根 10.35 来自一个决策：** 2910033 第 32 s，8 个候选都被低估约 40（回放期望 23–36，真值都捕获，约 74）。同一决策的候选一起偏，排序不受影响。去掉它，误差与第一段同量级；
- **第二段漏判 26 处：** 真值在第二段终止（17 捕获、9 超时），模型没判终局，因而不出标签。只少覆盖，不引入偏差；
- **已执行意图结局修正：** 在这些开局上没有改变任何标签。已执行意图真的进入时，入口结局偏差已由执行锚定平移给候选，同一处理预测与真值一致。

**结论：**
- 终局标签在判断成立时很准；
- 主要风险是约 5% 的"入口丢失"被当作终局，标签偏乐观；
- 训练中由柯西权重处理（未锚定入口计入入口模型偏差），并在训练读数 `term_q_minus_target_mean` 与关键状态打分中报告；
- 本检验不预言训练收益。
