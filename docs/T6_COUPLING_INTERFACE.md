## 1. 接口

上层每 2 s（20 个控制步）输出 **2 维**动作 `a = (a_commit, a_radius) ∈ [-1,1]²`，
解析成一个目标体系的 3D 航点，经**已有的** `external_local` 通道进入 MPC。
**MPC、约束、动力学、奖励、任务定义一行未改。**

| 通道 | 含义 | 端点 |
|---|---|---|
| `a_commit` | 从「惯性冻结保持」到「期望位姿」的推进程度 | `-1` 纯保持；`+1` 纯切入 |
| `a_radius` | 保持点的半径，绕冻结时的半径缩放 `exp(0.35·a)` | `±1` 约 ×1.42 / ×0.70 |

航点构造为**方向球面插值 + 半径线性插值**，不是两点连线：

```
方向 = slerp(冻结惯性方向, 接近轴方向, w)      w = (a_commit + 1) / 2
半径 = (1-w)·r_hold + w·3 m
```

seed 262000 上实测的通道形状：

| `a_commit` | 半径 | 离接近轴 |
|---|---|---|
| −1.00 | 17.84 m | 53.0° |
| −0.50 | 14.13 m | 39.7° |
| 0.00 | 10.42 m | 26.5° |
| **+0.35** | **7.82 m** | **17.2°** |
| +0.80 | 4.48 m | 5.3° |
| +1.00 | 3.00 m | 0.0° |

### 为什么是 slerp 而不是连线

离线可行性证书在 **7.5 m 处、接近轴上**分级暂存。两点连线在给出 7.5 m 半径时，
方向仍被 17 m 的保持端主导（远端点的模长压过近端点），落不到轴附近；
方向插值则让参考随收敛摆向轴线，与已知可行解的形状一致。

### 为什么保持必须是惯性冻结

接近轴固连在目标体上。**在目标系里保持一个固定点＝随目标共旋，进入几何永不改变**——
没有窗口可等，只有燃料在烧。所以保持端是一个冻结的**惯性**方向，
每个决策重新表达到目标系，即每次发出一个**不同的**目标系点。
仓库里有一次把这件事写反的记录，本接口用测试钉住。

### 为什么是 2 维

严格按 T2–T4 实测取舍：

| 候选变量 | 实测结果 | 是否给通道 |
|---|---|---|
| 切入时刻 | **唯一救回持续失败种子的变量**（262005） | 是（`a_commit`） |
| 保持半径 | 新增救援 0；但配对格上省燃料 **20.6%**（354.83 → 281.74 N·s） | 是（`a_radius`） |
| 横向调整 | 24 个非零角度格 + 2 个零角度对照，全败 | **否** |
| 推进速率 | T3 的延迟格在切入前已失败，**未被有效测试** | 否；已被 `a_commit` 的连续性覆盖 |

2 维而不是 4 维，直接压缩探索空间——这在 1.067 s/决策的预算下是硬约束，不是偏好。

## 2. 能力下界：已逐位证明

`a = (+1, ·)` 在任何半径设定下都精确返回期望位姿，因此外部通道承载的是一个常量，
参考退化为定点广播——**就是固定设定点的 Pure MPC 控制器**。

12 个种子、每个前 300 个控制步，与直接构造 `reference_source="fixed"` 的 MPC 对比：

```
max |Δwrench| = 0.000e+00   （12/12 种子逐位相同）
```

所以「学习层的某个常量动作即经典控制器」不是叙述，是可执行的测试。
相对 AC4MPC 用**并行双解**换「不劣于」保证，这里用**参考空间的端点选择**在
**单次求解**内拿到同类性质；保证形式更弱（在该动作上成立，而非每步成立），如实写。

## 3. 反馈通道：耦合的反方向

上层观测追加 **3 维**上一决策周期的执行摘要，全部有界于 `[0,1]`：

| 量 | 含义 | 开销 |
|---|---|---|
| 回退比例 | 该周期内 QP 落到零回退的步数占比 | 免费（求解过程现成） |
| 有效求解最大松弛 | 只从**真正解出**的步上读，按 `constraint_slack_limit` 归一 | 免费（已解 QP 的松弛变量） |
| 平均执行器使用率 | 力/力矩相对上限的逐步最大值再取均值 | 免费（就是下发的指令） |

三条实现纪律：

1. **松弛只在求解成功的步上读。** 回退步上 `slack.value` 可能仍是上一次成功求解的残留，
   无保护地读会把陈旧裕度当成本步的描述。测试钉住：`solved_steps == 0` 时该量为 0。
2. **用均值不用峰值。** 峰值几乎每个决策都饱和（Λ>1 下持续共旋本就要满三轴权限），
   峰值通道会是一个常量，上层无从据此行动。
3. **不放 `predicted_minimum_margin`。** 它需要一次完整时域 rollout，
   只在 `runtime_diagnostics=True` 时才算，而训练路径正是关掉它的。
   它也**不是**真值几何裕度——真值违约只由 RK45 真值判定，两者不得混用。

反馈通道与动作通道是配套设计的：下层报「执行器快满 / 松弛在涨 / 开始回退」，
上层手里必须有「缓一缓、退远一点」这个动作——`a_commit` 往负走正是它。

`--no-execution-feedback` 提供严格单因子消融：其余全同，只摘掉这条反向通道。

## 4. 262006：可解，但不是位置参考能解的

本轮用仓库已有的离线可行性证书结案：

| 262006 | 结果 |
|---|---|
| 完成 | **是**，217.5 s |
| 真值违约 | **全部为 0**（禁入、视场、外围速度、外围径向、走廊、总速率、闭合速率） |
| 力冲量 | 169.73 N·s |
| 最小视场裕度 | **0.693 rad** |
| 最小归一化裕度 | +0.148 |

**所以 262006 不在物理可达边界上，一条便宜的可行路径确实存在。**

但本轮又扫了 42 个新接口格（6 个暂存混合 × 7 个切入时刻），**全部失败**，
且全部在 35–52 s 内终止、半径反被推到 20–26 m。加上 T2 的时刻扫描、T3 的速率扫描、
T4 的横向扫描同样全败，结论是：

> **262006 的失败是指向（视场）失败，不是路径选择失败。**
> 可行计划保有 0.693 rad 的视场裕度，而 MPC 擦着视场上限死（49.92° 对 50°）。
> 上层通道只说位置，说不到这件事上去。

这条**不折进本轮**。它是一个独立的候选单因子（姿态参考），需要单独授权，
不能和接口、奖励、任务混在一次改动里。论文中按实测写：
在所测试的上层位置决策范围内该工况未被救回，而一条可行路径存在。

## 4b. 262005 在新接口上的完整网格：可行集不连通

42 格（6 个暂存位置 × 7 个切入时刻），14 格完成。按暂存位置分组：

| `a_commit` 暂存值 | 对应半径 | 完成 |
|---|---|---|
| −1.00（纯惯性等待） | 17.8 m | **3/7** |
| −0.50 | 14.1 m | **0/7** |
| 0.00 | 10.4 m | 1/7 |
| **+0.35** | **7.8 m** | **5/7** |
| **+0.50** | **6.7 m** | **5/7** |
| +0.80 | 4.5 m | **0/7** |

**成功区有两块，中间隔着一整块失败区，内侧也是失败区。** 在两个可行设置
（−1.00 与 +0.35）之间插值会掉进 −0.50 的空洞；再往里推到 +0.80 又全灭。

这是本工作支撑「需要学习层」最强的一条论据：

- 上层动作空间里的可行集**非凸且不连通**，梯度法与手写规则都会掉进空洞；
- 救援是**挑剔的**，不是「离得越近越好」，这排除了「只是重调了设定点」的质疑；
- 最好的一格（+0.35，7.8 m 暂存，80 s 切入）**122.1 s 完成**，
  而旧接口在同一工况上最快是 271.2 s。

新接口因此既保住了旧接口唯一的救援能力，又把它的质量提高了一倍以上，
而挑剔性没有被抹平——后者正是「这里存在一个值得学的决策」的证据。

```powershell
# V2：任务型接近策略，单向

    --parametrization arrival_condition --no-execution-feedback `
    --run-name sac_mpc_v2_arrival_262200

# V3：接近策略 + 反向反馈（完整耦合）

    --parametrization arrival_condition `
```
