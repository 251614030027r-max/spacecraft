## 2. ECC 的收敛表述（实现与第一稿 ECC_LE 的执行逐位相同）

在决策状态 x（模式 S / H），策略提出意图 a。执行层给出两类机会，两类都只在"最后机会"时由协调使用。

- **意图机会：** 对候选网格 𝔅 = {−1, 0, 1}² 与 a 做 48 s 模式预测，得到 (ê, τ̂, Δv̂)。
- **直接入口机会：** 入口规划器从当前状态按到达时刻 𝒯_L = {20, …, 220} s 求解，取第一个可行者。

**最后机会：** 一个在时刻 t_e 发生的机会，若 t_e + P > L（P 为自旋周期，L = T_d − 45 s 为最晚到达时刻），即错过它在 L 前不再有下一次经过。

**关键机会集** O_c(x) = O_I(x) ∪ O_L(x)：
- O_I(x) = { b ∈ 𝔅 : ê(x, b) = 1，t + τ̂(x, b) + P > L，Δv + Δv̂(x, b) ≤ B }；
- O_L(x)：端口在本阶段内经过（t_pass ≤ h）且 t + t_pass + P > L 时，直接入口可行则含它，否则为空。

**协调规则（一条）：**
1. 若 ê(x, a) = 1，执行 a（保持）；
2. 否则在 O_c(x) 中执行对 a 改动最小的机会：
   - 意图 b 的改动为 ‖b − a‖，并列时取 τ̂ 小者，再按网格固定顺序；
   - 直接入口完全替换意图，改动视为大于任何意图，所以只在 O_I 为空时被选；
3. O_c(x) 为空时执行 a。

这正是第一稿的"保持 / 修正 / 启动远场入口"，只是写成一个机会集加一条规则。

**开关：**

| 开关 | 含义 | 默认 |
|---|---|---|
| `coordination` | 协调开 / 关 | 开 |
| `correction` | O_I 是否参与（关闭即"无核心"：只剩保持与直接入口） | 开 |
| `long_entry` | O_L 是否参与（直接入口是协调的一部分，不单独做消融；关闭只用于测试） | 开 |

`correction` 关闭时只预测 a 本身，不预测网格。

**副机制 RWG 的检验工具**（2026-11-20 更正：此前把"无副机制"误写成评估时关闭直接入口；直接入口属于协调，副机制指 RWG）。RWG 有三部分：旋转同步意图（扫掠锥坐标、纬向律、沿扫掠速度）、动态入口、入口重定时（`facts/03`）。

| 工具 | 检验对象 | 是否训练 | 说明 |
|---|---|---|---|
| 评估开关 `rigid_entry`（`window = False`） | 入口重定时 | 否 | 策略看不到重定时，同一模型关闭即可配对比较（第一稿用过：+2.8 个百分点） |
| 固定意图配对：`c_10_0` 对 `b_10` | 旋转同步意图 | 否 | 同一接近意图 (1, 0)，带与不带旋转引导；不涉及学习策略，所以公平 |

**不允许**在训练好的 ECC 模型上直接关闭旋转引导做评估：策略的动作定义在自旋坐标系里，关闭后同一动作含义改变，测到的是错配，不是机制。

**学习：** 回放存提出的 a，回报与后继来自协调后的执行（不变）。

**逐位判据：** 同一初始条件、同一组随机意图序列下，新代码（协调全开、旧势函数 `lead24`）与旧代码（科学 `72a8d41`，`certify` + `long_entry`）逐步比较以下各项，必须全部一致：

## 3. 奖励：机会可达性势函数

**动机：** 第一稿的势函数 Φ = −min(25 m, ‖q − m(t + 24 s)‖) 用固定提前 24 s 的口部点。它与端口何时经过、期限前还剩几次经过、制动包络都没有关系。第一稿失败几乎都是超时，弱种子是节奏偏慢的策略（成功任务完成时间中位数更长、超时更多）。

**定义：** 用执行层自己的常数和恒速预报（与观测、规划器同一信息边界）。

1. **名义最早到达时间 t_m(x)：** 先由阶段层把距离接近到入口判定距离 12 m，闭合速度取 min(0.20 m/s, v_b(ρ − 6 m) − 0.02 m/s)。其中 v_b 为任务的径向制动包络，0.20 m/s 为意图盒的最大闭合速度，0.02 m/s 为入口判定的包络裕度。同时纬向偏差按 RWG 的固定纬向律收敛，要求 |δ_lat| ≤ 35°。以 0.5 s 步长积分。再加上入口规划最短的到达时刻 15 s。
2. **经过窗口与可调的经过时机：** φ 为端口到视线子午面的剩余相位。
   - 由引理 1，在扫掠锥上（λ = β）、门限 35° 时，每次经过的窗口在相位上为 [c − φ_hw, c + φ_hw]，中心 c = −2πk（k = −1, 0, 1, …；k = −1 为刚过去的一次）；
   - 由命题 1(iii)，沿扫掠速度 v_sw ∈ [−v_a, v_a] 使相位以 Ω(1 + κ) 减小，κ ∈ [−κ̄, κ̄]。其中 v_a = 0.15 m/s 是意图盒的最大沿扫掠速度，κ̄ = v_a / (Ω ρ sin β)，ρ 取当前距离；
   - 所以 t 秒后可达的相位区间为 [φ − Ω(1 + κ̄)t, φ − Ω(1 − κ̄)t]。它与第 k 个窗口相交的时刻集合是一个区间 [t_a(k), t_b(k)]：
     - t_a(k) = (φ − c − φ_hw) / (Ω(1 + κ̄))；
     - κ̄ < 1 时 t_b(k) = (φ − c + φ_hw) / (Ω(1 − κ̄))；
     - κ̄ ≥ 1 时相位还可以回退，下界相应改写，上界为 ∞。
3. **最早可赶上的入口时间：**

   T_go(x) = min_k max(t_m, t_a(k))，约束 max(t_m, t_a(k)) ≤ t_b(k) 且 t + max(t_m, t_a(k)) ≤ L。

4. **势函数：** Φ(x) = −min(Φ̄, c · T_go(x))；没有可赶上的窗口时 Φ = −Φ̄。
   - c = 0.10 /s，即任务自身的时间代价；
   - Φ̄ = 25，与旧势函数的界相同；
   - 终局 Φ = 0。

**含义：** c·T_go 是"用 RWG 的两个杠杆（闭合速度、沿扫掠速度）最快能赶上的入口还要付出的时间代价"的乐观估计，可以看作价值的一个时间分量。势函数由论文已有的引理 1（窗口宽度）、命题 1（经过时机可调）、制动包络和期限直接构成。
- 由距离限制时（还没接近到入口距离），Φ 随名义到达时间稠密变化：接近得越快，势越高；
- 由窗口限制时，Φ 随"最早可赶上的窗口"变化：迎向端口能使它提前，势随之升高；不用杠杆时它后移，势下降；
- 错过一个窗口时，T_go 跳到下一次经过，Φ 明显下降；
- 期限前已无可赶上的窗口时，Φ 落到最低。

**性质：**
- 标准的基于势函数的塑形 r̃ = r + γ_d Φ(x′) − Φ(x)，γ_d 与学习用的相同，终局 Φ(x′) = 0；最优策略不变（Ng 等 1999）。
- 不改成功、安全与超时的判定，评估只报告真实回报；所有组用同一奖励。
- 只用到任务与方法已有的常数（时间代价、旧势函数的界、意图盒的闭合与沿扫掠速度、制动包络、入口门限与裕度、期限余量），没有新增可调权重。
- 不调用模式预测，每次计算是毫秒级的解析运算。

**修订（2026-11-19，实现后、任何训练之前）：** 最初的定义让阶段层以 ≤ 0.20 m/s 一直接近到口部半径 6.3 m。用固定意图在 4 个开发初始条件（295300–295303，属于开发评估段；只飞固定意图，没有学习策略参与）上检查势函数的取值时发现，这样会把很多仍能兑现的状态判成"已无可用窗口"：开发初始条件 295301 用意图 (0, 0) 时，从 t = 16 s 起势函数一直停在下界。原因是执行层实际在 ≤ 12 m 处就启动入口规划，入口转移本身用 15–60 s 走完最后一段，速度不受意图盒限制。因此改为第 1 条现在的写法（接近到 12 m，再加最短到达时刻 15 s），与执行层的入口规则一致。

同一检查还发现第二个问题。开发初始条件 295300（期限 147.3 s，最晚到达 102.3 s）的端口下一次经过窗口从 113.3 s 开始。只按当前视线计算时，整个回合都被判成"无可用窗口"。但 RWG 的沿扫掠速度可以迎向端口，使经过提前（命题 1(iii)，κ̄ ≈ 0.28），这个窗口约 88 s 就能赶上。因此第 2、3 条加入沿扫掠速度对经过时机的调节；κ̄ = 0 时退化为原写法。

两次修订都发生在任何训练之前。

**旧势函数保留为开关** `potential = 'lead24'`，只用于第 2 节的逐位核对（`evidence/R2_EQUIV/` 的复现），不登记为任何实验配置。
