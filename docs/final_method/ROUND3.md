## 3. 方法 v4：以扫掠窗口贯穿的整合（2026-11-27，开发轮 B）

**用户要求：** 方法精简，体现算法整合而非工程罗列；第三点是增益型辅助机制（重定时的定位），把重定时做成有算法依据的形式；高自旋落实不了就不写；只再开一两轮开发；正式实验的变体不超过三四个，不单独验证反馈核心，但报告核心带来的增益。

**整合的主线：** 引理 1 的扫掠窗口是一个对象，三个机制各自用它：
1. **RWG（引导）：** 纬向调节让窗口出现、变宽，沿扫掠速度移动窗口到来的时刻（不变）。
2. **ECC（协调 + 反馈）：** "最后机会"就是期限前的最后一个窗口；在最后一个窗口上，执行层把提议换成最早可兑现的机会，并把这次替换反馈给学习。
3. **窗口约束的重定时（辅助增益机制）：** 入口在执行偏差下失效时，到达时刻只在这个窗口剩下的部分里重新搜索。

### 3.1 协调：一个机会集、一个最后窗口条件、一个反馈信号（`coord_rule='window'`）

- **机会集：** 提议 a、3×3 格点意图（模式预测给出是否在 T_p = 48 s 内进入、何时进入、燃料）、直接入口（入口规划器从当前状态直接规划，提交时刻为现在）。
- **最后窗口条件（状态级，所有机会共用）：** 下一次经过在预测时域内（τ_p ≤ T_p），且其后的下一次经过已晚于最晚到达（t + τ_p + T_sp > t̄_e）。取代原来两套条件（格点按事件时刻、直接入口按 16 / 32 s 的经过时刻）。
- **规则：**
  - 提议自己能兑现：执行提议；
  - 否则在最后窗口上：执行最早可兑现的机会。直接入口立即提交，可行时优先；否则取燃料够用、能进入的格点意图中离提议最近者；
  - 其余情况执行提议。
- **反馈信号：** 只要提议被替换（格点意图或直接入口），训练回报减干预代价 β = 2.0。只用于训练，评估报告真实回报。
- 去掉的部分："不动"与"保持"合并；32 s 参数、按事件时刻的关键性判定不再单列。

### 3.2 窗口约束的重定时（`retime='window'`，执行层，所有方法共用）

原到达时刻 τ₀ 的计划失效后，候选延后量取 σ = 2, 4, … s，只保留"预报端口在 τ₀ + σ 时刻仍在入口门限 35° 内"的连续一段（即窗口剩余部分，上限 30 s）；先用规划力界，再用备用力界（加 σ = 0）。窗口宽度随转速变化，搜索范围随之变化。原来的固定 {2, 4, 8} s 作为对照（`retime='fixed'`）。

3. 增益：V3B 对 SAC_MPC +26.4，满足。
4. **高自旋进论文：** V3B 对 SAC_MPC +26.0，下界 > 0。第二轮模型在同样条件下为 −2.4，改善来自 v3 的协调与反馈。

**定型（正式轮）：** `ECC_V3B` 作为 ECC。执行层与第二轮相同。方法精简体现在论文表述上：一个机会集、一条最后机会规则（立即可兑现优先，其次最小改动），一个反馈信号（修正代价），执行层写成两个阶段。

**打包：** 开发轮的运行来自两个提交（A 在 `89b1e784`，B 在 `5432ecce`），两者对 A 的配置逐位等价。注册表 `dev3.science_commits` 列出这两个提交，`resolve` / `pack` 据此接受。

## 4. 收束：开发轮 C（最后一轮）与正式实验（2026-11-28）

### 4.1 论文要点（定稿方向）

1. **RWG 旋转同步窗口引导：** 扫掠锥几何（引理 1、命题 1）让窗口出现，并决定它何时到来；动态入口与重定时是它的执行部分，重定时不单列为贡献。
2. **执行机会协调：** 执行层用自己的模型预测意图能否兑现；在期限前的最后一个窗口上，把兑现不了的提议换成可兑现的机会，立即可兑现的直接入口优先，其次是改动最小的格点意图。一条规则。
3. **执行一致的反馈学习：** 策略在协调后的闭环上学习，经验存提议（命题 2）；每次替换作为干预代价反馈给学习，恢复"自己可兑现的提议更优"的偏好（命题 2(ii) 的无差别被打破），真实目标的损失以 β 乘替换次数为界。依据是机理与推导，加训练中修正比例下降的观察，不做归因实验。

不作为要点的内容：势函数塑形（训练细节）；四种执行模式（写成接近 / 入口两个阶段）；细格点、对准优先、窗口重定时等已否决的方案（不出现）。

### 4.2 开发轮 C

**唯一问题：** 统一规则（v4，更干净）在固定重定时下是否只损失很少。

| 配置 | 内容 |
|---|---|
| `ECC_V4F` | v4 统一规则（最后窗口一个条件、立即可兑现优先、任何替换都有干预代价 β = 2）+ 第二轮的固定重定时 |

- 训练：`ECC_V4F` × 种子 40–42 × 3000 次决策（阶段 `dev3`，同一批评估初始条件，与 V3B、SAC_MPC 直接配对）。
- 评估：正式转速（`dev3`）与高自旋（阶段 `diag3d`，开关 `dev_hs`）。V3B、SAC_MPC 的结果已有。

**采用规则（开跑前写定）：** 统一规则被采用，当且仅当以下三条同时成立：
1. 正式转速下 V4F 对 V3B ≥ −1 个百分点；

3. 高自旋下 V4F 对 SAC_MPC ≥ +5 个百分点，区间下界 > 0。

否则 ECC = V3B。两种情况下 4.1 的三个要点都不变（V3B 的修正代价只作用于修正，命题同样成立）。
