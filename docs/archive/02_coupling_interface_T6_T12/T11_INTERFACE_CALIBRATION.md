# S8:接口不是标定出来的,是把振荡去掉

测于 2026-09-13,上层沙箱,h35,冻结的下层。**无训练、无 checkpoint。**

---

## 1. 原计划做不了

`docs/T10_EXECUTION_ORDER.md` §7 要求"把 `∂r_ref/∂a0` 压到一个决策窗的平动权限量级"。
算过之后这条**做不到**:

- blend 的行程是**几何固定**的——hold 冻结在 12–19 m,desired pose 在 3 m,中间 13 m。
  `∫|∂r/∂a0| da0` 恒等于 13 m,对 blend 做任何非线性变形只能**挪动增益落在哪**,不能减小它。
- 按权限(**0.094 m**/决策)做速率限制,从 hold 走到 commit 需要 **138 个决策 = 276 s**,
  300 s 的回合里 commit 就够不着了。

所以"标定增益"这个提法本身是错的。

---

## 2. 重读轨迹:病因是振荡,不是行程

死种子把 `a_commit` 来回走(均值 0.78–0.86、标准差 0.09),推力花在换向上;
活种子是**单调升到 1 然后钉住**。同一条回合内部 t=88 s 前后的对照也是这个形状。

所以单因子改成**提交棘轮**:

```
b_k = max(b_{k-1}, b_k_commanded)
```

零可调常数;一个决策仍能直接 commit;`a=(+1,·)` 依然每个决策命令目标位姿;
想等多久等多久。已测出的 headroom **全部是单调的先等后提交**,棘轮不会削掉任何可行提交时机。

---

## 3. 【测】证据:抖动注入,不需要训练

用 `a_commit ~ N(0.80, 0.09)` 直接复现死种子的动作统计,施加在
**固定设定点本来全部能完成的 8 个种子**上:

| 262003 | 完成 95.4 s / 191.0 | 失败 300 s / **1964** | 完成 95.2 s / 226.0 |

| 262007 | 完成 83.0 s / 160.3 | 失败 300 s / **2106** | 完成 84.6 s / 200.3 |
| 262008 | 完成 75.0 s / 180.9 | 失败 300 s / **1951** | 完成 153.6 s / 225.8 |
| 262009 | 完成 85.3 s / 130.2 | 失败 300 s / **1792** | 完成 91.1 s / 180.6 |

**两件事同时被确定:**

1. **接口增益假设被实验证实。** `docs/T7_T9_REVIEW_20260912.md` §5 把它标为
   "【推】纯推断、零实验",并请审查者找一个比"改接口再训练"更便宜的证伪办法。
   这就是那个办法:只往动作里注入死种子级别的抖动,**8/8 完成变成 0/8**,燃料涨到
   基线的 **10 倍以上**,每决策把设定点甩出 **0.618 m**——而权限只有 0.094 m。
   不需要训练,不需要 checkpoint。
2. **棘轮是有效的修法**:同样的抖动下 **7/8 恢复**,每决策位移中位数回到 **0.000 m**。

## 4. 【测】逐位地板没有被碰坏

`a=(+1,·)`,12 个种子,与棘轮引入之前的 `commit_now` 基线逐条比对:

**字段不一致 0 项;力冲量差异 0 项(连 1e-9 都没有);完成 8/12,失败集合不变。**

棘轮在 commit 角点上是恒等的:`max(b, 1.0) = 1.0`,所以 `a=(+1,·)` 仍然逐位是固定设定点
Pure MPC。这是整个接口的能力底线,它没有动。

---

## 5. 棘轮带来的一个必须一起做的改动

棘轮**在决策之间携带状态**:同一个动作在不同的已提交程度下命令不同的路径点。
如果不把这个状态给策略,决策问题就**不再是马尔可夫的**,策略等于在猜自己的过去。

所以观测尾部追加一个标量——当前 blend,落在 [0,1]。**这不是可调项,是恢复马尔可夫性的必需品。**
观测维数因此 24 → 25(`arrival_condition` 且棘轮开启时);关掉棘轮或换参数化都回到原值,
且前 24 维逐位不变(有测试钉住)。

这一条和棘轮是同一件事的两半,不拆成两个因子:**没有它棘轮不可训练。**

---

## 6. 边界与未测

1. **抖动是脚本注入的**,复现的是死种子的动作统计,不是它们的状态依赖性。
   这证明了机制,**没有**证明学习出来的策略一定表现得像哪一边。
2. **8 个种子、一个噪声水平、一个均值。** 没有扫 σ 或均值。
3. **棘轮对学习的影响未测。** 它改变了 MDP(动作效果依赖历史),观测补偿之后应当仍可学,
   但那要 S9 三个种子来证。
4. 262002 在有棘轮下仍然失败(300 s / 287.7 N·s,燃料只有无棘轮的 1/6.5,说明不是抖动
   耗尽,是停在那里)。棘轮去掉的是抖动病理,不是所有失败。
5. 棘轮下的成功燃料 219.6 N·s 比干净的固定设定点 173.3 高约 27%——因为它要花几个决策
   爬到 commit,而固定设定点一开始就在那里。**这是抖动的代价,不是棘轮的代价。**
