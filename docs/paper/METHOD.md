# 论文方法（唯一源文档）：执行感知 SAC–MPC 分层协同控制

**地位：** 论文方法章节的唯一依据。所有符号、命题、伪代码都能逐项对到冻结实现（科学 `e0a61753`，最终配置 `ECC_CERT_LOOP`），对照见 `FACT_MAP.md`。历史规格（`docs/archive/method_development/` 下的 `METHOD_SPEC`、`ECC_SPEC`、`ECC_FINAL_SPEC`、`C1_THEORY`、`METHOD_MINIMAL` 等）只作研发记录，**不是最终论文算法**。

**边界：** 本文只做表达与证明层面的统一，不改变训练、控制行为、超参数或奖励。研究背景与问题见 `BASELINE.md` 第 0、1 节。

**一句话验收：**
- **主问题：** 学习器的长期意图可能错过只有短期执行器才知道的关键捕获机会。
- **ECC：** 执行器以状态反馈辅助价值学习，以模式机会认证协调动作；训练与执行学习的是同一个协调系统。
- **RWG：** 扫掠锥几何把旋转窗口变成二维运动意图；入口重规划在原到达时刻附近扩展可行候选。

## 2. 方法

### 2.1 任务与多速率执行系统

**物理与约束。**
- 六自由度相对运动，SE(3) 描述；真值由 RK45 积分，含中心引力、J2、二阶质量矩与重力梯度力矩，控制周期 0.1 s。
- 追踪器 106 kg，每轴 ±2 N、±0.6 N·m。目标 225 kg 自由翻滚，2.1–2.7°/s；执行层用各向同性惯量估计，真值惯量未知。
- 约束与结局判定见第 2.5 节，安全只由真值几何判定。

**多速率执行链（职责以实现为准）。**

| 模式 | 平移 | 姿态 |
|---|---|---|
| 阶段飞行 S | 距离 > 7.5 m：阶段规划轨迹前馈 + PD 跟踪；≤ 7.5 m：冻结 MPC 跟踪阶段参考 | 远场：指向控制，使相机视轴对准端口；近场：冻结 MPC |
| 保持 H | 规划被拒或跟踪偏离 > 3 m 时原地保持（远场 PD；近场 MPC） | 同阶段飞行 |
| 入口转移 E | 条件入口规划器（下称"入口规划"）给出到口部的转移轨迹，冻结 MPC 跟踪 | 冻结 MPC |
| 末段下降 D | 冻结 MPC | 冻结 MPC |

论文不能写成"全程 MPC 控制"。

**事件驱动的高层决策。**
- 高层在模式 S / H 时每次给出意图 a。宏步以下列事件结束：
  - 名义 16 s；
  - 偏离触发保持且已过 ≥ 2 s 时提前结束；
  - 进入 E / D 后连续执行到终局，期间不再决策；
  - 终局事件。
- 每个宏步给出真实回报 r、后继 x′、终止 d。
- 学习使用每次决策固定折扣 γ_d。这是**事件驱动宏决策的固定折扣近似**，不是按真实时长折扣的半马尔可夫最优控制。

**信息划分。** 策略观测 o 的 18 项有效量：
- 距离、自旋系相对速度（3）；
- 端口–视线夹角、纬向偏差、相位的正弦与余弦、自旋角速度；
- 剩余时间、任务类型、已用燃料、剩余燃料；
- 径向制动裕度、锥半角、自旋系端口方向（3）。

其中不含相对姿态误差（由执行层姿态控制处理），也不含执行器的规划答案与执行状态（它们属于 z_E）。所有量都按物理尺度归一化，尺度表见附录 B。

### 2.2 RWG：旋转同步窗口引导

**(1) 扫掠窗口。** 恒速预报下，τ 秒后端口与视线的夹角满足

  cos θ(τ) = cos λ cos β + sin λ sin β cos(φ − ωτ)，

其中相位差按 2π 取模到 [−π, π]。在 sin λ sin β > 0 时记 c* = (cos θ_g − cos λ cos β)/(sin λ sin β)：
- c* > 1：无窗口，等价于 |Δλ| > θ_g；
- c* ≤ −1：整圈都在 θ_g 内；
- 其余情形：窗口相位半宽 Δφ = arccos c*，窗口在 φ − ωτ ∈ [−Δφ, Δφ] 时打开。
- sin λ sin β = 0（视线或端口与自旋轴共线）时，夹角与相位无关，单列处理。

几何机会集 𝒲_geo 定义为：存在入口到达时刻 τ ∈ 𝒯 = {15, 20, 25, 30, 40, 50, 60} s，使 θ(τ) ≤ θ_g（θ_g = 35°，入口预筛门限）。**它只是几何可入窗，不是安全或捕获保证。**

**(2) 二维意图到三维运动。** 阶段末目标速度为

  v* = −v_c e_r + v_l e_pol + v_z e_az，v_c = 0.05 + 0.15 a_p，v_z = 0.15 a_z，v_l = clip(k_λ r Δλ, ±v_l,max)，

其中 k_λ = 0.02 s⁻¹，v_l,max = 0.12 m/s。纬向分量是固定几何律，不是学习动作。局部运动学（已用 `spin_frame` 数值核对）为：
- **距离：** ṙ ≈ −v_c；
- **纬向：** Δλ̇ = −v_l / r，未饱和时 Δλ̇ = −k_λ Δλ，以 50 s 时间常数把视线拉到扫掠锥上，扩大窗口半宽 Δφ；
- **相位：** φ̇ = −‖ω‖ − v_z / (r sin λ)。
  - v_z > 0（朝迎面端口，**迎击**）：端口更早经过；
  - v_z < 0（**伴飞**）：经过推迟，对准时间拉长；
  - v_z = 0：**等待**。
  - r ≈ 10 m 时，沿扫掠速度可把经过时刻提前或推迟约 ±35%。

因此两个学习自由度分别管"接近节奏"和"与旋转端口的相遇时机"。迎击、伴飞、等待是同一连续动作在几何上的不同用法，实现中不存在人为的三分类器。

**(3) 阶段目标与执行。**
- **速度限幅：** 目标速度增量限制在阶段权限内，即 16 s 内 70% 规划推力（1.6 N）可达的变化量。
- **安全投影：** 阶段末距离不小于 6.8 m（操作球 6 m + 口部带 0.5 m + 0.3 m），径向接近速度不超过阶段末距离处的制动包络减 0.02 m/s。
- 局部阶段规划器（16 节点）给出参考，由第 2.1 节的执行链跟踪。

**(4) 动态入口。** 进入入口规划需同时满足：距离 ≤ 12 m、径向制动裕度 ≥ 0.02 m/s；对 𝒯 中预测夹角 ≤ θ_g 且到达不晚于 L 的候选时刻，依次调用入口规划（80% 力界、执行层估计惯量），第一个可行者开启入口转移。因此实际可执行入口集 𝒲_plan(x) ⊆ 𝒲_geo，前者要求真实的规划可行。

**(5) 入口重规划的候选扩展。** 正在执行的入口若在原到达时刻 τ₀ 重规划失败，依次尝试：
1. τ₀ + s（s ∈ {2, 4, 8} s），用规划力界 F₀；
2. τ₀ + s（s ∈ {0, 2, 4, 8} s），用备用 95% 力界 F₁。

候选只受"不晚于期限余量"和规划可行性检验。

> **性质 R1（可行候选不减）：** 同一状态与判据下，固定到达时刻的候选集是扩展候选集的子集，且扩展机制先按原时刻尝试；所以"存在可行入口计划"在扩展下不会变弱。同一时刻下力界放宽只扩大可行集。
>
> **注（"同一窗口"的准确含义）：** 实现并不显式检查相位窗口，被采用的候选由入口规划器按端口在该到达时刻的位姿核验。只有当原到达时刻的相位离窗口边缘的余量 ≥ ω·s 时，才可以断言重定时后的到达仍在同一次经过内。论文写作"原到达时刻附近、以窗口为导向的重规划"。R1 不蕴含捕获率单调提高，后者由配对实验检验。

### 2.3 ECC（一）：执行反馈与执行机会认证

ECC 只有一个执行器接口，分成两种功能不同的反馈，二者互不重复。

**(1) 状态层反馈 z_E（只进入评价器）。** 相对策略观测新开放的六项：
- **机会判断：** 到下一次端口经过的时间、各入口到达时刻上的最小预测端口–视线夹角（入口可达性）、经过后的期限余量；
- **执行状态：** 上一阶段的位置残差、速度残差、是否处于保持。

评价器为 Q(o, z_E, a)，策略为 π(a | o)。z_E 解释了"同一几何观测下，接管机会是否存在、意图是否被如实执行"，使评价器能表示更贴近真实后果的价值关系。数学上只说：增加条件信息不会缩小可表示的价值函数类。收益由实验说明；不主张无偏或必然更优。

**(2) 动作层：执行机会认证 𝒞。** 每次决策（模式 S / H），执行器对每个 b ∈ 𝔅 以及策略意图 a，用自身的阶段层、入口判定与入口规划，按恒速姿态预报和名义规划轨迹预测保持该意图至多 H = 48 s 的模式事件。预测在期限或燃料耗尽处截止，得到 (ê, τ̂, Δv̂)。可认证候选集为

  𝔅_c(x) = { b ∈ 𝔅 : ê(x,b) = 1，t + τ̂(x,b) + P > L，Δv_used + Δv̂(x,b) ≤ B_max }，

三个条件依次表示：会触发入口或下降；这是关键窗口（错过后期限前再无一整圈可等）；燃料够用。认证映射为

  𝒞(x, a) = a，若 ê(x, a) = 1 或 𝔅_c(x) = ∅；
  𝒞(x, a) = 在 𝔅_c(x) 中按 (‖b − a‖₂, τ̂(x,b)) 字典序最小者，其余情形。

只作用于当前一次宏决策，不强制后续保持。

> **性质 E1（认证）：** (i) 原意图在预测中会触发模式事件，或无可认证候选时，执行原意图；(ii) 发生替代时，执行意图满足有限集合的模型认证条件，且在其中对原意图的改变量最小（等距取事件更早者）。证明由有限集合的字典序选择直接得到。

**准确性说明（论文必须写）：**
- 原意图只按"是否触发事件"放行，不套用关键性与燃料条件；
- 候选事件可以是直接进入下降，不一定经过入口规划；
- 关键性条件 t + τ̂ + P > L 是"机会稀缺"的时间代理，不是对后续全部可达状态的计算。

**条件性改善（性质后的注记）：** 若 (a) 被选候选的预测事件在真值中兑现，(b) 之后的决策不把系统带离该窗口，(c) 原意图确实会错过这一关键窗口，则认证把一次超时变为入口。三个条件对应三种可能的失效：预测不兑现、后续偏离、过早介入。因此认证不保证"从不伤害"，实验报告净效应与翻转数。

### 2.4 ECC（二）：训练–执行一致的真实反馈学习

**认证诱导的转移。** 记执行器宏转移核为 P_ℰ，则

  P_𝒞(x′, r | x, a) = P_ℰ(x′, r | x, 𝒞(x, a))。

训练与执行使用**同一个** 𝒞。经验池保存策略**提出的** a，回报与后继来自认证后的**真实**执行。训练回报为

  r̃ = r + γ_d Φ(x′) − Φ(x)（终局取 Φ(x′) = 0），

用于常规 SAC 时序差分：
- **评价器：** 双评价器取最小、目标网络，目标为 y = r̃ + γ_d (1 − d)[min Q̄(o′, z_E′, a′) − α log π(a′|o′)]，a′ ~ π(·|o′)；
- **策略：** 最小化 E[α log π(ã|o) − min Q(o, z_E, ã)]；
- **温度：** 固定 α。

执行器的预测**只用于认证动作**，不生成任何长期价值目标，也不改动 SAC 的损失。

> **性质 E2（学习对象一致）：** 在完整状态 x 上，按上述方式收集的数据是马尔可夫决策过程 (P_𝒞, r̃, γ_d) 的样本，所以价值学习的对象是包含认证器的协调系统在执行时的真实后果。对照：若只在执行时加认证、训练时不用，则训练优化的是 P_ℰ，执行的却是 P_𝒞，两者不一致。这正是 RL–MPC 综述指出的后处理滤波器问题：训练时不可见的滤波器使策略无法闭环最优（Reiter 等 2026，8.3 节）。
>
> **推论（认证等价与策略依赖）：** 同一完整状态下，若 𝒞(x, a₁) = 𝒞(x, a₂)，两个提议的实际执行与后果分布相同，在相同后续策略下价值相等。所以在认证会替代的区域，策略无需自己学会选出被认证的意图；关闭认证时，在环训练的策略不必比单独训练的策略更强。这解释了开发期观察到的"执行时关认证后性能下降"。

**部分可观与函数逼近。** Bellman 对象定义在完整状态 x 上。策略只读 o、评价器读 (o, z_E)，是该对象的非对称函数逼近；采集为异步双进程、离策略回放。论文不主张无偏性或收敛性。

### 2.5 约束、奖励、参数与算法

**约束（真值判定；按适用阶段分类）。**

| 约束（`compute_t1_metrics` 的硬违背项） | 适用区域 | 判据 | 违背后果 |

| 操作球 / 终端走廊（并集） | 全程 | 在操作球（6 m）外，或在以端口为轴、半角 35° 的锥内 | 不安全终止 |
| 相机视场 | 全程 | 视轴与端口视线夹角 ≤ 50° | 不安全终止 |

| 总速度、轴向接近包络 | 口部区域内 | 相对速度、沿端口轴的接近速度不超过上限 | 不安全终止 |

各项按各自的容差（几何、角度、速度）判定，不跨量纲合成。

**奖励。**
- **真实回报：** r = −c_t Δt − c_f Δv + 终局项。终局项为捕获 +100，超时或燃料耗尽 −100，不安全 −150。紧急任务 c_t = 0.10 /s、c_f = 10 /(m/s)，经济任务 c_t = 0.02 /s、c_f = 40 /(m/s)。
- **势函数：** Φ(x) = −min(25 m, ‖q − m₂₄‖)，m₂₄ 为按恒速预报 24 s 后的口部位置（口部半径 6.3 m）。
- **塑形：** 带 γ_d，见第 2.4 节；只用于训练，所有评价报告真实回报。

**参数（只给依据，不改数值）。**

| 参数 | 值 | 依据 |
|---|---|---|
| 阶段时长 | 16 s | 一次经过约 26–33 s，16 s 的扫掠角为 34–43°（约半个窗口），经过前有 2–4 次决策机会；16 s 恒速预报误差约 1° |
| 接近 / 沿扫掠速度范围 | v_c ∈ [−0.10, 0.20]，v_z ∈ [−0.15, 0.15] m/s | 阶段权限约 0.17 m/s；沿扫掠可调经过时刻约 ±35% |
| 纬向律 | k_λ = 0.02 s⁻¹，限幅 0.12 m/s | 时间常数 50 s，约 3 个阶段内把纬向偏差减半以上 |
| 阶段权限 | 70% × 1.6 N | 为跟踪留余量 |
| 阶段末最小距离 | 6.8 m | 操作球 + 口部带 + 余量；操作球只由入口与下降进入 |
| 入口门限 | 12 m、35°、0.02 m/s，𝒯 = 15–60 s | 入口规划可行区的外包络（规划真正可行约在 20° 以内，见 C1 图 A） |
| 末段余量 | 45 s | 下降与捕获所需时间 |
| 重规划扩展 | +2 / 4 / 8 s，95% 力界 | 在原到达时刻附近恢复失效入口 |
| 模式预测 | H = 48 s，3 × 3 候选 | 3 个阶段覆盖一次窗口；动作盒均匀覆盖 |
| 学习 | SAC，[256, 256]，学习率 3e-4，经验池 10⁵，批量 256，起步 200，每条转移 2 次更新，固定 α = 0.05，目标 τ = 0.005，γ_d = 0.999⁸ | 冻结设置 |

只影响执行阶段的两项（H、候选密度）可做只评估的敏感性分析，放附录。

**算法（伪代码）。**

```
训练（每个采集进程）
  初始化 x，观测 o、执行反馈 z_E
  循环（每次高层决策）：
    a ~ π_θ(·|o)                               # 策略只读 o
    若模式 ∈ {S, H}：对 𝔅 ∪ {a} 做 48 s 模式预测，a^e ← 𝒞(x, a)；否则 a^e ← a
    经 RWG（意图 → 阶段目标 → 规划 / 跟踪 → 入口规划与重规划扩展 → MPC）执行 a^e，
      直到宏步结束（16 s / 偏离提前 / 入口或下降后至终局）
    r ← 真实回报；r̃ ← r + γ_d Φ(x′) − Φ(x)（终局 Φ(x′) = 0）
    存入 (o, z_E, a, r̃, o′, z_E′, d)                # 存提出的 a
    学习进程：每条转移 2 次 SAC 更新（第 2.4 节）
执行（测试）
  a ← π_θ 的均值；a^e ← 𝒞(x, a)；经同一执行链执行 a^e
```

**方法总图（唯一一张）：**
- 左：策略 π(a|o)；
- 中：执行机会认证 𝒞，读 48 s 模式预测，输出 a^e；
- 右：RWG 执行链（扫掠锥意图 → 阶段规划 / 跟踪 → 入口规划与重规划扩展 → 冻结 MPC），作用于六自由度真值；
- 下方两条反馈：真实转移 (r̃, x′) 回到经验池；执行反馈 z_E 只进入评价器；
- 标注"训练与执行使用同一 𝒞"。

## 3. 不主张

- 安全保证或捕获保证（安全只由真值判定）；
- 认证对连续动作最优，或"从不伤害"；
- 重规划扩展必定提高捕获率，或重定时后的到达必在同一次经过；
- 非对称评价器无偏或收敛；
- 优于动作空间外的直接入口规划（它只作参照）；
- 跨算法、跨任务的迁移性能。"策略无关的协调接口"只作结构性描述。

不进入主方法的内容：
- 新调节器（机会时刻承诺、只引向规划入口、递归保持），见 DEAD_ENDS D45；
- 动作层证书作为评价器输入（`cut_ecc`）；
- 反事实价值标签与动作梯度修正（D39–D43）。

## 附录 A　推导要点

- **R1：** 刚性候选 {(τ₀, F₀)} ⊆ 扩展候选；对每个 τ，F₁ > F₀ 只放宽力界约束。
- **E1：** 𝔅 有限，字典序存在唯一最小者（等距、同时刻时按 `PROBE_GRID` 顺序取先者）。
- **E2：** 由 𝒞 是 (x, a) 的确定函数，(x, a) → (x′, r) 的分布即 P_ℰ(·|x, 𝒞(x, a))；回放中的 (o, z_E, a, r̃, o′, z_E′, d) 是该过程在观测映射下的样本。推论由 𝒞 的取值相同直接得到。
- **扫掠窗口：** 端口方向绕 ŝ 匀速转动；视线与端口在 ŝ 坐标下的夹角公式由球面余弦定理得到，相位差取最短角距。
- **局部运动学：** e_az 与端口扫过视线的方向相反，所以沿 e_az 的速度使视线子午面迎着端口转动。符号已用 `spin_frame` 数值核对（r = 10 m，λ = 60° / 90° / 120°）。
