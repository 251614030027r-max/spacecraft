# 实验总账

`EXPERIMENT_REGISTRY_20261007.csv` 每行一个实验。上层按 Git 内的证据预填，下层盘点时补齐本地列，并对上层所填内容提出异议。

## 状态标签

| 标签 | 含义 | 能否进论文数字 |
|---|---|---|
| `OFFICIAL` | 按预注册执行、结论已判读 | 能；负结果也照实写 |
| `EXPLORATORY` | 开发检验、探针、事后分析 | 只能作为说明或动机，不能当性能数字 |
| `INVALID` | 已知缺陷导致结果无效（例如评估器从未更新执行反馈观测） | 不能 |
| `HISTORICAL` | 旧任务、旧接口、已关闭的路线 | 只作背景 |
| `ACTIVE` | 正在产生 | 尚不能 |
| `PENDING` | 已授权或预注册、尚未产生 | 尚不能 |

## 字段

| 字段 | 谁填 | 内容 |
|---|---|---|
| `experiment_id` … `claim_served` | 上层预填 | 编号、时间、状态、行、代码提交、模型种子、评估块、Git 内证据、审查提交、主读数文件及其 SHA、一行结论、有效性说明、论文角色、服务的主张 |
| `local_result_path` | 下层 | 本地原始结果所在路径；`D:/py/DRL2/...` 或 `C:/Users/35884/Documents/Spacecraft/...` |
| `local_sha_verified` | 下层 | 主读数文件本地 SHA 与上层所填是否一致：`yes` / `no` / `n/a` |
| `lower_note` | 下层 | 不同意上层标注的地方、找不到的文件、补充信息 |


总账只登记、不判定。改动状态标签需要上层或研究讨论层确认；下层的不同意见写在 `lower_note`。

`paper_role`、`claim_served` 两列里的 L1–L4 是 2026-10-07 时的论文主张代号。论文主张推演已移出 git（见 WORKFLOW 第 8 条），这两列只作历史标注。
