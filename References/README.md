# 文献与用途

| 文献 | 用来做什么 | 不要做什么 |
|---|---|---|
| `哈工大.pdf` | 本工作所基于的 SE(3) 建模 | 把建模当作贡献 |
| `北航.pdf` | 约束处理（锥、视场、饱和）。它的目标角速度为 0.0173 rad/s，且没有速度上限，正说明我们的工况在它之外 | |
| `南航.pdf` | 它的局限 1（LTI 预测模型假设中等翻滚）是本工作的动机 | 把分层结构声称为新颖。南航已经是上层提议、下层过滤、带死锁检测。我们的不同在于上层是学出来的，并且工况为 Λ > 1 |
| `北航编队.pdf` | RL 给 MPC 提供调度的接口模式 | 它的脉冲模型 |
| `上海交大.pdf` | 三方对比表的格式 | 它的方法：在线调整 MPC 代价权重已被排除（`docs/DEAD_ENDS.md` D16） |
| `AC4MPC.pdf` | 评论家作终端代价，以及并行双解给出"不差于"的界 | 两者都不可用：学到的终端代价实测有害，双解需要 1.5 倍预算（D15）。这种不可行性本身可以作为论文中的对比 |
| `ecc26_rollout.pdf` | 学习提供好的名义解，优化在其邻域内改进 | |
| `Synthesis of model predictive control and reinforcement learning...pdf`、`RL-MPC综述.pdf` | RL 与 MPC 结合方式的分类，用于定位本工作 | |
| `Leung和Kolmanovsky 2024`、`Tartaglione 2024` | 可行性调节器、显式参考调节器：参考整形一类的相关工作 | |
| `Wu 2024`、`Zeng 2026`、`Lu 2025`、`Duan和Zou 2025` | MPC 价值估计、残差 RL、安全演化 RL：相关工作 | |
| `Ramezani 2026` | RL 增强 MPC 用于在轨加注对接：最接近的航天应用 | |
| `视觉抓捕.pdf`、`视觉综述.pdf` | 感知背景（感知线已关闭） | |
| `引入死区迟滞...pdf` | 不用于论证，这是用户自己此前的论文 | 引用它 |
