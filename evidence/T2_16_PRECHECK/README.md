**修正：**
- 修正斜率改为带截距的中心化加权最小二乘，策略自身意图作为修正为 0 的参照点。所有点共有的误差不产生梯度（测试 `test_centred_slope_ignores_a_common_offset_and_needs_an_identifiable_direction`）；点数少于 2 或不够分散时，不施加修正；

## T2.16 门槛：真值方向审计（`experiments/t2_direction.py`）

**问题：** 6.1 能赢 `e_priv`，当且仅当在执行器与 critic 意见不同的地方，执行器修正后的方向更对。这可以不训练、直接在真值上测。

**做法：** 训练好的 `e_priv` 检查点确定性飞完整个回合（接口同 `e_pi`）。每个阶段决策用学习器自己的 `_actor_correction` 算修正斜率 g，以及 critic 的动作梯度 gq；从决策前状态分三条真值支路，意图沿 critic 方向（Q）、6.1 修正后方向（M）、执行器方向（E）各移动 0.25，然后同一策略飞到回合结束。门槛（预先登记，见 collab `T2_16_PI_20261104` A 段）只看 M 与 Q 夹角大于约 26° 的决策。

**沙箱冒烟（链路检查，不是证据）：** 30 步的 `e_priv` 策略，开局 2980000，1 个决策、3 条支路都飞到捕获，约 220 s；修正正常算出（64 行全部可辨识）；判 `insufficient`（一个决策，预期如此）。`输出/direction_smoke_*`。测试 87 项通过（`输出/pytest_87.log`，退出码 0）；新增 `test_direction_audit_uses_the_learner_correction_on_one_transition`。
