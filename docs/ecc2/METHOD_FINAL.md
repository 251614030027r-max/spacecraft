# ECC 最终方法：执行机会感知 — 反馈价值学习 — 跨时域协调控制（统一定义）

**状态（2026-11-18，用户确定的整合方向）：** 本文件取代 `ECC_LE.md` 中的方法叙述，作为最终方法的统一定义；`ECC_LE.md` 保留诊断与开发期检验。学习更新为标准 SAC。六维评价器输入暂时保留，是否精简由第 4 节的一次整体对照决定。

## 1. 统一结构

```
执行器的机会预测 ──► 执行机会集合 Ω(x) ──► 机会协调 𝒞(x, a) ──► RWG / 入口规划 / MPC 真实执行
        │                                         ▲                         │
        └──► 价值学习的执行条件化输入 z            │                         ▼
                           SAC 策略 π(a|o) ────────┘          真实回报、窗口状态、跟踪残差 ──► SAC 价值学习
```

方法只有一条主线：执行器对旋转窗口内可执行机会的预测，同时服务于两件事：

- **高层学习：** 价值学习的输入与目标都来自真实执行；
- **实际协调：** 在保持意图、修正意图、启动远场入口三者之间选择。

## 2. 执行机会集合

在决策状态 x（模式 S / H），执行器用自己的模型给出两类机会：

- **短程机会（阶段接近触发）：**

  Ω_S(x) = { b ∈ 𝔅 ∪ {a} : ê(x, b) = 1，Δv_used + Δv̂(x, b) ≤ B_max }

  其中 𝔅 为 3 × 3 意图网格，(ê, τ̂, Δv̂) 为 48 s 模式预测：保持意图 b 时，执行层是否、何时、以多少燃料转入入口或下降。
- **远场机会（末次经过的直接入口）：**

  Ω_L(x) = { τ ∈ 𝒯_L : t + τ ≤ L，入口规划器从当前状态在 τ 到达口部点可行 }

  其中 𝒯_L = {20, 30, …, 120, 140, …, 220} s。只在末次可用经过时评估，条件 κ(x) 为：

  t_pass ≤ h，且 t + t_pass + P > L

  t_pass 为端口到下一次经过的时间，h = 16 s，P 为自旋周期。

**关键窗口：** 机会 b ∈ Ω_S 满足 t + τ̂(x, b) + P > L，即错过它，期限前不再有下一次经过。

## 3. 机会协调映射（一个映射，三种动作）

  𝒞(x, a) =
  - a　　　　　　　　　　　　　　若 ê(x, a) = 1　　　　　　　　　　　　　　【保持】
  - argmin_{b ∈ 𝔅_c(x)} (‖b − a‖, τ̂(x, b))　　若 ê(x, a) = 0 且 𝔅_c(x) ≠ ∅　　　【修正】
  - 远场入口，τ* = min Ω_L(x)　　　　若上两条不适用，κ(x) 成立且 Ω_L(x) ≠ ∅　【启动】
  - a　　　　　　　　　　　　　　其余情形

其中 𝔅_c(x) 为 Ω_S(x) ∩ 𝔅 中的关键窗口候选，即原认证集。启动远场入口后，入口转移由近场 MPC 执行；丢失时转为保持，回到高层决策。

**性质（严格成立，由定义直接得到）：**

1. **最小干预：** 策略意图在预测中能自己触发事件时，总是被保持；修正只发生在关键窗口；远场入口只在末次可用经过、且没有其他可执行机会时启动。接近节奏与相遇时机始终由策略决定。
2. **保守扩展：** 与原 ECC 的认证映射相比，𝒞 只在"原映射飞行的意图预测不触发事件，且处于末次可用经过"的状态上不同；在其余所有状态上，两者给出相同的执行意图。所以按执行器的预测，加入远场机会不会减少原映射在任何状态上已有的可执行机会；它只在原映射已无预测机会的末次经过上增加一个选项。
3. **判定不变：** 成功、安全与任务回报的判定完全不变，协调只改变执行哪一个机会。

## 4. 反馈价值学习

- **算法：** 标准 SAC（固定 α = 0.05，双评价器，[256, 256]，学习率 3e-4，经验池 10⁵，批量 256，每条转移 2 次更新），在含 𝒞 的闭环上学习。
- **数据：** 经验池存策略提出的 a，回报与后继来自协调后的真实执行。
- **评价器输入 Q(o, z, a)：** z 为执行条件化输入，包括：
  - 窗口状态：到下一次经过的时间、入口可达角、经过后的期限余量；
  - 执行状态：上一阶段的位置残差、速度残差、是否保持。

  它是价值学习的信息接口，不单独作为贡献。
- **精简规则（一次整体对照，事先固定）：** 比较 ECC_LE（读 z）与 SAC_LE（不读 z，执行器与协调完全相同）。
  - 若 ECC_LE 的合并捕获高于 SAC_LE，且至少 2 个种子的配对差为正：保留 z，论文中作为信息接口简述；
  - 否则：最终方法采用不读 z 的结构（即 SAC_LE 的配置），论文删去这部分。

## 5. 实验（紧急任务，种子 20–22，300000–300095，与第一轮配对）

| 配置 | 内容 | 作用 |
|---|---|---|
| `ECC_LE` | 统一方法（读 z + 完整协调） | 主方法 |
| `SAC_LE` | 标准 SAC + 同样的完整协调 | 强基线；同时是 z 的整体对照 |
| `ECC_CERT_LOOP` | 原 ECC（第一轮） | 改进前的方法 |
| `SAC_C` | 普通 SAC–MPC（第一轮） | 基线 |
| 参考线 | 纯 MPC、固定意图、直接入口规划 | 参照 |

**步骤：**

1. **当晚只评估检验：** 第一轮 ECC 与 ECC w/o execution feedback 的模型，各加远场入口，评估 288 个紧急回合。
   - ECC 一项须达到 250/288 且不安全 ≤ 1，才训练；
   - 后者给出 z 的早期读数。
2. **训练：** 达标后训练 `ECC_LE`、`SAC_LE`，各 3 个种子 × 5000 次决策，各一场。
3. **采用 ECC_LE 作为最终方法：** 与原 ECC 配对比较，规则同 `ECC_LE.md` 第 5 节：捕获 > 236，至少 2 个种子为正，回报 > 36.4，不安全不增加超过 1。否则保留原 ECC。

**目标：** 近期 85–87%，继续冲击 90%。不放宽成功判定，不挑选初始条件。若需要进一步提高，下一步只考虑增加训练步数，不再增加门控或阈值。
