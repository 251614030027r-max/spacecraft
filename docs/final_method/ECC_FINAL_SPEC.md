## 1. 研究定位

主机制面向**长期学习决策与短期受约束执行之间的协同**：SAC 按长期收益提出运动意图，执行器掌握规划可行性、约束、模式切换与执行后果。学习器认为有价值的意图未必能被执行器及时兑现；执行器短期可行也不代表任务仍有完成机会。

闭环：**意图提出 → 执行器反馈可行性与执行机会 → 必要时最小调整 → 真实执行 → 真实结果用于长期价值学习。**

C1（扫掠锥阶段意图、窗口承诺）是面向快速翻滚目标的场景贡献，不变，不与主机制混淆。

## 2. 通用反馈接口与本任务实现

| 通用概念 | 定义 | 本任务实现 | 用于 |
|---|---|---|---|
| 关键模式事件 | 执行器离开决策层、进入完成任务的下层模式 | G★ 入口（bridge）；进入下降区由冻结 MPC 接管（descent） | 调节器 |
| 执行机会 ω(x, b) | 执行器模型在保持意图 b 时，时域 H 内是否、何时触发事件，消耗多少资源 | `ExecutorProbe.probe_intent`：事件、时刻、阶段与入口规划 Δv（H = 3 段 = 48 s） | 调节器 |
| 接管可接受性 | 下层模式自身的接管条件 | 入口：距离 ≤ 12 m、径向制动包络裕度 ≥ 0.02 m/s、到达 ≤ 期限 − 45 s（执行器入口规则本身）；下降：切换状态的径向制动包络裕度 ≥ 0.02 m/s（口部区域按执行器门槛视为满足）、切换时刻 ≤ 期限 − 45 s；两者都要求已用 Δv + 规划 Δv（含入口规划）≤ 预算 | 调节器 |
| 机会关键性 | 错过本次机会后期限前不再有可接受的机会 | 最早可接受事件时刻 + 自旋周期 > 期限 − 45 s | 调节器 |
| 剩余机会（状态层） | 离下一次机会多远、错过后还剩多少余量 | 过境时间、窗口可达角、过境后截止余量（工程观测第 8、17、19 维） | critic |
| 执行一致性 | 执行器是否兑现了上一段 | 位置 / 速度残差、保持标志（第 14–16 维） | critic |
| 约束裕度 | 当前离约束边界多远 | 制动裕度（第 18 维；actor 也可见） | actor、critic |

两条通道来自同一个执行器：**状态层反馈进 critic（学习），动作层机会核对进调节器（决策）**。critic 结构即 EACH_C 的 48 维（`cut_priv`），不新增输入；完整 ECC 的动作层证书（`cut_ecc`）不再使用。

## 3. 执行机会调节器 G(x, a)

**记号：** 决策时刻 t，最晚可接受时刻 L = T_d − 45 s，自旋周期 P = 2π/|ω|（恒角速度模型），探测集 B₉（3 × 3 网格），现任意图 a⁻（本回合上一次实际执行的意图；回合首次决策没有）。"可接受事件"按第 2 节接管可接受性判定（门控探询 `gate=True`）。

SAC 提出 a 后：

0. 在真实状态 x 上探询候选集 B(x) = B₉ ∪ {a⁻}（现任意图同样重新认证，不预设可行）。若 B(x) 中没有可接受事件 → **状态 `none`**，执行 a。
1. **关键性：** τ_min 为 B(x) 中最早可接受事件时刻；若 t + τ_min + P ≤ L（错过这次之后仍有可接受机会）→ **`not_critical`**，执行 a。
2. **本意图：** 探询 a 本身（保持 a 至多 3 段）。若有可接受事件 → **`own`**，执行 a。若在第一段内触发不可接受事件（例如无保护地进入下降区）→ a 破坏机会，转第 4 步。
3. **执行一步之后：** 取 a 飞完一次宏决策（执行器模型：规划可行则飞 16 s 名义轨迹，被拒则原地保持；第一段内若触发事件已在第 2 步处理）后的预测状态 x⁺(a)，在 x⁺(a) 上探询 B₉ ∪ {a}（按与 a 的距离排序，遇到可接受事件即停）。若有 → 机会仍在，**`successor`**，执行 a。
4. **替代：** a 会破坏关键机会。在 B(x) 中取可接受事件、且离 a 最近的候选 b（距离相同取事件更早者）→ **`replace`**，执行 b。没有 → **`lost`**，执行 a（不强行执行未确认的替代）。

**监测模式：** 计算完全相同、只记录、始终执行 a（不协调对照，同时给出"破坏机会的提议"计数）。探询使用独立的规划器实例，监测模式与关闭时的轨迹逐位相同。

**记录（每决策）：** 状态、是否关键、τ_min、本意图事件、替代意图与预测事件时刻 / 类别、候选数、调节器串行耗时。

**不做的事：** 不计算任何价值，不产生学习信号，不使用训练历史，不修改执行器、C1、冻结 MPC。

## 5. 理论（条件全部写明）

**命题 1（长短期失配）。** 上层意图的长期价值取决于执行器能否在机会消失前触发关键模式事件。机会稀缺时（只剩一次可接受机会），错过即以超时结束，价值在动作空间中出现由执行器短期模式规则决定的断崖；断崖位置依赖执行器的门槛、规划与事件时刻，学习器难以只从稀疏的终局回报中学到。

**命题 2（执行机会反馈与最小干预）。** G 只在以下条件同时成立时改变 SAC 的意图：机会关键；a 本身不触发可接受事件；执行 a 一步之后的预测状态上已无可接受机会；存在可接受的替代。其余情况决策权完全留给 SAC。被改时取离 a 最近的可接受候选。

**命题 3（条件性机会保持）。** 假设
- A1 一步预测一致：从预测后继状态可认证的候选，从真实后继状态也可认证；
- A2 模型平移一致：执行器模型是确定的，并从自身预测状态逐段重新规划，因此可接受候选 b（事件时刻 τ_b > 16 s）的延续在其一步预测后继上仍可接受，事件时刻为 τ_b − 16 s（按构造成立）；
- A3 宏决策按模型结束：完成一段、规划被拒保持、模式事件、期限或预算；不可预测的提前返回（偏离保持）在真实状态上重新决策。

若第 k 次决策时关键机会可被认证，则 G 执行的动作或在本步触发可接受事件，或使第 k + 1 次决策时仍有可认证的后续方案（a 自身的延续，或被执行候选的延续），因此关键事件不晚于 L 发生。A1 不成立时由第 k + 1 次在真实状态上的重新认证发现；若届时无可接受候选，G 不强行替代（状态 `none` / `lost`）。A1 在验证中直接测量：**持续率**（`replace` 后，本步触发事件或下一决策仍有可接受候选的比例）与**兑现率**（`replace` 的预测事件在真值中于预测时刻 + 16 s 内发生的比例）。

**命题 4（机会守恒与收益预言）。** 在某次决策时若剩余可赶上的机会不少于 2 次（t + τ_min + P ≤ L），G 不介入，该决策的同模型增益为 0。只剩 1 次时，同模型（同一策略，开 / 关调节器）的期望捕获增益 ≈ 破坏率 × 兑现率，回报增益 ≈ 破坏率 × 兑现率 × 200（捕获 +100 对超时 −100）。破坏率 = 监测模式下回合中出现 `replace` 判定的比例；兑现率见命题 3。两者都由监测与调节运行实测，预言在每个稀缺档上核对方向。

**命题 5（真实反馈学习的一致性）。** 训练与部署使用同一 G；目标只来自真实转移，学到的是受协调系统（转移核 P(·|x, G(x, a))）的价值。critic 读 actor 不可见的执行状态（残差、保持标志），属非对称 critic：原 U1 的"特权输入是 actor 观测的确定函数、信息不变"在 `cut` 接口上不成立，改按非对称 critic 的无偏条件表述（critic 同时以 actor 的信息与状态为条件，Baisero & Amato 2022）。学习使用每次高层决策固定折扣 γ_d = 0.999⁸，而宏步真实时长随事件变化（16 s、提前返回 ≥ 2 s、终局宏步）：这是事件驱动的宏决策近似，不是连续时间半马尔可夫折扣。

**存提出动作的推论（约束论文写法）：** 被 G 改写区域内的提议具有相同的真实后果，actor 没有直接动力离开它们。因此本方法预言"受协调系统的价值被一致地学到"，**不预言** SAC 自己学会更好的意图；后者只作读数（第 7 节），读数支持才写。

**两级解释：** 决策层由 G 保住执行机会，执行层由窗口承诺保住入口计划——同一原则：每一步都保留可执行的后续方案（C1_THEORY T4）。

**谱系：** 参考调节器 / 可行性调节器（Leung & Kolmanovsky 2024；Tartaglione 2024）从约束可满足推广到时限机会；与 shield / 安全过滤器的区别是保护任务机会而非约束。

**不写入的结论：** 无条件递归可达；调节前后最优值相等；价值断崖完全消失；安全保证。

## 6. 验证条件：机会稀缺度（只按几何定义）

**几何（执行器的恒角速度模型，t = 0，不依赖任何策略或学习结果）：**
- 过顶时刻 t_k = t_pass,0 + kP（k = 0, 1, …），t_pass,0 为端口扫到视线子午面的时间（`spin_frame`）；窗口半宽 h = 35°/|ω|（入口预筛角 `BRIDGE_ANGLE_DEG` 对应的扫掠时间）。
- 名义接近时间 t_app：以动作盒最大接近速度 0.20 m/s 接近至 12 m（`BRIDGE_RANGE_M`），同时按固定纬向律（`latitude_velocity`）把纬向误差收敛到 35° 以内；两者都满足的最早时刻。最早到达 t_arr = t_app + 15 s（`BRIDGE_TAUS_S` 最小值）。
- 可赶上的窗口：t_k + h ≥ t_arr；按时间排序为 c₁ < c₂ < …
- **N 档期限：** T_d = 45 + c_N + h + u·(P − 2h)，u ~ U(0, 1) 由开局号确定。即最晚可接受到达落在第 N 个窗口结束之后、第 N + 1 个窗口开始之前：名义上恰有 N 次可赶上的窗口。
- **档与代价：** 开局号 mod 4 = 0、1 → N = 1；2 → N = 2；3 → N = 3。N = 1、2 用紧急代价（0.10 /s、10 /(m/s)），N = 3 用经济代价（0.02 /s、40 /(m/s)）；预算 3 m/s。训练与评估的档比例因此固定为 1/2、1/4、1/4，所有组相同。
- **自然分布**（紧急 U(140, 200) s、经济 U(280, 340) s 各半）照常评估，作外部有效性。

**筛查（只用非学习策略，只跑一次，开局 294400–294447，从未用过）：** 策略 `gstar`、`rally`、`c_10_0`、`c_10_-5`、`c_6_5`、`b_10`、`pure`。门槛（N = 1 档，24 个开局）：
- F（可解）：G★ 捕获率 ≥ 0.80；
- D1（有学习空间）：最佳单一固定阶段策略（rally、c_10_0、c_10_-5、c_6_5、b_10 中捕获最多者）捕获率 ≤ G★ − 0.15；
- D2（状态相关）：逐开局最佳固定阶段策略的捕获率比最佳单一固定策略高 ≥ 0.10；
- M（充裕可解）：N = 3 档 G★ 捕获率 ≥ 0.80。
- pure MPC 原样运行，只报告。

**备选定义（只用一次，事先写死）：**
- F 或 M 不过（太难）→ 严格可赶上：窗口须整体在最早到达之后（t_k − h ≥ t_arr）。
- D1 或 D2 不过（太易）→ 最晚可接受到达落在第 N 个窗口的前半：T_d = 45 + c_N − h + u·h。
- 改一次后在同一批开局上重跑筛查；仍不过则本轮在第 0 步停下，交用户决定。定档后训练期间与之后不再改动。

## 7. 开发验证与判据

**开局：** 294320–294367 只作回归（294323、294334 重放），不用于定档或选型。A 步评估 294500–294595（96 个：N1 48、N2 24、N3 24）；B 步评估 294600–294695（同样分档），并以同一批开局的自然分布任务评估。正式块 300000 以上不碰。

**A 步（不训练）：** RUN_ECC 的 EACH_C、SAC_C 模型（种子 10、11，2000 步检查点），在稀缺度条件下各评三种：监测（= 不协调）、旧认证、新调节器。同模型配对为 4 个模型 × 96 个开局。

机制判据（主证据，A 步）：
- M1：N1 档同模型（调节器 − 监测）合并均值 > 0，且合并捕获数增加；
- M2：0 丢失（任一开局监测下捕获、调节器下未捕获）；
- M3：0 unsafe 由调节器引入（任一开局调节器下 unsafe、监测下不是）；
- M4：N3 档每回合 `replace` ≤ 0.05；
- M5：各档同模型均值增益与命题 4 的预言方向一致（|值| 小于该档一次翻转当量 200/n 时记为 0）。

**M2 或 M3 不过 → 弃用调节器，B 步的在环与部署协调改用旧认证**（在环配置 `ECC_CERT_LOOP` = EACH_C 配置 + 旧认证在环）。M1、M4、M5 不过只如实报告。

**B 步：** SAC_C、EACH_C、在环方法（A 步胜出的协调规则）× 种子 10、11 × **3000 决策**，从零训练，训练任务为稀缺度条件；检查点 1000、2000 只报告。评估 3000 步模型：SAC_C；EACH_C（不协调、新调节器部署、旧认证部署）；在环方法（按训练方式、监测）。稀缺度与自然分布各一次。

选型判据（B 步；G1–G5 即 `experiments/u2_readout.gates`，在 N1 档、按种子按开局配对的 96 对上）：
1. 在环方法 对 SAC_C：N1 档过 G1–G5，且自然分布对 SAC_C 不劣（均值差 ≥ −8.3、unsafe 0）→ **最终方法 = 在环方法**；
2. 否则 EACH_C + 部署协调（A 步胜出的规则）对 SAC_C 同样两条 → **最终方法 = 部署协调**（论文不主张训练与部署一致）；
3. 否则 → **保留 `ECC_deploy`**（RUN_ECC 选定版本，EACH_C + 旧认证部署）。

只报告：按档剂量曲线（N1 / N2 / N3）、持续率、兑现率、破坏率与命题 4 预言对实测、训练曲线（含训练期超时与每回合介入次数）、在环模型监测模式下的原始行为（对比 EACH_C 监测）、调节器串行耗时（不作实时性主张）。

## 8. 纪律

不挑种子、不挑检查点（主模型为预算步数）。奖励、物理、C1、冻结 MPC、网络超参数、`cut` 信息边界不动。判据与选型顺序入库后不改；新方法失败如实报告并回退，不再调阈值、不加模块。
