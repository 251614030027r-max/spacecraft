## 追加（11-02 晚）：`opp2` 为何沉默；决策级执行校准的离线检验

**`silent.py` → `silent_OUTPUT.txt`：**
- 在真值为"捕获对超时"（差 ≥ 50）而 `opp2` 没有表态的 221 对中，210 对是 `opp2` 预测两个意图都能进入（捕获概率 1.0），而真实执行中一个捕获、一个超时。
- 规划器假定可以从阶段末直接进入；真实执行器只在 12 m 内、端口离视线 35° 以内才发起入口。中间多花的时间导致超时。
- 结论：问题不是缺信息，而是上层评价与下层真实执行不一致。

**`calib.py` → `calib_OUTPUT.txt`：**
- **做法：** 对 `opp2` 做决策级执行校准，用逻辑回归按机会特征预测"是否真的捕获"。在挑选块上拟合，在留出块上检验。
- **捕获预测准确率（留出块）：** 0.929；原始 `opp2` 为 0.702；只猜多数类为 0.583。
- **策略遗憾分解：** 已训练策略（SAC 与 EACC，1000–2000 步）在这些关键状态上"错失捕获"的决策只占约 5%（每次约 200 分）。
  - 截止窗口里 75% 的决策是所有候选都会超时（rally 轨迹已经错过时机）；
  - 其余决策只差燃料 / 时间。
- **校准信号的直接用处：** 在 critic 判错的捕获 / 超时对上不会判反，但纠正得很少。按"校准后捕获概率高 0.4"去改策略的动作，几乎不改变任何选择，因为现有策略本来就选能捕获的动作。
- **含义：** 在保留规划答案特征的接口下，训练好的 SAC 很少在捕获时机上犯错，反馈没有可补的空间。
