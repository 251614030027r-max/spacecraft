# 05 执行机会感知与协调（ECC）

ECC 处理理论问题：长期决策（学习的高层，每 16 s 一次）与短期受约束执行（执行层，0.1–2 s）之间的耦合。

**主线：** 执行机会感知 → 机会协调 → 真实执行 → SAC 价值学习。执行器对旋转窗口内可执行机会的预测同时服务两件事：

- 实际执行时，在"保持策略意图、修正意图、启动远场入口"三者之间协调；
- 学习时，价值学习的输入和目标都来自协调后的真实执行。

**要解决的失配：**

- 高层意图要经过执行层的规划、门限与跟踪才会兑现，而端口经过时能否转入入口，只有执行层在短时域内看得清；
- 只靠真实回报学习的高层，在机会稀缺时可能错过唯一的一次窗口。

## 5.1 执行机会集合

在决策状态 x（模式 S / H），执行器用自己的模型给出两类可执行机会：

- **短程机会**（阶段接近触发，第 5.2 节）：

  Ω_S(x) = { b ∈ 𝔅 ∪ {a} : ê(x, b) = 1，Δv_used + Δv̂(x, b) ≤ B_max }

  𝔅 为动作盒上的 3 × 3 网格 {−1, 0, 1}²；(ê, τ̂, Δv̂) 为 48 s 模式预测。
- **远场机会**（末次经过时的直接入口，第 5.3 节）：

  Ω_L(x) = { τ ∈ 𝒯_L : t + τ ≤ L，入口规划器从当前状态在到达时刻 τ 可行 }

  𝒯_L = {20, 30, …, 120, 140, …, 220} s；只在末次可用经过时评估（条件 κ(x) 见第 5.4 节）。

**关键窗口：** 短程机会 b 满足 t + τ̂(x, b) + P > L，即错过它，期限前不再有下一次经过（P 为自旋周期，L = T_d − 45 s）。可修正候选集为

  𝔅_c(x) = { b ∈ 𝔅 ∩ Ω_S(x) : t + τ̂(x, b) + P > L }。

**为什么需要两类机会：** 入口判定只在距离 ≤ 12 m、到达 ≤ 60 s 时尝试入口。若接近节奏使末次经过时仍在 12 m 外，或经过已近而 60 s 内的到达都不可行，短程机会就为空。远场机会用同一个入口规划器、更长的到达时刻，从当前距离直接规划入口，覆盖这种情形。

## 5.2 短程机会：模式预测

**问的是什么：** 在当前决策状态 x，对一个意图 b，执行层回答："如果接下来一直保持意图 b，自己会不会、在什么时候、花多少燃料离开阶段层，转入入口转移或末段下降？"

**怎么算：** 完全用执行层自己的规则与输入：

1. 从当前状态出发，按阶段层的规则（扫掠锥目标速度、阶段权限限幅、安全投影）与阶段规划器，逐阶段生成名义规划轨迹，至多 3 个阶段（H_p = 48 s）。规划被拒的阶段按原地保持处理；
2. 沿名义轨迹每 2 s 检查一次，与实际执行的规则相同：
   - 先查是否进入下降区；
   - 再查入口判定（距离、制动裕度、35° 夹角、到达不晚于 L）；
   - 对通过的到达时刻调用入口规划器，第一个可行者即为入口事件；
3. 目标姿态用恒速预报，惯量用估计值；
4. 预测在以下任一情形截止：达到预测时域、达到期限，或计划燃料用完剩余预算。

**输出：**

- ê(x, b) ∈ {0, 1}：是否发生模式事件；
- τ̂(x, b)：事件时刻，或预测截止的时刻；
- Δv̂(x, b)：到事件为止的阶段规划燃料，入口事件还要加上入口规划的燃料。

**它不是什么：**

- 不计算回报或价值，不对意图排序；
- 不使用历史数据，同一状态得到同一回答；
- 预测的事件是执行层模型下的模式切换，不等于捕获；
- 48 s 内无事件也不等于没有可行解。

**实现隔离：** 模式预测使用规划器的独立实例，不改变实际执行的求解器状态。有没有做这次预测，实际轨迹完全相同。

## 5.3 远场机会：长到达时刻的直接入口

- **规划：** 入口规划器（第 04 节，不改动）从当前相对状态出发，按 𝒯_L 中不晚于 L 的到达时刻从小到大尝试，第一个可行者即为远场入口。
- **执行：** 与普通入口转移相同，由近场 MPC 跟踪；跟踪偏离时按剩余时间重规划；丢失时转为保持，回到高层决策。
- **代价：** 只在末次可用经过、且没有其他可执行机会时才求解，计算量很小。

## 5.4 机会协调：一个机会集、一条规则

**最后机会：** 一个在时刻 t_e 发生的机会，若 t_e + P > L，即错过它在 L 前不再有下一次经过。

**关键机会集** O_c(x) = O_I(x) ∪ O_L(x)：
- O_I(x) = 𝔅_c(x)，即满足最后机会且燃料够用的短程机会（意图）；
- O_L(x)：处于末次可用经过（κ(x)：t_pass ≤ h 且 t + t_pass + P > L）且直接入口可行时，含这一个直接入口，否则为空。

**协调规则：**
1. ê(x, a) = 1：执行 a（保持）；
2. 否则在 O_c(x) 中执行对 a 改动最小的机会：
   - 意图 b 的改动为 ‖b − a‖，并列时取 τ̂ 小者，再按网格固定顺序；
   - 直接入口完全替换意图，改动视为大于任何意图，所以只在 O_I 为空时被选（到达时刻取 Ω_L 中最早者）；
3. O_c(x) 为空时执行 a。

等价的分支写法：

| 动作 | 条件 | 执行 |
|---|---|---|
| 保持 | ê(x, a) = 1 | a |
| 修正 | ê(x, a) = 0 且 O_I(x) ≠ ∅ | O_I(x) 中离 a 最近者 |
| 启动 | ê(x, a) = 0，O_I(x) = ∅，O_L(x) ≠ ∅ | 直接入口 |
| （其余） | — | a |

**实现与第一稿 ECC_LE 的执行逐位相同**（`evidence/R2_EQUIV/`：12 个回合、31 次协调决策，含 13 次修正、3 次直接入口）。

**开关**（用于归因，`docs/final_method/ROUND2.md` 第 2 节）：
- 关闭修正（只剩保持与直接入口）= 无核心；
- 关闭协调 = 无反馈（SAC–MPC）。

直接入口是协调的一部分，不单独做消融。副机制指 RWG（第 03 节），其检验见第 07 节。

**作用范围：** 只作用于当前这一次宏决策，不强制后续决策保持。

**性质（由定义直接得到）：**

1. **最小干预：** 策略意图在预测中能自己触发事件时总被保持；修正只发生在关键窗口；远场入口只在末次可用经过、且没有其他可执行机会时启动。接近节奏与相遇时机始终由策略决定。
2. **最小改动：** 发生修正时，执行意图满足有限候选集上的模型条件，且对原意图改动最小；距离相同时取事件更早者，再相同时按网格的固定顺序取，所以映射是确定的。
3. **保守扩展：** 与不含远场机会的协调相比，只在"按预测已无可执行机会的末次经过"多一个选项，其余状态的执行意图完全相同。
4. **判定不变：** 成功、安全与任务回报的判定不变，协调只决定执行哪个机会。

**准确性说明：**

- 预测的事件是执行层模型下的模式切换，不等于捕获。修正或启动之后，结局仍取决于真值中的兑现、后续决策和执行，所以协调不保证"从不伤害"，实验报告净效应与翻转数；
- 关键性条件是"机会稀缺"的时间代理，不是对所有后续可达状态的计算。

## 5.5 价值学习

- **算法：** 标准 SAC（第 06 节），在含协调的闭环上学习。记执行层的宏转移核为 P_ℰ，闭环核为 P_𝒞(x′, r | x, a) = P_ℰ(x′, r | x, 𝒞(x, a))。
- **数据：** 经验池存策略提出的 a，回报与后继来自协调后的真实执行；评价器学的是"提出 a 时闭环系统真实会发生什么"。执行器的预测只用于协调，不生成价值目标，也不改动 SAC 的损失。
- **部分可观与函数逼近：** Bellman 对象定义在完整状态 x 上；策略与评价器都只读 o，是部分可观下的函数逼近；采集为异步双进程、离策略回放；不主张无偏或收敛。

## 5.6 一次决策的完整流程

```
训练（每个采集进程）
  循环（每次高层决策）：
    a ~ π_θ(·|o)                                     # 策略只读 o
    若模式 ∈ {S, H}：
      对 𝔅 ∪ {a} 做 48 s 模式预测；按 5.4 决定保持 / 修正 / 启动
    执行：意图经 RWG（阶段目标 → 规划 / 跟踪 → 入口判定、入口规划与重定时 → MPC），
          或远场入口转移（入口规划 → MPC），直到宏步结束
    r ← 真实回报；r̃ ← r + γ_d Φ(x′) − Φ(x)
    存入 (o, a, r̃, o′, d)                               # 存提出的 a
    学习进程：每条转移 2 次 SAC 更新
执行（测试）
  a ← π_θ 的均值；同样的协调与执行
```

**方法总图（一张）：**

- 左：策略 π(a | o)；
- 中：执行机会集合与协调（读 48 s 模式预测，必要时求解远场入口），输出执行动作；
- 右：RWG 执行链与近场 MPC，作用于六自由度真值；
- 下方：真实转移回到经验池。

## 5.7 不主张

- 安全保证或捕获保证（安全只由真值判定）；
- 协调对连续动作最优，或"从不伤害"；
- 重定时必然提高捕获率；
- 部分可观下的价值估计无偏或收敛；
- 跨算法、跨任务的迁移性能。

**开发期试过、未纳入方法的做法：** 反事实价值标签、动作梯度修正、历史校准的机会图作为评价器输入、动作层证书作为评价器输入、带机会时刻承诺的最小干预调节器。它们都没有带来改进，见 `docs/DEAD_ENDS.md` D39–D45。
