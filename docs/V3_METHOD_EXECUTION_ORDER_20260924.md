## 0. 一句话与依据

**SAC 学一个长期任务策略；训练后分别学"学习策略一直走下去"和"Pure MPC 一直走下去"的长期价值；
开局选一个分支；在学习分支上，一旦 Pure MPC 有把握地更好就交回，交回后本回合不再切回。MPC 始终是唯一执行者。**

| 实测（精确 rollout） | 救回保住 | 基线完成丢失 | 产物 |
|---|---:|---:|---|
| 学习层偏离 2 s 后交回 Pure MPC | 0 / 9 | 0 / 18 | `eval/adp/v3_p1_p2_readout.json` |
| 学习层偏离 10 s 后交回 Pure MPC | 2 / 9 | 0 / 18 | 同上 |
| 两个策略各自继续，按价值选：开局（66 个新回合） | —— | **0 / 66** | `eval/adp/v3_p2prime_readout.json` |
| 同上：沿学习策略走到 k = 10 / 20 时再选 | **9 / 9、9 / 9** | —— | 同上 |

P2′ 验证的正是本执行单的两种判断：**开局选分支**、**沿学习策略走一段后决定是否交回**。
"Pure MPC 已经运行一段后再切回学习策略"**没有验证过**，所以第一版不做。

理论依据（现成定理）：按状态选择"自己继续下去价值更高"的策略，所得策略不劣于其中任何一个（Lu 2025 定理 1；广义策略改进）。
价值有误差时只写"误差受控条件下的有界退化"，**不写"高概率保证"**。

## 1. 组成

```
训练（与 V2 相比只换 T0 接口）： SAC，学习分支始终执行                    → π_L
训练后数据：                     π_L 全程回合 / Pure MPC 全程回合 / 交回探针 → M2
训练后价值：                     完整折扣回报的监督回归，各 5 头            → V_L、V_B
部署：                           开局选择 + 单向交回                        → 分支 → MPC
```

**同一组网络，仲裁关 = 修好接口的普通层级 SAC→MPC；仲裁开 = 完整方法。** 核心消融不需要重训。

## M1｜SAC 训练（与 V2 相同，只换接口）

- 参数化 `task_state_v3`（T0），训练时分支恒为 `learned`；
- 超参与 V2 完全相同：γ 0.99、`ent_coef` 0.005 固定、`n_critics` 2、网络、学习率、batch 都不改；
- 从零训练 60,000 决策 × 3 种子（262420 / 421 / 422）；manifest 记录 `parametrization=task_state_v3`；
- 这一步的产物同时就是"修好接口的普通层级 SAC→MPC"对照行。

## M2｜数据收集（训练后，每个模型分别收集）

训练种子块 **270000–270047**（48 个，与评估块 262000–262047、校准块 262100–262111 都不重叠）。每个种子跑 4 个回合：

| 回合 | 用途 |
|---|---|
| Pure MPC 全程 | V_B |
| π_L（确定性）全程 | V_L |
| 交回探针 × 2：π_L 跑到第 k 个决策，然后 `controller.reset()` 并交回 Pure MPC 到底；k 在 [0, 该种子 π_L 全程回合长度) 里均匀抽取，抽样种子固定并写入 manifest | V_B 在学习策略到过的状态上的数据 |

每个模型 192 回合，可并行（任务级数字与进程数无关，线程钉 1）。
逐决策记录：策略观测、分支、决策奖励（env 已在决策内求和）、`terminated`、`truncated`。

**为什么必须有交回探针**：P2 中学习策略暂存后交回，出现了硬约束失败和飞出。V_B 没见过这类状态就会高估，仲裁就会把系统交给一个接不住的 Pure MPC。

## M3｜价值：完整折扣回报的监督回归

环境确定、轨迹完整，每个状态之后的折扣回报可以直接算出来，所以**不用 TD，直接回归**：
```
G_t = Σ_{j≥t} 0.99^{j−t} · r_j        （决策级，算到回合结束）
V_L(s_t) ≈ G_t   只用 π_L 全程回合的状态
V_B(s_t) ≈ G_t   用 Pure MPC 全程回合的全部状态 + 交回探针中交回之后（含交回时刻）的状态
```
**交回探针中交回之前那段学习分支的状态，不能作为 V_L 的样本**：它们的 G_t 包含了后面的 Pure MPC 段，不是"学习策略一直走下去"的回报。

- 网络：每个价值 5 个独立 MLP（与 SAC critic 同宽），输入为策略观测，输出标量，MSE 损失；
- 集成的多样性：**按回合做自助采样（bootstrap）**（同一回合的状态高度相关，按状态采样会低估分散度），加上不同的随机初始化；
- 按种子留出 8 个做验证（270040–270047），报每个价值在留出集上的 MAE 与 R²；
- 奖励、γ 与 SAC 训练完全一致。

## M4｜仲裁：开局选择 + 单向交回（部署期）

```
μ_L, σ_L = V_L(s) 5 个头的均值与标准差
μ_B, σ_B = V_B(s) 5 个头的均值与标准差

第 0 个决策：   若 μ_L − z·σ_L > μ_B + z·σ_B → learned，否则 → baseline
在 learned 上：  若 μ_B − z·σ_B > μ_L + z·σ_L → 交回 baseline（controller.reset()），否则继续 learned
在 baseline 上： 本回合不再切回
```
- z = 1.0，是保守的工程判据，**不宣称概率含义**；
- learned 分支执行确定性动作 `π_L(s)`；
- 开局默认偏向 Pure MPC：学习策略必须有把握地更好才采用。交回同样要求 Pure MPC 有把握地更好，否则继续学习策略，防止在不确定的状态上贸然交回；
- 额外在线计算只有每 2 s 10 次小网络前向，**不增加 MPC 求解**；
- 每个决策记录 μ/σ 四个量与分支。

## M6｜校准检查（正式评估前，必须先过）

校准块 **262100–262111**（12 个种子），每个模型分别做：
- 跑 π_L 全程回合 1 次，得到 k = 0、10、20 处学习策略继续到底的真实回报（取回报到结束）；
- 在 k = 0、10、20 处各做一次交回 Pure MPC 到底，得到真实回报（沿用 `experiments/probe_base_policy_rollout.py` 的做法，学习段用模型）；
- 回合在 k 之前已结束的，跳过该检查点。

报告：
1. **总体**：`sign(μ_L − μ_B)` 与 `sign(G_L − G_B)` 的一致率、两个价值的 MAE、σ 与绝对误差的相关系数；
2. **关键状态**：两个分支真实结局不同（一个完成、一个没完成）的状态上，价值差的符号正确率；
3. **误选**：按 M4 规则实际做出的选择中，"选了失败分支、而另一分支本来能完成"的次数。

| 观测 | 动作 |
|---|---|
| 总体一致率 ≥ 80% | 进入 M5；第 2、3 项必须随结果一起上报 |
| < 80% | 停，报上层；不做正式评估 |

## M5｜正式评估（M6 通过后才跑）

评估块 262000–262047，每个模型两行：
- **learned-only**（仲裁关，即普通层级 SAC→MPC）；
- **arbitrated**（M4 规则）。

`experiments/evaluate_hybrid_policy.py` 增加 `--arbiter {off,one_way}`、`--learned-value <path>`、`--baseline-value <path>`。
每回合额外记录：逐决策分支与 μ/σ、是否开局选学习分支、交回时刻、学习分支占比。

## 6. 预注册判读（每个种子分别看，不合并）

**第一层：基线保护**（arbitrated 行）

| 指标 | 通过条件 |
|---|---|
| 完成 | ≥ 36/48 |
| destroyed | ≤ 2 |
| 真值违约 | 不多于 Pure MPC |
| 学习分支占比（回合平均） | ≥ 5%，否则记为 **coupling inactive**，不得解释为方法成功 |

**第二层：对 Pure MPC 的净改进**：`rescued > destroyed`。

| 结果 | 结论 |
|---|---|
| ≥ 2 个种子两层都过 | 方法成立：保住基线并有净改进 |
| ≥ 2 个种子只过第一层 | 仲裁保住了基线，但学习层没有带来净改进；如实写，不算主结论成立 |
| 其他 | 不成立，报上层 |

- 死种子（learned-only 为 0/48）：arbitrated 行应退回约 36/48，记为"仲裁保住了基线"，**不算学习层有效**；
- learned-only 行是普通层级对照，不设通过条件；
- 第三个种子如实报告，不丢弃。

## 7. 不做的事

- 不做 Pure MPC → 学习策略的二次切换（未验证，等正式结果出来再考虑）；
- 不做动作层残差 / β 分级（P2 已证明短偏离拿不到价值）；
- 不把 MPC 预测塞进价值（Q = M + D），不加干预惩罚、课程等机制；
- 不改奖励、MPC、任务参数。
