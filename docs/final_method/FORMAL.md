## 2. 预登记的报告量（正式实验不设采用判据，全部如实报告）

**主比较：** ECC 对 SAC–MPC 的捕获率配对差。
- 95% 区间用自助法：在每个种子内按初始条件重采样，10,000 次，随机种子 20261121；
- 同时报告逐种子差值与翻转数（仅一方捕获的任务数）。

**次要比较（同样方法）：**
- ECC 对 TD3–MPC、ECC 对 MPC；
- ECC 对 无核心；
- 无核心 对 SAC–MPC；
- ECC 对 ECC 关闭重定时；
- 固定意图带 / 不带旋转引导。

**每组报告：**
- 逐种子与合计的捕获、超时、不安全、燃料耗尽、平均真实回报；
- 双方都捕获的任务上，完成时间与 Δv 的中位差。

**安全：** 每个不安全回合列出此前是否有"下降"类修正（DEAD_ENDS O7）。

**学习曲线：** 训练回合按精确决策数排序（`episodes.json` 的 `steps` 字段，同 TensorBoard 横轴）。每 100 回合一个滑动窗口，给出捕获率与真实回报，按种子与三种子均值报告。

**闭环协同适应：**
- 训练中每回合的修正次数，与捕获率按同样窗口报告；
- 评估时协调动作的构成：保持 / 修正 / 启动直接入口 / 不动。

**分层：** 按期限（140–155、155–170、170–185、185–200 s）与初始自旋角速度（三等分）分层，报告捕获率。

**计算开销：** 每次协调决策的墙钟耗时（审计记录），给出中位数、95 分位与最大值，与 16 s 的决策周期对比；同时注明并行负载下的耗时不能作为实时性结论。

## 6. 分工与效率（执行书细化）

**原则：** 两台机器始终满载，主比较最先完成。

1. **第一批训练：** 每个运行 2 个采集进程，约占 2.3 个核。
   - 本机 4 个：`ECC` s30、s31、s32，`SAC_MPC` s30；
   - 云端 2 个：`SAC_MPC` s31、s32。
   - 这样主比较 ECC 对 SAC–MPC 在第一批全部完成。
2. **第二批训练：**
   - 本机 4 个：`ECC_NO_CORE` s30、s31、s32，`TD3_MPC` s30；
   - 云端 2 个：`TD3_MPC` s31、s32。
3. **空闲核：** 非学习策略（`pure`、`c_10_0`、`b_10`）不需要模型，从第一批开始就在空闲核上跑。
4. **评估：** 每个模型训练完，在训练它的机器上立即评估；ECC 模型同时做 `rigid_entry` 评估。
5. **案例重放：** 在 ECC s30 与 SAC_MPC s30 所在的本机进行。
6. **核数不同时：** 下层按"训练优先、空闲核跑评估与非学习"自行调整，不改设置。

## 8. 修订（2026-11-21，开跑前）：分工按整组；开跑前的短检查只影响 ECC

**分工（用户建议：一台机器负责完整的组）：**
- **云端：** `SAC_MPC`、`TD3_MPC` 各 3 个种子（6 个运行），按云端可并行数排队；
- **本机：** `ECC_NO_CORE` 3 个种子先开；`ECC` 3 个种子在短检查定案后开；非学习策略用空闲核；
- **评估：** 每台机器评估自己的模型。案例重放也分开：ECC 在本机，SAC–MPC 在云端，用同一组初始条件。

**短检查：细格机会（只影响 `ECC`，其余组照常开跑）。**

- **动机：** 远场入口是对机会集合的保守扩展。它最先在已有模型上做了只评估的配对检验，后来在正式实验中稳定带来 +5.2 个百分点。细格是同类的下一步。
- **定义（开关 `extended_lattice`，默认关闭）：** 在最后机会状态上，若原意图接不上、3×3 格点没有关键机会、直接入口也不可用（当前规则在这里什么都不做），再评估 5×5 格点 {−1, −0.5, 0, 0.5, 1}² 中其余 16 个意图，按同样的关键性条件，执行离原意图最近者。其他状态的执行与现有 ECC 完全相同，属于保守扩展。
- **检验：**
  - 开发轮已训练的 3 个 `ECC` 模型（种子 0、1、2，3000 步），在 192 个开发初始条件上只评估 `extended_lattice`；
  - 与这些模型已有的结果配对（同一模型、同一初始条件），不训练，约 1 小时。
- **采用判据（预先登记）：**
  1. 捕获(细格) ≥ 捕获(现有) + 5（576 个中）；
  2. 只有细格捕获的任务数 ≥ 2 × 只有现有规则捕获的任务数；
  3. 不安全(细格) ≤ 不安全(现有) + 1。
- **结论：**
  - 通过：正式实验的 ECC 开启 `extended_lattice`（配置 `ECC` 改为开启，训练与评估同开）；
  - 未通过：正式 ECC 不变。
  - 两种情况下，其余组都不受影响。
- 判定由 `experiments/r2_dev_readout.py paired` 给出。
