## 1. 要回答的问题

B1/B2 已经证明，在冻结的 60k 策略上，"在对的时刻把控制权交给 Pure MPC"在 262000 块的每条轨迹上都存在。所以本阶段只回答一件事：

> **能否只根据当前状态，实时识别"现在交给 Pure MPC 能干净完成"？**

不回答的问题：不训练 SAC，不改接口、奖励、任务和 Pure MPC，不比较网络结构，不补第三轮数据。

## 2. 方法（只此一个定义）

**估计对象**：

  p_M(s) = P( Pure MPC 从状态 s 接管并一直飞到底，结果为干净完成 | s )

干净完成 = 完成，且全回合真值违规步数为 0。仿真是确定性的，所以真实标签是 0/1；p_M 表达的是估计器对没见过的状态有多大把握。

**在线规则**：在学习分支上，每个决策点计算 p_M(s)。第一次满足 p_M(s) ≥ τ 时交给 Pure MPC，此后一直由 Pure MPC 飞（单向，切换时重置 MPC，与 M2/M5/B 阶段相同）；否则继续学习策略。第 0 步就满足，等价于 Pure MPC 从开局起飞。

**不确定时继续学习策略**。这一条取代 09-30 记录的"不确定时倾向交接"。理由：
- 那条规则针对的是旧的两个长期价值相比较；
- 新规则里两种错误的代价不对称：
  - 误交接（以为能接住、其实接不住）不可逆，B2 显示 46/113 条成功轨迹上存在这种时刻；
  - 晚交接只是推迟，B1 显示 30/31 条失败轨迹的可救时段至少连续 4 s，硬失败前中位还有约 30 s。

论文中的表述是"学习识别 Pure MPC 的可接管区域（一种最优停止型的交接决策）"，不宣称求解了一般的最优停止问题。

## 4. 拟合（C2，一轮）

| 项 | 冻结值 |
|---|---|
| 模型 | 5 个小 MLP 的平均（31 → 64 → 64 → 1，tanh），种子 0–4 |
| 训练 | 输入标准化；按轨迹加权的二元交叉熵；Adam，学习率 1e-3，权重衰减 1e-4；全批量 400 轮；单线程 |
| 交叉验证 | 6 折，**按开局分组**：fold = (seed − 262000) mod 6。同一开局在三个模型下的全部状态必在同一折 |
| τ 的规则 | 在网格 {0.50, 0.55, …, 0.95, 0.97, 0.99} 上，取**最小的** τ，使折外预测中 p ≥ τ 的状态的**加权精度 ≥ 0.95**（即触发交接的状态里，加权后至少 95% 真能接住） |
| C2 判定 | 找到 τ，判为 `TAU_FOUND`，进入 C3；找不到，判为 `C_STOP`，不做 C3 |
| 最终判断器 | 用全部带标签状态、同样设置重新训练，附上 τ，存为 `handoff_classifier.pt`，并登记 SHA-256 |

**报告但不作门槛**：
- 折外加权 AUC 和精度曲线；
- 折外的"第一次触发"分析，这是最贴近实际使用的读数：
  - 失败轨迹（逐决策标签，结果确切）：第一次触发时救回 / 第一次触发就交接失败 / 从未触发；
  - 成功轨迹：从未触发（保住）/ 触发在有标签的点上（干净或毁掉）/ 触发在无标签的点上（结局未知）。

## 5. 闭环验证（C3）

| 项 | 内容 |
|---|---|
| 开局块 | **266000–266047**（全新，未在任何设计中用过） |
| 行 | Pure MPC（一次，与模型无关）；每个模型的学习策略单独跑；每个模型的"学习策略 + 判断器"（混合） |
| 判断器 | C2 的最终判断器，三个模型共用同一个文件 |
| 环境 | 主线配置，与 B 阶段同一条路径（`step_with_branch`） |

**每个模型的通过条件**（三条同时满足）：
1. 混合行干净完成数 **>** Pure MPC 干净完成数；
2. 混合行真值违规回合数 **≤** Pure MPC 真值违规回合数；
3. 被毁掉的 Pure 成功开局（Pure 干净完成、混合行没有）**≤ 2**。

**总判定**：
- `FIDELITY_FAIL`：结果文件不全、提交不一致、工作树不干净，或用了不同的判断器 / 模型文件；
- `C_STOP`：通过的模型少于 2 个。判断器识别不了交接时刻：停止，不加风险判断器、安全集等模块，也**不用 D 来掩盖**；
- 至少 2 个模型通过后，看效率。取三行（Pure、学习策略单独、混合）都干净完成的开局，开局数 ≥ 5 才计算：
  - 混合行相对 Pure 多用的时间（中位数）**≤** 学习策略单独跑多用时间的一半（若后者 ≤ 0，则要求 ≤ 0）；
  - 混合行相对 Pure 多用的 Δv（中位数），按同样规则。
- `A_GO_TO_E`：至少 2 个通过的模型同时满足效率条件，即至少消掉了一半"该交没交"造成的额外代价。跳过 D，进入 E；
- `B_GO_TO_D`：协调成立，但效率仍不达标。进入 D（只改接口，奖励只在有证据时才动），再进入 E。

**同时报告**：救回 / 毁掉的开局、交接时刻分布、从未交接的回合数、学习策略占比，以及共同完成开局上三行的时间和 Δv。

## 6. 证据分级与边界

- 判断器的训练、τ 的选择都只用了 262000 块；C3 用全新的 266000 块，但仍是开发验证。**论文数字全部来自 E**：全新训练种子、全新的 267000 块、在新块上重跑 Pure MPC。
- "违规回合 ≤ Pure"在 48 个开局上很严格：Pure 若为 0，混合行出现 1 次就不通过。这是事先接受的标准，事后不放宽。
- τ 是在 262000 块上按规则选出的，不在 C3 之后调整；三个模型共用同一个 τ。
