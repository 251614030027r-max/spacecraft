# 论文资料

写论文时从这里取事实，文字按论文写法另写。名称与符号以 `facts/00_术语与符号.md` 为准。

| 文件 | 用于 |
|---|---|
| `BACKGROUND.md` | 引言：背景、两个问题、贡献、研究问题 |
| `facts/00`–`07` | 方法：术语符号 → 问题与建模 → 总体框架 → RWG → 执行层 → ECC → 学习 → 对比方法 |
| `facts/08_实验结果.md` | 实验的全部数字；作图数据在 `evidence/R2_FORMAL/`（第二轮正式实验） |
| `facts/工程附注.md` | 代码位置、配置名、实现细节、旧名对照、开发期数据。**不进论文正文**，复现说明或附录需要时取 |
| `latex/` | 论文 LaTeX（IEEE TAES 模板），编译见 `latex/README.md` |
| `References/README.md`（仓库根目录） | 每篇参考文献用来做什么 |

**取材原则：**
- 论文靠方法图、轨迹图和结果表讲故事。事实稿里的数字是"可以用"，不是"都要写"。
- 论文中不出现配置名、文件路径、提交号、开发过程，也不出现"冻结""逐位等价"这类工程说法。
- 实验数字只取 `facts/08`；第一稿（第一轮）的数字在 `docs/archive/facts/`，不混用。
