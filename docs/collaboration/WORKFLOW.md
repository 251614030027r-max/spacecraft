# 协作纪律摘要（2026-11-12）

三层的职责、共同红线与各自纪律以 [HANDOFF.md](HANDOFF.md) 第 4 节为准；本页只保留工作链。

**工作链：** 研究层（用户 + 讨论窗口）决定方法与授权 → 上层实现、必要测试并冻结科学 SHA，写可直接执行到交付的执行书 → 下层在本机按书执行、交付原始数据 → 上层集中审查 → 研究层决定下一步。没有明确 GO，不自动启动训练。

1. **版本与授权：** 用户最新授权与有效执行书优先；"已批准"只能由用户给出。PROJECT_STATE 由上层维护，CURRENT 由下层维护。
2. **停止与结果：** 停止规则只按当轮执行书；预注册判据事后不改；所有检查点与失败样本如实交付。
3. **仓库：** `collab/spacecraft` 只改 `docs/collaboration/`；实验只用冻结的科学 SHA；提交前 fetch，禁止强推；Git 只记事实，不记讨论。
