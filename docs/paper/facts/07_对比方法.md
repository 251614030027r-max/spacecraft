# 07 对比方法：各自改动了什么

所有学习方法共用同一执行层（RWG、规划器、MPC）、同一策略观测、同一动作空间、同一训练设置与交互预算（5000 次决策 × 3 个种子），只在下表列出的地方不同。

| 方法 | 评价器读 z | 机会协调 | 学习算法 |
|---|---|---|---|
| **ECC（本文）** | 是 | 保持 / 修正 / 启动远场入口 | SAC |
| ECC w/o long-range entry | 是 | 保持 / 修正（没有远场机会） | SAC |
| ECC w/o execution inputs | 否 | 保持 / 修正 / 启动 | SAC |
| ECC w/o coordination | 是 | 无（始终执行策略意图） | SAC |
| SAC–MPC | 否 | 无 | SAC |
| TD3–MPC | 否 | 无 | TD3 |

- **主对比：** ECC 对 SAC–MPC、TD3–MPC。
- **机制拆解：** 沿"无协调 → 保持 / 修正 → 加远场入口"逐级加入协调，对应 ECC w/o coordination → ECC w/o long-range entry → ECC。ECC w/o execution inputs 检验评价器输入 z。
- **RWG 部件：**
  - 入口重定时：同一个"ECC w/o long-range entry"模型关闭重定时，属于正式数据；
  - 旋转引导：开发期固定意图的对比（带与不带旋转引导的同一接近意图）。
- **参考线：** 纯 MPC、固定意图 (1, 0)、截止规则、直接入口规划，来自开发期紧急筛查，是另一组 48 个初始条件，单独成表。
