## 4. 推断（依据如上；待 learned 行与 4.8 重放核实）

1. **学习继续分支是主要短板，不是停止判据。**
   - 依据：价值估计的区分度比上一轮明显提高（第 3 节）；
   - 但在 Pure 失败的开局上，学习分支的继续价值同样很低；
   - nominal 作为继续分支能完成全部 13 个；训练期学习策略单飞的完成率也没有提高（DEAD_ENDS O1）。
   - learned 行交付后，可以直接核实学习策略单飞在这些开局上的表现。
2. **早交接的决策落在接近相等的估计上**，对小的价值误差很敏感。4.8 的 ε_H、ε_C 实测可以给出误差量级。
3. **交接状态不一定能被 Pure 安全接管**（262460 的两次视场违规），而 Q_H 没有把这一点区分出来。只有 1 个模型、2 个开局，是否是普遍现象未知。
4. **跨种子差异大**：262460 和 262462 的交接分布与安全结果都不同。
