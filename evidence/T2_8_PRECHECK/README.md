# T2_8_PRECHECK：执行层安全缺口的定位与修复验证（沙箱，探索性）

**缺陷（科学 `be596d9` 修复，环境 t2-stage-0.6.0）：** 阶段层生成阶段目标时只限制单段速度变化，不按真值判据约束接近速度与终止距离。T2.6W、T2.6W1、T2.7 评估中的全部 8 次 unsafe 都可由记录的动作序列在冻结代码 `2208a51` 上原样复现，均为刀口式越界（0.000–0.004）：

| 违反项 | 次数 | 情形 |
|---|---|---|
| 径向制动包络 | 3 | 7.5–7.7 m，锥外，以约 0.18 m/s 逼近（7.6 m 处包络 0.179 m/s，动作空间允许 0.20） |
| 口部总速度 | 4 | 6.3–6.5 m，锥内，阶段飘入口部带，与旋转端口不同步（未经入口规划） |
| 视场 | 1 | 下降段 |

**修复：** `stage_goal(..., task)` 把阶段末投影到安全集合——终止距离不小于 6.8 m（操作球 6 m + 口部带 0.5 m + 0.3 m，操作球只由入口 / 下降即 MPC 进入），径向接近速度不超过阶段末距离处的制动包络减 0.02 m/s（入口规则的余量）；只减小向内的径向分量。执行器所有调用（实际阶段、候选模型、第二阶段、执行器意图）都用它，对所有臂与固定规则相同；纯 MPC 与下降段不变。

**验证：**
- `记录/unsafe_replay_before_fix_2208a51.jsonl` → `记录/unsafe_replay_after_fix.jsonl`：8 个动作序列在修复后全部以超时结束、无违规（这些开局本身捕获不了）。
- `记录/safety_screen*`：19 个紧急审计开局，跟踪执行器规划 19/19、c_10_5 17/19、c_10_0 15/19（修复前 16/19）、rally 9/19，均无 unsafe。

修复改变了所有臂共用的执行器：之后的 SAC 必须重新训练，历史 SAC 结果不再复用。

## 2. 预检 P1 / P2：关键状态的真值与反馈（`脚本/keystate_probe.py`、`脚本/p12.py`，`keystates/`，`记录/keystates_P12.txt`）

**做法（沙箱，探索性，执行器代码 `be596d9`（环境 0.6.0）；容器重启后自 2910027 起在 `f428c54a` 上续跑，真值积分与之前逐位相同）：**
- 审计开局 2,910,000–2,910,039 中的 19 个紧急任务（截止 U(140, 200) s），用规则 rally（hold 7.5 m）飞行。
- 关键决策：离截止 40–140 s，加上开局头两步，共 86 个。
- 每个关键决策从快照出发，对 3 × 3 意图网格（p ∈ {−0.5, 0.25, 1.0}，z ∈ {−1, 0, 1}）分别做两件事：
  - 真值：该意图保持至多 4 段（64 s），入口则飞到结束；
  - 模型：执行器模型给出生产用第一段标签，再接一段同规则的第二段（与 T2_7_PRECHECK 第 2 节相同）。
- `keystates/*.json` 存每个决策的观测 `obs`、候选及其真值，供检查点打分（`experiments/t2_keyscore.py`）。`输入/CAL.json` 与 T2_7_PRECHECK 相同。

**结果：**

| 项 | 读数 | 预检条件 | 判定 |
|---|---|---|---|
| P1 真值有差别 | 39/86（45%）的决策中，9 个意图的真值结局不同（捕获对超时，或回报差 ≥ 50），常见是只有一部分意图能捕获 | ≥ 20% | 过 |
| P2 反馈不颠倒 | 回报差 ≥ 50 的候选对：模型判对 299、判错 3、几乎同值（差 < 5）290 | 判对 ≥ 2 × 判错 | 过 |
| 投影是否压平动作 | 9 个意图阶段末位置两两距离：中位 1.14 m；每个决策最近一对中位 0.18 m（P10 0.03 m） | 只报告 | 没有整体压平，但相邻意图常常接近 |

- **同值对的含义：** 两段模型看不到第 3–4 段才分出的捕获，这部分信息只能靠 critic 的自举接上。
- **局限：** 模型的第二段沿用 T2_7_PRECHECK 的链式规则，阶段目标没有经过安全投影（生产用第一段经过了投影）；真值的续飞是"保持意图"，不是策略续飞。
- rally 在本探针中捕获 11/19，与安全筛查的 9/19 不同：本探针开启了标签计算（`candidates=8`），候选抽样占用环境随机数，两次飞行并不相同。
