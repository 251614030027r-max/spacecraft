β = 0 也用探针运行，因为后续比较需要它的已采纳计划和重规划原因。它同时与本机 `logs/t1/_v2/rule_local` 逐位核对，相当于在下层机器上再做一次 B0 第 1 项。

```

python -B -m diagnostics.t1_beta.beta_probe --beta 3   --openings <B1> --output-dir logs/t1/_beta/b1 --workers 8
```

**判据**（由上层执行 `diagnostics.t1_beta.analyze_beta` 判定）：

- **安全：** 相对同开局 β = 0，任一 β 只要新增以下任一项即被否决：
  - 真实任务失败（unsafe 或超时）；
  - 数值失败；
  - 最终规划失败：某个决策结束时没有任何可用计划，即 G★ 进入保持状态；
  - 求解器异常。

  G★ 正常搜索（最早可行网格、滑移）中候选不可行的次数**只报告、不否决**。真值最小裕度同时给出绝对值和差值；基准接近 0 或跨越正负时不用百分比，逐项核查。
- **作用：** 某个 β 在至少 4/8 个开局上同时满足以下两条，才算"起作用"：
  - 首个已采纳计划在同一时刻的最大位置差 > 0.1 m；
  - 全程 Δv 差 > 0.02 m/s。

  所有安全的 β 都不起作用，判 **NO-GO**。
- **只报告、不作门槛：** 远场重规划次数（按原因）、远场 Δv、首个计划 τ 的变化、滑移与保持。
- **在 B1 上冻结：**
  - 最佳固定 β：4 个取值（含 0）中 8 开局平均回报最高者；
  - 开局状态规则：形式为"若 x_f ≤ 阈值 取 β_低，否则取 β_高"；f 取自初始观测的 6 个预登记特征（range、rho_perp、port_los、port_latitude、ω、fov_margin）；阈值取 B1 相邻值的中点；以 B1 平均回报最高者为准。若任何规则都不优于最佳固定 β，状态规则就退化为该固定值。

  两项都在 B2 运行前写入 `frozen_on_b1`，之后不再改动。
