## 1. 先做：停掉当前训练

262100 跑了 18,680 步 / 396 局 / 约 10 小时，**是一条平线**：

| | 前 100 局 | 后 100 局 |
|---|---:|---:|
| reward | −27.00 | −27.74 |
| ep_len | 48.0 | 49.9 |
| completed | 0 | 0 |
| latched | 0 | 0 |

400 局之后的行为，和 buffer 还在灌随机动作时**一模一样**。按预先定的判据：停。
**不是训练时长问题，再跑 31 小时结果相同。**

## 2. 原因：动作空间不可学（这是上层的设计错误）

reward 拆得很干净：1020 个控制步的时间惩罚 −10、失败事件 −20、推力 −4、shaping +7 ≈ −27。
局长 48 远小于上限 150 → **不是超时，是提前被推出去**。
（另：safety_penalty 是每控制步 −1.0 且不乘时间步，若在蹭约束总分会是几百负；
现在 −27，说明**约束根本没被蹭到**，就是单纯飞走了。）

按均匀采样统计原动作空间：

| 原 `absolute` 空间 | |
|---|---:|
| 命令 >15 m（往外、背离目标） | **69.8%** |
| 命令 6 m 以内任何点 | 1.94% |
| 落在目标位姿 3 m 内 | 0.24% |
| 落在 1 m 内 | 0.0055% |
| 中位数命令半径 | 17.7 m（起点才 16–17 m） |

**七成的探索决策把追踪星推出这一局，有用指令的测度接近零。**没有梯度可跟，
因为没有值得跟的经验。这是我把动作箱按"要够到 17–20 m 起点"来定，却从没数过
里面有多少是可行指令。

## 3. 替换：`radial_local`

同一种对象——**目标体系里的绝对航点，仍然不是位移，对 MPC 的接口仍是那个 3D 航点**——
只是改用"以当前位置为原点"的坐标来命名：
1 个径向分量（±1 把命令半径乘 `exp(±0.7)`，约 ×2 / ÷2）+ 3 个横向微调分量
（投影到垂直于当前方向的平面，满量程约 41°）。**动作 4 维，航点仍 3 维。**

| 均匀采样 | `radial_local` | `absolute` |
|---|---:|---:|
| 命令向内 | **49.9%** | 30.2% |
| 中位数命令半径 | **等于当前半径** | 17.7 m |
| 每决策横向偏转中位数 | 21.8° | — |

零动作 = 追踪星自己当前的目标系点，也就是**共旋保持**；
而真正能打开窗口的**惯性冻结保持**，只是抵消 `ω·2s = 4.7°` 的一个小横向偏置——随手可及。

**要说清楚：这个参数化偏向"保持"。**我不藏着——另一个偏向是 70% 往外飞，已实测致命。
横向平面不选基底（直接对当前方向做投影），所以动作的小变化永远对应航点的小变化，
不会在某个切换面上翻转含义。

## 4. 新空间的实测价值——**比我上一版说的差，如实报**

12 种子，脚本控制走新参数化：

| | 完成 | 平均时间 |
|---|---:|---:|
| `desired_pose`（无窗口决策） | **8/12** | **99.9 s** |
| 逐种子扫描入口时机 | **10/12** | — |

- 基线完成数仍是 8/12，但**失败种子集变了**（262003 现在能完成，262001 不能了），
  平均完成时间从约 124 s 降到 **99.9 s**——因为"每决策按有界倍率收缩半径"
  比"一个很远的固定设定点"是更好条件的参考。
- **天花板从 11/12 降到 10/12**：262005（60 s 提交）、262011（20 s 提交）被救回；
  **262001 和 262006 靠单独选入口时机在这个网格上救不回来。**

**所以耦合方法要打败的目标变成：8/12，平均 99.9 s；单标量天花板 10/12。**
上一版报的 11/12 属于 `absolute` 参数化，那个参数化已被证明不可学，该数字不再是现行目标。

有一点这个天花板管不着：扫描只动一个标量，而策略每 2 秒有 4 个自由度、
还能横向操舵。262001 和 262006 也许正是要靠这个。**10/12 是手写决策的上限，不是动作空间的上限。**
