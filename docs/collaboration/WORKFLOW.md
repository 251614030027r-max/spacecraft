# 协作纪律（2026-10-18）

**三窗口的职责、共同红线与各自的执行纪律已统一写入 [HANDOFF.md](HANDOFF.md) 第 7 节，以那里为准。** 本文件只保留工作链摘要，供快速查阅。

**工作链：** 研究层（用户 + 协作窗口）决定方法与授权 → 上层实现、必要测试并冻结科学 SHA，写可直接执行到交付的执行单 → 下层在本机按单执行、交付原始数据 → 上层集中审查 → 研究层决定下一步。没有明确 GO，不自动启动训练。

1. **版本与授权。** 用户最新授权与有效执行单优先；任何"已批准"字段都不能扩大授权。PROJECT_STATE 由上层维护，CURRENT 由下层维护。
2. **准入从简。** 训练前只排除会让实验无效的问题（程序或数值错误、动作或物理不生效、不可追溯的配置、明显不公平的对照）；学习收益与收敛交给真实训练。已通过的检查直接复用。
3. **停止与结果。** 停止规则只按当轮执行单；FAIL 即停，原判定原样保留，不改阈值、不追加候选、不换开局。所有检查点与失败样本如实交付。
4. **仓库。** `collab/spacecraft` 只改 `docs/collaboration/`，不从它运行科学代码；实验只用冻结的科学 SHA；提交前 fetch，禁止强推；Git 只记事实，不记讨论。
