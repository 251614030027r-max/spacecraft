# 旧文件说明

本目录保存历史资料：旧论文复现/基线文档、选定审查证据、一个早期参考模型、从活动`models/`迁出的失败模型和非代表checkpoint，以及从活动`logs/`迁出的早期Phase-I完整日志。它们不属于当前活动基线，不参与Python import，旧模型也不保证能由当前canonical入口直接加载。

保留内容为`documents/`中的复现规范与偏差记录、`reference_baseline_evidence/`中的选定manifest/evaluation、`reference_model/sac_reference_20260817_200k.zip`、`model_history/`中的历史模型资产，以及`log_history/`中的早期完整日志。重复的`old_source/`代码快照已由活动源码、规范文档和选定证据取代并删除。
