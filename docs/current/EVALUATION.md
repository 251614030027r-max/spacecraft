# 评估与准入协议（2026-10-18）

本线的做法：先证明任务存在可学习的状态相关决策价值，再训练。所有判据、候选和开局都在第一个相关回合之前提交冻结，失败结果原样保留，不事后改阈值。

## 1. 通用规则

- **安全裁判：** 真值 RK45 几何是唯一的安全裁判。
- **评估方式：** 确定性评估；每个回合独立，可按回合并行，结果与串行逐值一致。
- **回报重算：** 燃耗权重通过逐步 Δv 精确重算，同一物理轨迹不必为不同 λ_f 重跑。
- **快照分叉：** 两个分支从同一快照出发，并新建求解器（`CounterfactualPredictor.sync(fresh_solvers=True)`），两分支逐位一致。与长程原轨迹之差（1e-8 至 6e-4）记为数值重复性；只有远大于该误差的差别才算真实作用。
- **配对统计：** 逐开局配对差，报告均值、sd、95% t 区间、更好 / 更差计数。
- **样本属性：** 16 / 32 / 64 开局只改善同一种子上的分辨力，不代表跨训练种子的稳定性。
