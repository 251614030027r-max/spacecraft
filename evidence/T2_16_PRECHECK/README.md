## 学习器 6.2（2026-11-04，A 审计数据暴露的问题）

**发现**（`evidence/T2_16_PI/A/RUNS`，137 个分叉决策）：执行器斜率 g 多半与 critic 动作梯度 gq 反向（夹角余弦中位数 −0.84，|g|/|gq| 中位数 0.98）。6.1 的修正后更新 gq + g_c 方向是真值偏好的方向（A 通过），但长度中位数只剩 |gq| 的 0.61，40% 的决策不到一半。A 比较的是等长的步，没有检验这种缩短；训练中它会削弱策略在最近状态上的学习。
