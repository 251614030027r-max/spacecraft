# T2_13_PRECHECK：EACC 迭代（学习器 4.1、环境 0.11.0）训练前测量与自检（沙箱，探索性）

**代码：** 科学 `0de3dd4`，77 项测试。研究层 11-03 建议书提出的问题：受约束执行是否把不同意图投影成同一执行；时长 / 终止语义是否一致。

## 1. 意图被执行器投影到同一执行的程度（`脚本/alias_probe.py` → `输出/alias_probe_OUTPUT.json`）

**做法：** 10 个紧急训练段开局，共 88 个决策，随机意图（相当于训练早期）。阶段目标（投影、限速后的阶段末速度）唯一决定执行器的阶段计划。

| 读数 | 值 |
|---|---|
| T2.11 / a3f4c65 候选生成器：候选与已执行意图的阶段目标 < 0.005 / 0.01 / 0.02 m/s | 1.8% / 4.3% / 12.1% |
| 候选两两 < 0.005 / 0.01 / 0.02 m/s | 0.7% / 2.5% / 7.4% |
| 至少一个候选与已执行意图 < 0.005 m/s 的决策 | 12.5% |
| 候选触发速率限制 / 安全投影 | 37.5% / 7.5% |
| 21 × 21 意图网格上，相距 ≥ 0.5 的意图对阶段目标 < 0.005 m/s | 0.06%（6–8 m 处 0.12%） |
| 非终止阶段中不足 16 s 的（偏离保持提前结束） | 0 / 78 |

**结论：**
- 投影基本是单射：速率限制只改速度增量的大小，不合并方向；安全投影只在少数边界状态合并径向分量；
- 不需要构造执行等价类，只需去掉模型分辨不了的比较；
- 所有自举的转移都是完整的 16 s 阶段，按决策折扣与按时长折扣一致。

## 2. 新代码的端到端自检（`脚本/selfcheck_iter.py` → `输出/selfcheck_iter_OUTPUT.json`、`selfcheck_iter.log`）

**做法：** 同开局、同动作，40 个决策，T2.11 `e_acc` 环境与新 `e_rel` 环境（候选间隔 0.01 m/s、共同随机数）对比。

**结果：**
- 两臂都有 37 个带标签的决策、296 个候选；
- `e_rel` 为满足间隔共重抽 79 次（每个候选平均 0.27 次）。只算阶段目标，不解规划；
- 每决策耗时：e_acc 9.6 s，e_rel 8.4 s；
- 新学习器 300 次更新：
  - 候选价值差均值 0.024σ，上一版（独立抽样，`T2_12_PRECHECK`）为 0.045σ；模型项残差 63 → 18，上一版 137 → 73；
  - 同一开局和动作下，约一半的"差值"原来是末端估值的抽样噪声，共同随机数把它去掉了。critic 还没训练，这只是方向性读数；
- 权重均值 0.999，跨类对占 0.3–0.9%。
