# 无效观测误差网格：姿态偏置错误旋转惯性速度

本目录的 36 份 JSON 由错误版本的观测误差注入生成。该版本在施加目标姿态偏置时同时旋转了目标惯性速度，从约 7.6 km/s 的轨道速度中注入数量级为 m/s 的虚假相对速度，导致推力饱和和 `total_speed` 违约。

这些文件保留用于审计错误如何产生，但不得用于支持“姿态偏置击穿 MPC”“偏置不可滤”或 hybrid 缺口等性能主张。无偏置 `e0` 文件虽然不受该机制直接影响，但属于同一无效网格，作为对照一并隔离。

正确实现位于 `env/observation_error.py::TargetStateEstimator._biased`：只改变姿态估计，保持惯性位置、速度和角速度不变。修正后的结论见 `docs/PROBE_RESULTS.md`。
