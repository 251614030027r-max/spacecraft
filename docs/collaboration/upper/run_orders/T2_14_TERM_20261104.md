## 为什么有这一轮（T2.12 中期事实）

T2.12 第 1000 步（下层中期报告，训练记录口径）：

| 臂 | 250–1000 步曲线 AUC | 500–1000 步真实回报 |
|---|---|---|
| 特权 critic、无反事实反馈 `e_priv` | 14.86 | 33.63 |
| T2.11 EACC-A | 12.05 | 19.80 |
| 相对反事实标签 `e_rel` | −5.74 | 14.43 |
| 同接口 SAC | −13.92 | −0.08 |

- **增益来自训练期读执行器判断的 critic。** 反事实标签（旧的绝对标签、新的相对标签）都没有在它之上带来增量，新版还拖后腿。
- **上层诊断：** `e_rel` 的标签里大部分是阶段末行，其价值是 critic 自己在"执行器模型预测出来、critic 从没训练过的状态"上的估值。模型把 critic 的外推误差包装成"换个意图更好"的信号还给 critic，策略随之被拉偏。

## 方法：EACC，只用执行器能独立算完的反事实

- **只保留终局候选：** 执行器模型能把它一直推到终局事件的候选意图——打开入口并按历史回放算到捕获 / 超时，或到截止 / 预算终止。
- **目标是常数，不读 critic：**
  - 第一段内终局：Y_j = 模型给出的到终局的回报；
  - 第二段内终局（仅 `e_term2`，第二段用策略的确定性意图）：Y_j = r̂_1 + γ·r̂_2；
  - 若已执行意图的同一处理预测也是同类终局，再减去模型在已执行结果上的误差：T_j = Y_j + (y_f − Y_f)。
- **其余候选（只到阶段末）不出标签：** 它们的价值只能来自 critic 的外推。
- **可信度：** 同一条柯西规则。
- **理论：** 没有任何目标在模型状态上自举，融合回归在表格情形下仍是 γ-收缩。
- **不变的部分：** 特权 critic、执行锚定（M2）、入口回放、截止终止、候选按执行器阶段目标间隔抽取。执行器、观测、奖励、场景都不变。
