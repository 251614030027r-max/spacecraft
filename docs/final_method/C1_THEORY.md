# C1 理论：旋转扫掠锥的有限时间入口机会集与窗口承诺

> **非最终论文算法（2026-11-10）：** 本文件是研发记录。论文方法以 `docs/paper/METHOD.md` 为唯一源，对照见 `docs/paper/FACT_MAP.md`。

记号与 `env/t2_stage.py: spin_frame` 一致：
- ŝ：自旋轴；β：端口相对自旋轴的锥半角；λ：视线极角；Δλ = λ − β：纬向误差；
- φ：端口到达视线所在子午面还需扫过的相位；ω：自旋角速度（2.1–2.7 °/s）。

预报采用恒角速度模型，与执行器、观测相同（`observe` 中的 `port_at`）。

## T3｜扫掠锥入口机会集

**角距公式。** 端口在锥面上匀速转动，τ 秒后端口与视线的夹角 θ(τ) 满足

  cos θ(τ) = cos λ cos β + sin λ sin β cos(φ − ωτ).

在 τ* = φ/ω（过境时刻，`time_to_pass_s`）取得最小值 θ_min = |λ − β| = |Δλ|。

**命题 T3a（名义几何窗口）：** 给定门限 θ_g（源码入口预筛 `BRIDGE_ANGLE_DEG = 35°`），令

  c*(Δλ) = (cos θ_g − cos λ cos β) / (sin λ sin β).

则 θ(τ) ≤ θ_g 当且仅当 |φ − ωτ| ≤ Δφ(Δλ) := arccos c*（取 [0, π]）。
- 窗口存在，当且仅当 |Δλ| ≤ θ_g；
- 窗口在相位上的半宽为 Δφ(Δλ)，持续时间为 2Δφ/ω；Δλ → 0 时半宽最大；在 β ≈ 90° 时 Δφ(0) ≈ θ_g = 35°，即一次过顶约 26–33 s（ω = 2.7–2.1 °/s）。

**入口机会集。** 执行器只在离散到达时刻 𝒯 = {15, 20, 25, 30, 40, 50, 60} s 上尝试入口（`BRIDGE_TAUS_S`），所以名义几何机会集为

  𝒲_geo = {(Δλ, φ) : ∃ τ ∈ 𝒯, |φ − ωτ| ≤ Δφ(Δλ)}.

再叠加两组条件，得到**实际候选入口集** 𝒲_ℰ(x) ⊆ 𝒲_geo × 𝒞：
- 𝒞：距离 ≤ 12 m、径向制动裕度 ≥ 0.02 m/s、τ ≤ 剩余时间 − 45 s；
- 条件 G★ 的可行性：力界、口部速度与制动包络（`_try_bridge`）。

**图 A**（`experiments.final geoscan` → `experiments.final_figures`）对每个开局的目标状态画出这两层：
- 虚线是 θ_min = 35° 的名义几何边界；
- 色块是 G★ 实际可行的最早到达时刻，空白表示不可行；
- 三种距离分开作图；相对速度取零。

源码初筛门限是 35°。经验上入口真正有效的区域约在 18–20° 以内，这是图中"几何可达但规划不可执行"的那一圈，不能把经验值写成程序硬阈值。开发开局 294200 的扫描：几何窗口约占平面的 23%，G★ 可行区只在 |Δλ| ≤ 30° 内，距离 8 / 10 / 12 m 时约 17% / 14% / 13%。

**意图与可行区域（不是分类器）。** 一个 16 s 阶段内：
- **等待**（a = (0, 0)）：端口自然扫过 ωh ≈ 34–43°，φ 随之减小；
- **迎击**（a_z = +1，沿 e_az 指向迎面来的端口）：视线额外转过约 v_z h / (r sin λ) 弧度（r = 10 m 时约 14°），φ 减小得更快，更早过境；
- **伴飞**（a_z = −1）：φ 减小得更慢，相当于把过顶推迟、把对准时间拉长；
- **纬向调节**（固定，不学习）：按 dΔλ/dt ≈ −0.02 Δλ 把 Δλ 拉向 0（时间常数 50 s，受 0.12 m/s 限幅），从而扩大 Δφ。

图 A 的箭头画的是这三种意图在同一平面上的名义一步位移，由源码 `target_velocity` 与恒角速度预报算出。迎击、伴飞、等待是策略动作在机会集上的不同用法，代码里没有人工三分类控制器；该选哪一种取决于剩余时间（紧急 / 经济）和燃料，这正是交给 SAC 的状态依赖决策。

**为什么不能只靠恒速开环规划：** 恒速预报在惯量未知时会漂移，16 / 30 / 60 s 的中位误差约 1° / 3° / 9°（HANDOFF 3.1）。离入口越远，开环选定的 τ 越不可靠；分段决策每 16 s 用新观测重估 φ、Δλ。

## T4｜从刚性时刻到同窗口承诺

**候选集合。** 对一个正在执行、在固定到达时刻 τ₀ 重规划失败的入口（`WindowGStar.decide`）：
- 刚性承诺：𝒫_rigid = {(τ₀, F₀)}，F₀ 为 80% 力界；
- 窗口承诺：𝒫_window = 𝒫_rigid ∪ {(τ₀ + s, F₀) : s ∈ {2, 4, 8}} ∪ {(τ₀ + s, F₁) : s ∈ {0, 2, 4, 8}}，F₁ 为 95% 力界；
- 所有候选都满足 τ ≤ 截止时间 − 45 s。

**命题 T4a（规划可行性不减）：** 同一规划状态与判据下 𝒫_rigid ⊆ 𝒫_window，且窗口承诺先按刚性方式尝试 τ₀。因此"存在可接受计划"在窗口承诺下不弱于刚性承诺：Feasible(𝒫_rigid) ⇒ Feasible(𝒫_window)。
- 同一 τ 下，力界越大，可行集越大（凸规划的约束放宽）；
- 所以 95% 备用规划器只会增加可行候选。

这是集合包含关系，**不**自动保证真实轨迹的成功率或回报单调提高；后者由配对试验检验（图 C）。

**命题 T4b（同一次过顶）：** 最大重定时 8 s 内端口扫过 ω · 8 ≤ 21.6°，小于 Δλ 接近 0 时的窗口全宽 2Δφ ≈ 70°。所以重定时后的到达仍在同一次过顶内，只是在窗口内往后移。

**为什么重定时比放弃整次窗口经济：**
- 放弃意味着等待下一次过顶，约一个自旋周期 2π/ω ≈ 133–171 s；这已接近或超过紧急任务的全部期限（140–200 s，且要扣 45 s 下降余量）；
- 重定时最多多花 8 s，Δv 只受规划力界约束。

**开发期证据**（T2.3 A2，`evidence/T2_3_TEST/A/A2_WINDOW.json`；同一批 120 组开局 × 固定策略配对）：
- 入口丢失 110 → 3，捕获 92 → 96，平均回报差 +9.085（去掉前两名 +4.90）。

预实验在独立开局上复现；正式实验重跑。

## 16 s 阶段时长的论证

**保守余量条件：** 一个阶段内，相位预报误差与跟踪偏差之和，必须小于入口门限与名义对准之间的余量：

  ε_θ(H) + θ_track(H) < θ_g − θ_nom.

- ε_θ(16 s) ≈ 1°（恒速预报中位误差），而 ε_θ(30) ≈ 3°、ε_θ(60) ≈ 9°；
- θ_track(H) ≈ e_pos(H) / r：阶段末位置残差除以距离，由训练与评估日志的执行残差给出（预实验记录 `exec_stats` 与观测中的残差项）；
- θ_nom：阶段末的名义对准角。

**取舍：**
- H 更长：ε_θ 增大（30 s 时已到 3°），并且每次决策跨越的相位更大（ωH ≈ 64° 时一个阶段就接近一次过顶的全宽，策略无法在过顶前修正）；
- H 更短：阶段规划在力界下可改变的速度变小（d ∝ H²），重规划开销增加。

16 s 时 ωH ≈ 34–43°，约半个过顶窗口，能在一次过顶前给出 2–4 次决策机会，且预报误差约 1°。

**参数不反向拟合：** 16 s 与 2 / 4 / 8 s 都是冻结参数，这里只解释，不调。
