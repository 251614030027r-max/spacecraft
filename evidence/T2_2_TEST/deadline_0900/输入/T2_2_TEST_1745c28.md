**两个通用函数**（后面各段反复使用）：

```powershell
function Train($tag, $arm, $seed, $steps, $marks, $extra) {
  Start-Process -FilePath $py -WorkingDirectory "D:\py\DRL2" -WindowStyle Hidden `
    -ArgumentList (@("-B","-m","experiments.t2","train","--arm",$arm,"--seed",$seed,"--steps",$steps,"--envs","3",
                     "--checkpoints",$marks,"--output","$R\$tag") + $extra) `
    -RedirectStandardOutput "$R\$tag.out.log" -RedirectStandardError "$R\$tag.err.log"
}
function EvalRun($tag, $label, $root, $steps) {   # $steps: e.g. @(0,1000,2000,3000); the last one is final.zip
  foreach ($k in $steps) {
    $zip = if ($k -eq $steps[-1]) { "$R\$tag\final.zip" } else { "$R\$tag\checkpoints\step_$k.zip" }
    & $py -B -m experiments.t2 eval --checkpoint $zip --label "${label}_step_$k" --openings 294000-294023 `
      --workers 5 --output "$R\$root\$label\step_$k" *>> "$R\$root.log"
  }
}
```

## 预先登记的判定标准（`experiments/t2_decide.py`，研究层 2026-10-22，事后不得修改）

| 项 | 标准（3000 步，种子 0、1） |
|---|---|
| C0 完整 | 每个臂、每个检查点都是 24/24，且没有 `ERROR_*.json` |
| C1 MVE 水平 | 每个种子的 E-MVE 平均回报 > 23.4217（上一轮 E-MVE 3000 步） |
| C2 耦合 | 每个种子在 2000 步和 3000 步的配对 MVE − SAC 都 > 0；两种子 3000 步的平均 ≥ 10 |
| C3 紧急任务 | 两种子在紧急任务上的配对 MVE − SAC 平均 > 0（上一轮是 −0.26） |
| C4 集中度 | 两种子剔除最大两例后的配对差平均 > 0（上一轮是 −2.40） |
| C5 安全 | 每个种子：MVE 捕获数 ≥ SAC 捕获数 − 1，且 MVE unsafe ≤ SAC unsafe + 1 |
| 学习失败 | 两臂的（3000 步 − 0 步）平均回报，两种子平均都 < 60 |

- C1–C5 全部满足：`pass`；
- 否则若满足"学习失败"：`learning_failure`；
- 其余情况：`coupling_failure`。

### 分支 K（`coupling_failure`）：两个单因素的耦合修正，并行

- 只训练 E-MVE，种子 0、1，各 3000 次决策。
- E-SAC 直接复用第 1 段的结果：两个开关只影响模型标签，不改变 SAC 的轨迹。
- 两个修正是：
  - **K1：** 模型项的影响上限 0.5 → 1.0（`--gradient-cap 1.0`）；
  - **K2：** 入口视界 2 → 3 个阶段（`--entry-stages 3`）。

```powershell
foreach ($s in 0,1) { Train "K1_e_mve_s$s" "e_mve" $s 3000 "1000,2000" @("--gradient-cap","1.0")
                      Train "K2_e_mve_s$s" "e_mve" $s 3000 "1000,2000" @("--entry-stages","3") }
# 全部 finished.json 后，K1 / K2 分别：
foreach ($v in "K1","K2") {
  foreach ($s in 0,1) {
    EvalRun "${v}_e_mve_s$s" "e_mve_s$s" "${v}_eval" @(0,1000,2000,3000)
    Copy-Item -Recurse "$R\VB_eval\e_sac_s$s" "$R\${v}_eval\e_sac_s$s"      # 第 1 段 SAC，同代码同种子
  }
  & $py -B -m experiments.t2_readout curve --eval-root "$R\${v}_eval" --train-root "$R" --screen "$R\VA_screen" --output "$R\${v}_READOUT.json" *> "$R\${v}_readout.log"
  & $py -B -m experiments.t2_decide --readout "$R\${v}_READOUT.json" --output "$R\DECISION_$v.json" *> "$R\decide_$v.log"
}
```

`--train-root "$R"` 会把所有训练目录的统计都列出来，读时只看对应变体的那几个目录。
