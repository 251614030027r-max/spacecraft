# 06 学习算法与训练

## 6.1 网络与视图

- **策略：** π_θ(a | o)，高斯策略经 tanh 压缩到 [−1, 1]²，输入为策略观测 o。
- **评价器：** 双评价器 Q_1、Q_2 及其目标网络。
  - ECC 与ECC w/o 认证：评价器读 (o, z_E)；
  - SAC–MPC、ECC w/o 执行反馈、TD3–MPC：评价器只读 o。
- **网络结构：** 策略与评价器都是两层隐藏层 [256, 256] 的全连接网络。策略与评价器各自有独立的输入层，不共享特征。

## 6.2 训练回报（塑形）

- **势函数：** Φ(x) = −min(25 m, ‖q − m₂₄‖)。m₂₄ 为恒速预报下 24 s 后的口部点位置，即端口轴上 6.3 m 处。
- **训练回报：** r̃ = r + γ_d Φ(x′) − Φ(x)，终局时取 Φ(x′) = 0。
- **用途：** 塑形只用于训练；所有评估都报告真实回报。这是标准的基于势函数的塑形，折扣与学习用的 γ_d 一致。

## 6.3 SAC 更新

每存入一条真实转移，做 2 次梯度更新。

- **评价器目标：** y = r̃ + γ_d (1 − d) [min_i Q̄_i(o′, z_E′, a′) − α log π(a′ | o′)]，a′ ~ π(· | o′)，评价器以均方误差回归。
- **策略：** 最小化 E[α log π(ã | o) − min_i Q_i(o, z_E, ã)]，ã ~ π(· | o)。
- **温度：** 固定 α = 0.05，不做自动调温（开发期自动调温导致评价器高估）。
- **目标网络：** 软更新 τ = 0.005。

## 6.4 超参数

| 项 | 值 |
|---|---|
| 学习率（策略、评价器） | 3 × 10⁻⁴ |
| 经验池容量 | 10⁵ |
| 批量 | 256 |
| 预热 | 前 200 次决策用均匀随机动作 |
| 每条转移的更新次数 | 2 |
| 折扣 γ_d | 0.999⁸ ≈ 0.992 |
| 温度 α | 0.05（固定） |
| 目标网络软更新 τ | 0.005 |
| 训练预算 | 5000 次高层决策 |
| 学习曲线检查点 | 1000、2000、3000、4000 次决策；最终模型固定取 5000 次（不挑检查点） |
| 种子 | 3 个（每组相同） |

## 6.5 训练任务分布与采集

- **任务分布：** 紧急 3/4、经济 1/4（每个初始条件独立抽取），期限与预算按第 01 节抽取：紧急 3.0 m/s、经济 2.0 m/s，训练与评估相同。初始条件来自训练专用的编号段，与开发、测试的编号段不重叠。
- **异步采集：**
  - 2 个采集进程各自运行一个环境；
  - 学习进程用当前策略回答每一次动作请求，采集进程不持有策略副本；
  - 学习进程每收到一条转移就存入经验池并更新。
- **可复现性：** 两个采集进程的转移到达顺序取决于各自的运行快慢，所以同一种子的两次训练不保证逐位相同；评估是确定的。论文写"按种子报告分布"即可。

## 6.6 评估

- **动作：** 用策略均值，不加探索噪声。认证、重定时等执行层机制按各方法的设置启用。
- **执行：** 每个初始条件单独、串行运行，结果确定。
- **学习曲线：** ECC、SAC–MPC、TD3–MPC 的 1000–5000 次检查点在 24 个验证初始条件（紧急任务）上评估，只用于画学习曲线，不用于挑模型。

## 6.7 TD3 对照的设置

除算法本身外，与 SAC 组一致：

- 一致的部分：观测、动作、执行链、任务分布、交互预算、异步采集、网络 [256, 256]、学习率、经验池、批量、预热、γ_d、每条转移 2 次更新、软更新系数；
- TD3 自身的设置：
  - 目标策略平滑噪声 0.2，截断 0.5；
  - 策略延迟更新 2；
  - 采集时在确定性动作上加 N(0, 0.1²) 的高斯噪声后截断到动作盒，噪声用独立的随机流。
