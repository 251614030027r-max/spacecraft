## 2. 事件对齐的价值目标

**模式事件：** 宏决策 k 的执行过程中，执行层转入入口转移或末段下降，或回合结束（捕获、超时、不安全、燃料耗尽、数值失败），记 ε_k = 1。入口转移一旦开始，同一宏步内一直执行到终局，除非入口丢失转为保持。所以发生事件的那一步，其真实回报已经包含执行层兑现这次窗口的结局。

**接近段：** 决策 k 的接近段终止于

  m(k) = min{ j ≥ k : ε_j = 1 或 j = k + N − 1 }，N = 5（最多 80 s 的接近）。

**事件对齐目标：**

  y_k^E = Σ_{j=k}^{m} γ^{j−k} r̃_j + γ^{m−k+1} (1 − d_m) V̄(o_{m+1})，V̄(o) = E_{a∼π}[min_i Q̄_i(o, a) − α log π(a|o)]。

其中 r̃ 为训练用的塑形回报，γ = 0.999⁸ 为每次宏决策的折扣，d_m 为终局标志（数值失败按截断处理，仍然自举）。

**评价器目标：**

  y_k = (1 − λ) [ r̃_k + γ (1 − d_k) V̄(o_{k+1}) ] + λ y_k^E，λ = 0.5。

- 发生事件的决策自身 m(k) = k，两个目标相同；
- 事件之前的接近决策直接拿到"这次接近最终是否兑现为入口、捕获还是超时"的真实结局，不需要经过中间状态的价值估计逐步回传。

策略更新不变：最小化 E[α log π(ã|o) − min_i Q_i(o, ã)]。

**N、λ 的取值：** 一次接近通常 4–5 个宏决策（训练中平均每回合约 5 次决策）。N = 5 覆盖一次完整的接近段；λ = 0.5 让单步目标保留一半权重，控制离策略多步回报的偏差。两者事先固定，不调参。

## 3. 性质（理论部分需要的）

1. **事件边界：** y^E 的自举状态只可能是事件之后的状态（入口丢失后的保持、或终局）或接近段上限处的状态，从不落在同一接近段的中间。所以一次窗口兑现的真实结局，在一次更新里就传给整个接近段的所有决策。单步目标需要 m − k + 1 轮回传。
2. **塑形一致：** 多步目标中的塑形项按同一 γ 叠加后成为 γ^{m−k+1}Φ(x_{m+1}) − Φ(x_k)，所以多步目标与单步目标对应同一个塑形后的决策过程，势函数塑形的不变性不受影响。
3. **算子：** 在策略内（on-policy）的数据上，混合目标是 (1 − λ)T^π + λ(T^π)^{n_k} 的样本。每一项都是模不大于 γ 的压缩，所以混合算子是 γ-压缩，不动点为 Q^π。

   用经验池中的历史数据时，多步部分是未经重要性修正的离策略回报（Peng 型多步回报），会偏向行为策略；有限跨度 N 和权重 λ 限制了这一偏差。

   不主张函数逼近下的收敛或性能保证。

## 5. 开发训练与采用规则（事先固定）

- **设置：** `ECC_EVT` × 种子 20、21、22 × 5000 次决策，训练设置与原 ECC 相同（含紧急 3/4 的训练任务分布）。
- **评估：** 紧急任务 300000–300095，确定性策略；验证曲线照原 ECC 的做法。
- **比较：** 与原 ECC 第一轮结果配对（同种子、同初始条件）：捕获 236/288，真实回报均值 36.4，不安全 0。
- **采用新方法，须同时满足：**
  1. 合并捕获数 > 236；
  2. 与原 ECC 的逐种子配对捕获差，至少 2 个种子为正；
  3. 真实回报均值 > 36.4；
  4. 不安全回合数不多于原 ECC 加 1。
- **否则：** 保留原 ECC，不再追加补丁。训练曲线只作辅助参考。
