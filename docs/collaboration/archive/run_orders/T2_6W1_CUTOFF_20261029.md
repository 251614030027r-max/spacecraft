## 本轮唯一改动：模型标签在截止时间 / 燃料预算处终止（修正一处已确认的实现缺口）

这个缺口由下层在 T2.6W 问题定位报告中发现（`evidence/T2_6W_WIDE_140_200/诊断/问题定位报告.md` 第 2 节），上层已在源码中核实。

- **原来的问题：** 一段不进入入口的预测阶段，总是推满 16 s 再自举。即使截止时间或燃料预算在这段时间内到期，也不终止。真实环境在这种情况下会判超时或资源耗尽，扣罚分并直接结束。
- **影响范围：**
  - 第一阶段标签只在实际阶段完整执行后才生成，所以缺口实际发生在第二阶段，即离截止 ≤ 32 s 的每个决策。
  - T2.5.1 的第二阶段单步行按全权重使用了这些错误目标。
  - 在 140–200 s 的截止分布下，约 30% 的训练回合会进入这个窗口（T2.6W 两个 EACC 种子各 249 / 251 个回合）。
- **修正：** 截止或预算先到者结束该段。目标值 = 到终止时刻为止的代价 − 超时罚分，终止、不自举，与真实环境一致。这类终止标记为 kind 0，不施加入口结局偏差。
- **修正二（同一因素，`e2d4c14`）：** 入口扫描在前；但若出发到预测入口时刻这段飞行的 Δv 已超出剩余预算，该标签按真值在耗尽处终止（资源耗尽，代价 − 罚分，不自举，kind 0），不再记为入口。第一、第二阶段都适用。T2.6W 训练中资源耗尽每个训练约 1–3 次（约 800 个回合中），罕见但可达。进入入口之后、桥接 / 下降段内的预算超支仍由入口结局回放近似处理，未改。
- **测试：** 48 项（新增入口前预算耗尽的两阶段功能测试，以及第二阶段截止的真实运行测试；两项新测试在 `8e612e7` 上失败）。
- **不变：** 任务（紧急 U(140,200) s、经济 U(280,340) s、各 0.5）、动作、奖励、执行器、K、β、共享校准、候选集合、两阶段机制，以及 Cauchy 权重。
