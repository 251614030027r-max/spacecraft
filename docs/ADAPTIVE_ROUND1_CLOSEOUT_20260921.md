## 4. 机理：接口的几何

三处独立合理的设计合成一个吸收态（`env/hybrid_env.py`）：

1. `a_commit = clip(1 + 2r)`，**所有 `r ≥ 0` 映射到同一点**；
2. `blend = max(历史最大, 本次)`，`blend` 到 1 后**直接 return 捕获位姿**，
   负残差被 max 吃掉、`a_radius` 被整条绕过；
3. 门的回退动作是零残差，即 `r = 0` → `blend = 1` → 锁存。

实测（`monotone_commit=False` 隔离映射本身）：

- **21 个等距 commit 残差 → 只有 11 个不同参考点**；`r ∈ {0.0, 0.1, …, 1.0}` 这 11 个
  全部落在捕获位姿上，逐位等于 Pure MPC。
- **一次门回退之后，2D 动作网格 15 个点 → 1 个参考点。整个动作空间 100% 惰性**，不是一半。

`blend` 直接决定参考半径（20 m 冻结起点 → 3 m 捕获位姿）：

| 第 0 步残差 | blend | 参考半径 |
|---:|---:|---:|
| −1.00 | 0.000 | 20.00 m（原地不动，不接近） |
| −0.40 | 0.600 | 9.80 m |
| **−0.265** | **0.735** | **7.42 m ← 离线可行性证书的暂存点** |
| −0.10 | 0.900 | 4.70 m |
| **≥ 0（含策略实测中位 +0.97）** | **1.000** | **3.00 m，Pure MPC** |

所以物理上有用的那一段是 `r ∈ [−0.3, −0.1]`，**占整个通道宽度的 10%，紧邻一个占 50%
的死点**。

**策略的意图是有的，只是时间错了**（从 48 种子行的 `policy_actions_raw` 直接提取）：

| | 262410 | 262411 |
|---|---|---|
| 第 0 步 raw commit 残差中位数 | **+0.9714** | **+0.9546** |
| 第 0 步 raw < 0（想暂存） | 1/48 | 1/48 |
| **整局中曾出现 raw < 0** | **47/48** | **48/48** |
| **首次 raw < 0 的决策序号（中位）** | **12** | **3** |

例（种子 262000）：第 0、1 步被门回退成零残差 → 锁存；第 2 步策略要求
`[−0.937, +0.082]`（接近完整暂存）——完全无效。

**为什么会学成这样**：从 15–28 m 出发，`blend` 同时承载"距离接近"和"对旋转位姿的承诺"
两件事，而 shaping 奖励接近。策略无法表达"再靠近一点，但先别承诺那个旋转位姿"，
只能把 blend 推到 1。加上棘轮使第 0 步不可逆，**一个决策决定全局、其余约 40 个惰性**
——这种信用分配结构本身就极难学。

## 4b. P0：第 0 步的意图，三模型 × 48 种子

`experiments/probe_policy_intent.py`。第 0 步棘轮还咬不住，所以参考异于固定设定点的
充要条件就是 commit 残差为负——整个决定性时刻退化成一个数的符号，一次 reset 加一次前向
传播即可读出，**不做任何滚动**。算法假设的那条代数已改为由环境测量交叉验证，
**144/144 全部通过**。

| 模型 | 第 0 步残差 中位 | 残差范围 | 想暂存 | 门会放行 | critic 优势 中位 / 范围 | **暂存存活到执行** |
|---|---:|---|---:|---:|---|---:|
| 262410 | +0.9714 | [−0.3190, +0.9998] | 1/48 | 32/48 | +0.0791 / [−0.221, +1.744] | **1/48** |
| 262411 | +0.9546 | [−0.1139, +0.9999] | 1/48 | 40/48 | +0.1149 / [−0.295, +0.530] | **1/48** |
| 262412 | +0.9902 | **[+0.3796, +0.9997]** | **0/48** | 39/48 | +0.1246 / [−0.124, +0.595] | **0/48** |

三件事：

1. **三个模型的第 0 步动作全部饱和在通道的死半边。262412 在 48 个种子上残差最小值是
   +0.3796——它在任何状态下都没有能力在第 0 步暂存。**
2. **门在多数状态下是放行的**（32/40/39 of 48），回退 16/8/9，均值 23%，与 D1 的
   6/24 = 25% 一致。三模型 144 个 episode 里，**暂存存活到执行的只有 2 个**。
3. **critic 优势是个跨零的小数**（中位 +0.08…+0.12）。所以门在约三分之一的状态里，
   决策取决于两个 Q 值的微小差，其中一个还是离策略分布的动作。这正是仓库 2026-09-16
   自标的 `Q(s, a_nom)` 隐患，**现在有数字了**。

### 这补上了 R2 的机理，不只是"没探索到"

`r ≥ 0` 那半边不是"没用"，是**梯度恒为零的平台**：在那里 commit 通道对参考的偏导
处处为 0，策略**感觉不到这个通道存在**。所以它是一个自我强化的陷阱——任何游荡进
`r ≥ 0` 的策略，在该通道上再也得不到推它出来的梯度。

这解释了为什么三个独立种子全部收敛到同一处，也说明 **R2 不必依赖"训练早期未探索"这个
假设**：即使早期探索到过暂存，一旦进入死半边就出不来。D0b（5k/10k checkpoint）仍有价值
——它区分"一开始就在里面"和"漂进去的"，但两者的修法都是 F2/F3。

## 5. 决定性证据：救回是"不相交"的

`--control staged_residual`（不经策略、不经门，走真实残差接口），只跑 Pure MPC 全败的
12 个种子（`nominal_pairing_two_model_interim.json` 的 `both_failed`）：

| 暂存时长 | 完成 | 救回种子 | 零违约 | 最薄真值归一化裕度 |
|---|---:|---|---|---|
| 10 s（n=5） | **2/12** | 262001, 262039 | 是 | 0.0198 / 0.0189 |
| 30 s（n=15） | **2/12** | 262011, 262035 | 是 | 0.0199 / 0.0196 |

**两个固定时长救回的是不相交的种子集。**

- 任何**单一固定**暂存时长，最多 **2/12**；
- 按状态**选**时长，**4/12**。

这个 2 倍差距就是"同一策略随状态改变行为"的**实测价值**，而且是在主线任务自己的产物上
测出来的，不是从 T12 继承的论证。12 个难例中 8–9 个死于超时，而暂存花的正是时间——
救回的是几何收益压过时钟代价的那些，这是自洽的物理解释。

| 方案 | 48 种子块完成 |
|---|---|
| Pure MPC | 36/48 |
| + 固定 10 s 或 30 s（仅施加于难例） | 38/48 |
| **+ 按状态选时长（预言机上界）** | **≥ 40/48** |

**破坏效应已由 D4c 测出**（第 8 节）：一律暂存 10 s 毁掉 1/36，30 s 毁掉 7/36。所以

- 一律暂存：最好 **+1**（10 s），最坏 **−5**（30 s）；
- 按状态选：**+4**，即 **40/48**。

40/48 仍是**预言机上界**（要求门控完全正确），但它现在有了完整的收益/破坏账本支撑，
不再是一个悬空的数。T12 那个继承来的"诚实上界 38/48"看起来是低估。

## 7. D0b：R2 也被证伪了，真正发生的是训练期能力崩塌

早期 checkpoint 的随机滚动（12 episode，种子 262000–262011，同 D0 协议）：

| checkpoint | 完成 | latch 中位 | latch = 0 | **有效参考改变** | 成因 |
|---|---:|---:|---:|---:|---|
| 262410 @5k | **11/12** | 0 | 7/12 | **45/767 = 5.9%** | policy 12/12 |
| 262410 @10k | 8/12 | 0 | 8/12 | 44/985 = 4.5% | policy 12/12 |
| 262411 @5k | 8/12 | 0 | 7/12 | 39/874 = 4.5% | policy 12/12 |
| 262411 @10k | 8/12 | 0 | 10/12 | 19/973 = 2.0% | policy 12/12 |
| 262412 @5k | 9/12 | 0.5 | 6/12 | 37/894 = 4.1% | policy 12/12 |
| 262412 @10k | 8/12 | **1.5** | **2/12** | **148/1001 = 14.8%** | policy 12/12 |
| **最终 @60k ×3** | 8/12 | 0 | **12/12** | **0/973 = 0%** | policy 12/12 |

**读法：暂存分支在训练早期是可达的，而且被大量使用——5k 时 12 个 episode 里有 5–6 个
没有在第 0 步锁存，有效介入 4–6%；262412 在 10k 时达到 14.8%、只有 2/12 立即锁存。
到 60k，三个种子全部 12/12 锁存、有效介入精确为 0。**

**所以 R2（"暂存分支从未可达"）证伪。** 真正发生的是：

> **训练把策略单调地推进了动作空间的"死半边"，进去之后梯度恒为零，再也出不来。
> 这是训练期的能力崩塌，不是探索失败。**

而且 **262410 @5k 完成 11/12，最终策略只有 8/12**——在这个 12 种子块上，**还会暂存的
早期策略比训练完的策略更好**。（12 种子、随机滚动、单次采样，是强提示不是结论。）

机理已在 4b 节给出：`r ≥ 0` 是梯度恒零的平台，占动作空间 50%。奖励梯度（接近 shaping +
时间惩罚）把 commit 通道往正方向推，而平台内没有任何反向压力，所以这是策略空间里的
**吸收吸引子**：走进去就走不出来。三个独立种子收敛到同一处，正是这个。

## 9. D3：代价结构的实测，以及一处必须修正的论文口径

3 个翻滚率 × 两种极端策略，各 8 种子（`eval/cal2/`，`read_cal.py`）：

| 策略 | 翻滚 | 完成 | 等效 Δv | 完成时间 | 最薄真值裕度 |

| | 2.36°/s | **5/8** | **2.244** | **93.1 s** | 0.0125 |
| | 3.54°/s | **4/8** | **3.894** | 103.3 s | 0.0054 |

1. **代价结构确实不同、而且随翻滚率变化**：早共旋的 Δv 从 1.53 涨到 3.89（2.5 倍），

2. **但方向和原先期望的相反**：早共旋在每个翻滚率上、每个指标上都更好；一律暂存的完成率

3. **必须修正的论文口径**：原先的跨工况表述是"随翻滚加快，暂存的燃耗优势出现"。
   **这个"工况级交叉"版本被测否了。** 站得住的是另一个版本：
   **暂存是一种定向干预——施加在 Pure MPC 失败的状态上值 +4，一律施加值 −1 到 −7；
   价值完全在"选哪些状态"。**
   > 注意边界：D3 比的是两个**固定**策略。它否的是"工况级交叉"，**没有否**"按状态选，
   > 而正确答案随翻滚率移动"。后者仍然开放，需要把第 8 节那张账本在 r=0.10 和 0.30 上
   > 重做一遍（记为 **D5**，下一轮的头条证据）。

| **F1 门语义分离** | 第二 | 原则问题（安全回退不得写不可逆模式状态），但只占 25%。判据用 T-B |
| **F4 门的对象一致** | 第二 | 门应对"映射后参考/模式转移"去重，报告 effective-reference deviation |

## 13. 下一轮设计的入口

这一轮把机制创新的**动机从审美变成了实测**：

- 一个纯启发式的 critic 阈值门，在这套接口上不但没帮忙，还因为回退动作带不可逆副作用
  贡献了 25% 的锁存。→ **"把接口做成可证的、把安全回退与模式转移分开"有了实测依据。**
- 决策被压缩到单步、其余惰性，是信用分配问题。→ **"用 MPC 已经算好但被丢弃的前瞻做
  critic 的多步目标"针对的正是这个病**，且额外算力为零。
- **注意边界**：MPC 时域 3.5 s、决策周期 2 s、翻滚周期 152.4 s。下层前瞻看不到
  "同步 vs 暂存"这个尺度，所以它改善短时程信用分配，**供不出长时程决策信号**。

**不建议在接口修好前重训。** 接口不动，重训只会再烧两天得到同一个结果。
