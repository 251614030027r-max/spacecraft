# V3 P2′ 预注册：策略层选择（各自继续）的确认性测试

*2026-09-24，上层窗口。写于 P2 结果之后、P2′ 任何 rollout 之前。*

## 为什么有这一步

P2（`docs/V3_P1_P2_RESULT_20260924.md`）按预注册**不通过**："偏离 K 步再交回 Pure MPC"的价值只捕获 0/9（K1）和 2/9（K5）的救回。
事后分析显示，**比较两个策略各自继续下去的价值**（学习策略继续 vs 此刻交回 Pure MPC）在 s_0/s_1/s_5 上都保住 8/9 救回、丢 0/18 基线完成。
这是在同一批数据上看出来的，所以必须在**新的回合和新的检查点**上确认，才能作为 V3 的仲裁结构。

被测命题：在状态 s 上，按 `argmax{ V^learned(s), V_b(s) }` 选择"学习策略继续"或"交回 Pure MPC"
（回报 = 决策级 γ = 0.99 折扣和，均为精确 rollout），能否同时保住救回、不丢基线完成。

## 数据（与 P2 样本不重叠）

**A 组：保护侧，新回合，s_0**

- 262411、262412：P2 未用到的全部 destroyed 与 retained 回合；

P2 的 9 个救回回合，在 **k = 10 和 k = 20** 处交回 Pure MPC（`K10`、`K20`），与已有的 `Kinf` 比较。
（k = 0/1/5 已在 P2 中看过，这里只用新检查点。）

## 判据
