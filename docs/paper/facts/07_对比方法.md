# 07 对比方法：各自改动了什么（第二轮）

所有学习方法共用：
- 同一执行层（RWG、规划器、MPC）；
- 同一观测 o（17 项，策略与评价器共用）、同一动作空间；
- 同一网络、奖励（机会可达性势函数）与训练设置，只用限时捕获任务；
- 从零训练，6000 次决策 × 3 个种子。

各组只在下表列出的地方不同（用户 2026-11-19 / 11-20 确定；正式阶段见 `docs/final_method/FORMAL.md`：种子 30–32，测试初始条件 301000–301191）。

**本文 ECC：** `ECC`（执行机会投影闭环）。反馈机制开发轮的 `ECC_FB` 未被采用（`FEEDBACK_DEV.md` 第 5 节，DEAD_ENDS D47）。

## 主对比与核心归因（训练）

| 方法 | 机会协调（保持 / 关键窗口修正 / 直接入口） | RWG | 学习算法 |
|---|---|---|---|
| **ECC（本文）** | 全部 | 是 | SAC |
| 无反馈：SAC–MPC | 无（策略意图直接执行） | 是 | SAC |
| 无核心：ECC w/o critical-window correction | 保持 + 直接入口（原意图接不上、且处于末次可用经过时启动直接入口） | 是 | SAC |
| TD3–MPC | 无 | 是 | TD3 |
| MPC | 只用冻结 MPC，没有阶段层与入口规划 | — | 非学习 |

直接入口是协调的一部分，不单独做消融。

## 副机制 RWG 的检验（`ROUND2.md` 第 2 节）

| 检验 | 对象 | 是否训练 |
|---|---|---|
| 入口重定时：最终 ECC 模型评估时关闭重定时（`rigid_entry`），同一模型配对 | RWG 的入口重定时 | 否 |
| 旋转同步意图：同一固定意图 (1, 0) 带与不带旋转引导（`c_10_0` 对 `b_10`），非学习 | RWG 的旋转同步意图 | 否 |

**不能在训练好的 ECC 模型上直接关闭旋转引导做评估：** 动作含义会改变，测到的是错配，不是机制。
