# T2_11_SELFCHECK：EACC-A 训练前的代码与数值自检（沙箱）

**冻结代码：** 见提交说明。环境 t2-stage-0.9.0，学习器 t2-learner-3.0，测试 68 项。

| 自检 | 结果 | 文件 |
|---|---|---|
| 1. 训练模块中的决策级执行校准，用 P4 数据复现 | 挑选块在线"先预测后观察"准确率 0.945，判为可信；留出块 0.929（原始 `opp2` 为 0.702，只猜多数类为 0.583），与离线 `calib.py` 一致 | `selfcheck_cal.py`、`selfcheck_cal_OUTPUT.txt` |
| 2. 真实环境 + 学习器联合运行（接口 `reduced_priv`，EACC 标签加机会判断） | 40 个真实决策，每个约 7.5 s，全部给出机会判断；37 个带反事实标签；观测与标签末态都是 48 维；critic TD 误差 1663 → 393 | `selfcheck_int.py` |
| 3. 校准优势触发频率（P4 关键状态） | 已训练策略错失捕获 3–11 / 154 次，其中校准优势（Δp ≥ 0.4）只识别 0–3 次 | `dp_dist.py`、`dp_dist_OUTPUT.txt` |
| 4. 视图分离 | 只改执行器信息，部署策略输出不变；EACC-A 的 critic 读取执行器信息，SAC 基线的 critic 不读；保存 / 加载后视图保持 | 测试 `test_split_views_keep_the_executor_information_out_of_the_actor` |
| 5. 多进程冒烟（两臂各 24 步） | 训练正常；manifest 记录视图（EACC-A critic 48 维，SAC critic 24 维）；评估从 manifest 读取接口；关键状态打分转换为 48 维 | 沙箱 |

**第 3 项的含义（设计因此调整）：**
- 校准擅长判断"这个决策还能不能捕获"，难以区分同一决策下哪个候选能保住捕获，所以优势项只作辅路。
- 主路改为：执行器对每个真实状态和每个反事实预测状态的判断（过境时间、窗口可达、截止余量、制动余量、执行残差 / 保持），作为训练期信息输入 critic。
- 这样反事实标签末端的价值估计也带有执行器的窗口判断。
