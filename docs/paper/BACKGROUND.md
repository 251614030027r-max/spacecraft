# 背景、问题与贡献（引言素材）

本文件提供引言与问题陈述的事实材料：背景、两个问题、研究问题、贡献，与汇报稿 `wang24.pdf`（协作分支）一致。名称与术语以 `facts/00_术语与符号.md` 为准；方法见 `facts/`，实验设计见 `EXPERIMENTS.md`。

## 1. 研究背景与目标（与汇报稿第 1 部分一致）

### 1.1 背景

- **预捕获：** 在轨服务（维修、补给、失效航天器处置）中，服务航天器在捕获前要先安全接近目标，并建立满足捕获要求的相对位置、姿态和速度。
- **非合作目标无法配合：** 捕获接口随目标本体运动，追踪器必须同时协调相对位置与姿态。
- **多重约束：** 安全距离、接近走廊、视场、相对速度与执行器能力。

### 1.2 快速翻滚带来的难点

1. 捕获接口持续运动：面对的是运动的捕获位置，不是固定目标点；
2. 捕获窗口与相遇时机需要协调：端口周期性转动，过早或过晚都会错失机会；
3. 多重约束随翻滚状态变化。

**核心难点：** 可行捕获窗口随时间变化。追踪器不仅要满足局部运动约束，还要在有限时间与燃料下选择接近速度和捕获时机。

### 1.3 能力边界与融合方式

- **MPC：** 约束处理强，但预测时域有限，长期性能依赖参考与终端设计（Xu 等 2026）。
- **RL：** 能学习长期、状态相关的策略，但依赖数据，复杂约束下探索效率与执行可靠性不足（Yang 等 2025）。
- **RL–MPC 的融合方式**（汇报稿 1.4 节；Reiter 等 2026 综述）：学习系统模型、学习代价与长期价值、学习任务参考、状态相关策略协调。本文属于"学习任务参考"一类，即 RL 生成阶段目标、MPC 执行。

### 1.4 两个问题（论文主线）

| | 理论问题（主） | 场景问题（副） |
|---|---|---|
| 表述 | **长期策略决策与短时约束执行如何有效协同？** 高层决策的预期收益不一定等于约束执行后的实际长期效果 | **快速翻滚目标的动态捕获窗口如何被有效利用？** 端口位置与法向持续变化，局部可行不代表最终能捕获 |
| 对应不足 | 不足 2：RL 的长期价值判断与实际约束执行存在偏差，高层意图未必能及时兑现，缺少兼顾执行反馈学习与动作协调的闭环机制 | 不足 1：动态捕获窗口利用困难；不足 3：旋转条件下阶段引导与入口规划困难 |
| 对应机制 | **ECC** | **RWG** |
| 对应目标 | 目标 2：执行感知的分层协同决策 | 目标 3：旋转感知的捕获窗口引导；目标 1（六自由度动态捕获建模）是两者的验证基础 |

### 1.5 论文中深化后的具体科学问题

**理论问题深化为"决策–执行失配"的三个方面：**
1. **信息失配：** 执行层知道某意图能否、何时进入入口 / 下降模式，学习层只能从稀疏的终局回报间接推断；
2. **时间尺度失配：** 高层每 16 s 决策一次，入口机会以秒级窗口出现，每圈一次；
3. **后果失配：** 机会稀缺时，相近意图的后果可能是捕获与超时之别。价值在动作空间出现由执行器规则决定的断崖，学习层难以从回报中学到。

**场景问题深化为：**
- 捕获端口在扫掠锥上周期性经过视线，入口可行性同时取决于纬向偏差、相位与相对速度；
- 时间与燃料预算决定了"现在接近还是等下一圈"的取舍；
- 已建立的入口在执行偏差下可能失效，需要在同一窗口内恢复。

### 1.6 研究问题（实验章节逐一回答）

- **RQ1：** ECC 能否在时限任务上显著提高捕获率与任务回报？
- **RQ2：** 在成功率不是瓶颈的经济任务上，能否提高时间与燃料效率？
- **RQ3：** 增益来自哪里？分开回答执行反馈增强价值学习、执行机会认证，以及训练与执行一致各自的作用。
- **RQ4：** RWG 的旋转同步引导与同窗口重定时分别贡献多少？方法何时起作用、边界在哪里（机会稀缺、燃料约束、自旋率）？

### 1.7 贡献（论文写法）

1. **ECC（主，算法贡献）：** 面向长期决策与短时约束执行失配的执行反馈闭环协同。
   - 执行器的状态层反馈进入非对称评价器，执行器的短期模式预测对意图做执行机会认证；
   - 训练与执行使用同一认证，使价值学习对应协调系统的真实后果；
   - 执行器不生成任何价值标签。
2. **RWG（副，面向任务的规划与引导贡献）：** 利用端口扫掠锥几何构造旋转同步的二维阶段意图，并以动态入口规划与同窗口重定时提高捕获窗口的利用率。
3. **验证：** 在含 J2、重力梯度的六自由度高保真环境中，对紧急、经济（含 2.0 m/s 燃料约束）与混合任务进行系统验证。建模是基础，不作为创新点。

### 1.8 与汇报稿的差异（论文按实现写）

| 汇报稿 | 实现 | 论文写法 |
|---|---|---|
| 2.2 节：观测含"相对姿态误差""已有执行状态" | 策略有效观测 18 项，不含姿态误差（由执行层姿态控制处理），也不含执行残差与保持状态 | 策略观测 o 为 18 项；实现为 24 维、6 维恒为 0 |
| 2.7 节：评价器"48 维完整观测" | 48 维 = 策略观测 + 完整工程观测，比策略多出 6 项执行反馈，其余重复 | Q(o, z_E, a)，z_E 为 3 项机会判断 + 3 项执行状态；实现表保留 24 / 48 |
| 2.9 节：塑形为 Φ(s_{k+1}) − Φ(s_k) | 塑形为 γ_d Φ(x′) − Φ(x)，终局取 0；只用于训练 | 补上 γ_d；评价只报告真实回报 |
| 2.3、2.7 节：训练与"部署"同用认证 | 同 | 写作"训练与执行"；"部署"不用 |
| 2.6 节："执行层……由近场 MPC 完成终端捕获" | 远场平移为阶段轨迹前馈加 PD 跟踪，远场姿态为指向控制；近场与入口、下降由冻结 MPC 执行 | 按职责分开写，不称全程 MPC |
| 2.6 节：同窗口重定时 | 只检查期限与规划可行，不显式检查相位窗口 | 写作原到达时刻附近的窗口导向重规划；可行候选不减（`facts/03` 第 3.5 节）；"同一次经过"只在给出充分条件时断言 |
