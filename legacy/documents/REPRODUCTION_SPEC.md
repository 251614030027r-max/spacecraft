# 最终纯 SAC 基线复现约定

## 目标与正式名称

当前冻结成果是 rationalized_level_c_physical_v4 名义六自由度交会任务上的“共享父模型课程适配纯 SAC 确定性基线”。目标是在物理自洽的中等难度任务中获得多数回合收敛，作为后续算法的固定对照；不要求 Level-C 从随机网络端到端训练，也不声称扰动、参数不确定性或精密对接能力。

## 环境与任务尺度

| 项目 | 冻结设置 |
|---|---|
| 动力学 | 耦合 SE(3) 刚体、中心引力、二阶矩、重力梯度、J2、RK45 |
| 初始距离 | 2–10 m球壳，体积均匀 |
| 初始姿态 | 随机轴、角度均匀0–75 deg |
| 惯性相对速度 | 每轴±0.125 m/s |
| 相对角速度 | 每轴±0.03 rad/s |
| 目标翻滚 | 0.50×[0.05, 0.2, 0] rad/s |
| 执行器 | 每轴±5 N、±0.6 N·m；六维动作为[torque; force] |
| 时域与边界 | dt=0.1 s、200 s、直接相对距离30 m失败 |
| 扰动与不确定性 | 关闭追踪器外扰，关闭质量惯量随机化 |

几何PD无学习审计10/10完成、无距离失败；1000次reset均位于合法边界。任务可控但并不等同真实飞行鲁棒性验证。

## 观测、奖励和成功语义

观测为12维[phi/r_phi, rho/r_p, omega/r_omega, v/r_v]，冻结尺度为30 deg、3 m、0.05 rad/s、0.2 m/s，并使用clip=10的严格单调softsign。rho和v是SE(3)相对对数/相对twist量，不应误写为简单质心差。

奖励固定为 se3_physical_storage_v4：

~~~text
V   = ||[ell phi, rho]||^2 + tau^2 ||[ell(omega + phi/tau), v + rho/tau]||^2
Psi = log(1 + V/ell^2) - log(1 - (d/d_max)^2)
r   = (Psi_prev - Psi) - (dt/tau)Psi - (dt/tau)mean(a_i^2)
~~~

ell=0.448267 m是名义追踪器均方回转半径，tau=30 s。三个核心项分别为储能耗散、残余储能时间代价和归一化控制努力；最后一项不是严格的推进剂或电能。奖励无成功bonus、固定失败罚分或经验进度项。

正式15 deg工程口径要求姿态、相对角速度、Lie代数平移误差和相对线速度分别不超过15 deg、0.03 rad/s、0.5 m、0.1 m/s，并连续保持5个0.1 s步骤。训练终止使用更严格10 deg；最终交付只对15 deg口径负责。

## 训练谱系

L0使用不同随机网络从零训练；最佳L0模型继续适配L2，随后三条Level-C分支共同加载通过验收的L2 SAC完整状态。每条Level-C分支重新建立空经验池、使用不同训练种子，但继承Actor、Critic、目标网络和优化器状态。稳定配置为学习率1e-4、gradient_steps=2、train_freq=4、gamma=.993、固定熵系数.005、batch=256、buffer=100k、learning_starts=20k；距离课程由2–8 m扩至2–10 m。

因此三条分支证明的是共享祖先条件下的适配随机性，不是三次端到端独立从零复现。
