## 1. 研究背景与目标（对齐汇报稿第 1 部分）

### 1.1 背景

- **预捕获：** 在轨服务（维修、补给、失效航天器处置）中，服务航天器在捕获前要先安全接近目标，并建立满足捕获要求的相对位置、姿态和速度。
- **非合作目标无法配合：** 捕获接口随目标本体运动，追踪器必须同时协调相对位置与姿态。
- **多重约束：** 安全距离、接近走廊、视场、相对速度与执行器能力。

### 1.2 快速翻滚带来的难点

1. 捕获接口持续运动：面对的是运动的捕获位置，不是固定目标点；
2. 捕获窗口与相遇时机需要协调：端口周期性转动，过早或过晚都会错失机会；
3. 多重约束随翻滚状态变化。

**核心难点：** 可行捕获窗口随时间变化。追踪器不仅要满足局部运动约束，还要在有限时间与燃料下选择接近速度和捕获时机。

### 1.3 能力边界与融合方式

- **MPC：** 约束处理强，但预测时域有限，长期性能依赖参考与终端设计（Xu 等 2026）。
- **RL：** 能学习长期、状态相关的策略，但依赖数据，复杂约束下探索效率与执行可靠性不足（Yang 等 2025）。
- **RL–MPC 的融合方式**（汇报稿 1.4 节；Reiter 等 2026 综述）：学习系统模型、学习代价与长期价值、学习任务参考、状态相关策略协调。本文属于"学习任务参考"一类，即 RL 生成阶段目标、MPC 执行。

### 1.4 两个问题（论文主线）

| | 理论问题（主） | 场景问题（副） |
|---|---|---|
| 表述 | **长期策略决策与短时约束执行如何有效协同？** 高层决策的预期收益不一定等于约束执行后的实际长期效果 | **快速翻滚目标的动态捕获窗口如何被有效利用？** 端口位置与法向持续变化，局部可行不代表最终能捕获 |
| 对应不足 | 不足 2：RL 的长期价值判断与实际约束执行存在偏差，高层意图未必能及时兑现，缺少兼顾执行反馈学习与动作协调的闭环机制 | 不足 1：动态捕获窗口利用困难；不足 3：旋转条件下阶段引导与入口规划困难 |
| 对应机制 | **ECC** | **RWG** |
| 对应目标 | 目标 2：执行感知的分层协同决策 | 目标 3：旋转感知的捕获窗口引导；目标 1（六自由度动态捕获建模）是两者的验证基础 |

### 1.5 论文中深化后的具体科学问题

**理论问题深化为"决策–执行失配"的三个方面：**
1. **信息失配：** 执行层知道某意图能否、何时进入入口 / 下降模式，学习层只能从稀疏的终局回报间接推断；
2. **时间尺度失配：** 高层每 16 s 决策一次，入口机会以秒级窗口出现，每圈一次；
3. **后果失配：** 机会稀缺时，相近意图的后果可能是捕获与超时之别。价值在动作空间出现由执行器规则决定的断崖，学习层难以从回报中学到。

**场景问题深化为：**
- 捕获端口在扫掠锥上周期性经过视线，入口可行性同时取决于纬向偏差、相位与相对速度；
- 时间与燃料预算决定了"现在接近还是等下一圈"的取舍；
- 已建立的入口在执行偏差下可能失效，需要在同一窗口内恢复。

### 1.6 研究问题（实验章节逐一回答）

- **RQ1：** ECC 能否在时限任务上显著提高捕获率与任务回报？
- **RQ2：** 在成功率不是瓶颈的经济任务上，能否提高时间与燃料效率？
- **RQ3：** 增益来自哪里？分开回答执行反馈增强价值学习、执行机会认证，以及训练与执行一致各自的作用。
- **RQ4：** RWG 的旋转同步引导与同窗口重定时分别贡献多少？方法何时起作用、边界在哪里（机会关键性、燃料压力、翻滚率）？

### 1.7 贡献（论文写法）

1. **ECC（主，算法贡献）：** 面向长期决策与短时约束执行失配的执行反馈闭环协同。
   - 执行器的状态层反馈进入非对称评价器，执行器的短期模式预测对意图做执行机会认证；
   - 训练与执行使用同一认证，使价值学习对应协调系统的真实后果；
   - 执行器不生成任何价值标签。
2. **RWG（副，面向任务的规划与引导贡献）：** 利用端口扫掠锥几何构造旋转同步的二维阶段意图，并以动态入口规划与同窗口重定时提高捕获窗口的利用率。
3. **验证：** 在含 J2、重力梯度的六自由度高保真环境中，对时限、经济、混合任务及燃料压力进行系统验证。建模是基础，不作为创新点。

### 3.3 认证规则的论文写法（按源码，冻结）

- **短期模式预测：** 每次决策，执行器用自身的阶段规划、入口判定与入口规划器，对 3 × 3 候选意图与策略意图各预测 48 s，得到是否触发入口或下降、触发时刻、燃料需求。
- **可认证候选：** 触发模式事件；该窗口是关键窗口（触发时刻加一个自旋周期已晚于最晚可接受入口时刻）；已用加预测燃料不超预算。
- **认证：** 策略意图本身在预测中触发模式事件，或没有可认证候选时，执行原意图；否则执行离原意图最近的可认证候选，距离相同取事件更早者。只作用于本次决策。
- **如实交代：**
  - 原意图只看是否触发事件，不套用全部候选谓词；
  - 候选可能是直接下降事件，不一定经过入口规划；
  - 认证不强制后续决策保持。

## 4. 正式实验设计（对齐汇报稿第 3 部分的结构）——**暂停，待用户指令后另行统筹**

### 4.1 设计原则

- **按同类论文惯例组织七类证据：** 主对比、蒙特卡洛统计、部件消融、一条物理量上的压力曲线、多种子训练曲线、代表性案例、在线计算开销。参照 Ramezani 2026、Zeng 2026、Yang 等 2025、Lu 2025。
- **一个主终点：** 时限任务上 ECC 对 SAC 的捕获率与真实回报。其余预先登记为次要终点。
- **严格隔离：** 训练、开发、筛查与正式评估的初始条件互不相交；正式块运行前不访问；不按正式结果调整任何设置。

### 4.2 仿真场景（汇报稿 3.1 节）

| 场景 | 设定（物理与初始分布不变：12–16 m，2.1–2.7°/s，500 km） | 回答 |
|---|---|---|
| **紧急任务 U**（主） | 期限 140–200 s，时间优先代价，燃料预算 3 m/s | RQ1 |
| **经济任务 E** | 期限 280–340 s，燃料优先代价 | RQ2：双方都成功时的用时与燃耗 |
| **混合任务 N** | U、E 各半 | 自然比例下的外部有效性 |
| **燃料压力 R**（扩展） | 同 E，只收紧燃料预算；档位只用非学习策略按事先规则定 | RQ4 边界 |

- **训练任务：** 紧急 3/4、经济 1/4，所有学习方法相同。
- **评估：** 分场景报告，不合并成一个总分。

### 4.3 对比方法与消融（训练组：每组 3 个新种子 × 5000 决策，从零训练）

| 组 | 角色 | 方式 |
|---|---|---|
| **ECC（本文）** | 主方法 | 训练 |
| **SAC–MPC**（同执行链，无反馈无认证） | 主基线（汇报稿"SAC-MPC 无反馈"） | 训练 |
| **TD3–MPC**（同上） | 不同 RL 算法的基线 | 训练 |
| **纯 MPC** | 传统基线（冻结，重跑） | 不训练 |
| **ECC w/o 认证**（只有执行反馈增强价值学习） | 归因：状态层反馈 | 训练 |
| **ECC w/o 反馈**（只有训练与执行一致的认证） | 归因：动作层认证 | 训练 |
| **ECC w/o 旋转同步**（阶段目标只沿视线接近） | 归因：RWG 扫掠锥引导 | 训练 |
| ECC 执行时关认证（同一模型） | 训练与执行一致带来的依赖 | 只评估 |
| SAC–MPC + 仅执行时认证、ECC w/o 认证 + 仅执行时认证（同一模型） | 认证在执行时单独加入的作用；与训练执行一致相比 | 只评估 |
| ECC 固定到达时刻（同一模型） | 归因：RWG 同窗口重定时（汇报稿 3.6 节） | 只评估 |
| 直接入口规划（动作空间外） | 参照，不作竞争基线 | 不训练 |

**归因结构（F6a）：**
- 2 × 2 训练组：执行反馈 {无, 有} × 认证 {无, 训练与执行一致}，即 SAC–MPC、ECC w/o 反馈、ECC w/o 认证、ECC；
- 两个"仅执行时认证"的评估格，用来区分"有认证"与"训练与执行一致"。

**计算量：** 7 个训练组中纯 MPC 不训练，实际训练 6 组 × 3 种子 = 18 条 × 5000 决策。下层约 3 批、每批 6 条并行，预计 75–90 小时。

### 4.4 训练协议

- 种子、预算、交互数、更新次数、网络与超参数对所有学习组一致；TD3 用其标准配置并披露。
- 检查点 1000 / 2000 / 3000 / 4000 只画学习曲线，**最终模型固定为 5000 步**。
- **事先登记的收敛读数：** 最后 1000 次决策的回报斜率与捕获率变化，只报告，不用来挑检查点。开发期 3000 步时部分曲线仍在上升，这是选 5000 的依据。
- 学习曲线来自训练回合（行为策略，图中标注）；可选在 24 个开发初始条件上评估各检查点，作为确定性曲线。

### 4.5 评估协议

- **初始条件：** U、E、N 各 96 个正式块初始条件，编号在执行书中登记，三段互不相交；R 复用 E 的初始条件、只改预算；所有模型用同一批初始条件，按种子、按初始条件配对。
- **执行方式：** 确定性、串行计时；在线耗时只作开销报告，不作实时性主张。
- **评估量：** 约 9,500 回合，下层约 35 小时。

### 4.6 指标（汇报稿 3.1 节的四项加以完整化）

| 层面 | 指标 |
|---|---|
| 全部回合 | 捕获成功率；超时 / 燃料耗尽 / 不安全构成；平均真实任务回报 |
| 成功回合 | 任务耗时、累计燃耗（Δv，m/s）、终端位置 / 速度 / 姿态 / 角速度误差；**双方都成功**的配对差 |
| 约束与执行 | 各约束分别的最小裕度（不跨量纲合成）；入口丢失、保持、规划被拒 |
| 机制 | 关键 / 非关键决策的认证修改率、救回 / 丢失翻转、预测兑现率、可认证候选比例 |
| 开销 | 每次决策的认证耗时（均值 / P95 / 最大）、MPC 每步求解时间，对比 16 s 决策周期 |

### 4.7 统计

- 种子是训练重复，初始条件是配对单位。
- 成功率给二项区间与翻转数；回报、耗时、燃耗给效应差与按种子分层的自助法区间；同时列出各种子单独结果。
- 主结论只看 U 上 ECC 对 SAC–MPC，其余为次要终点，不按显著性更换主终点。

### 4.9 有效性威胁与局限（论文需写）

- 只有仿真，单一执行器实现；目标惯量未知，执行层用估计模型。
- 认证依赖短期预测的准确性，预测不兑现会导致丢失；认证不保证"从不伤害"，报告净效应与翻转。
- 训练与执行一致带来对认证的依赖（执行时关认证会下降）。
- 直接入口规划在动作空间外，可能更强，只作参照。
- 期限与预算是仿真任务设定。
