# EACH 方法规格：决策、信息、动作、执行器、真实 TD

> **非最终论文算法（2026-11-10）：** 本文件是研发记录。论文方法以 `docs/paper/METHOD.md` 为唯一源，对照见 `docs/paper/FACT_MAP.md`。

每个公式后给出源码位置（`env/t2_stage.py` 简写为 `env`，`train/t2_mve_sac.py` 简写为 `learner`）。所有数值都是冻结值，最终实验不改。

## 1. 执行诱导的宏观决策（理论 T1）

**高层决策时刻 k：** 系统真值状态 x_k，策略可见 o_k = h(x_k)（24 维），动作 a_k = (a_p, a_z) ∈ [−1, 1]²。

**宏转移：** 执行器 ℰ（C1 全部下层）把 (x_k, a_k) 映射为一次宏转移 (R_k, x_{k+1}, d_k, τ_k, m_k)。
- R_k：本宏步内的真实回报；
- d_k：是否终止；
- τ_k：真实持续时间；
- m_k ∈ {stage, hold, bridge, descent, terminal}：宏步结束时的执行模式。

`env: T2StageEnv.step` 的宏步结束条件：
- 16 s 阶段飞完（模式 stage 或 hold）；
- 阶段偏离触发 hold，且已过 ≥ 2 s：立即重新询问策略；
- 阶段内打开入口：bridge 与 descent 连续飞到终止事件，期间不再询问策略；
- 终止事件：success / unsafe / timeout / resource_exhausted。

这些真实时长不同，但学习使用的是**每次高层决策固定折扣** γ_d = 0.999^(16/2) ≈ 0.99203（`env: GAMMA_STAGE`）：

  Q^π(o_k, a_k) = E[ R̃_k + γ_d (1 − d_k) V^π(o_{k+1}) | o_k, a_k ]

用 γ^{τ_k} 的连续时间半马尔可夫形式只是可选推广，**不是当前实现**。

**训练回报含势函数 shaping**（`env: step`、`_macro_to_end`）：
- R̃_k = R_k + γ_d φ(x_{k+1}) − φ(x_k)，终止时 φ(x_{k+1}) = 0；
- φ(x) = −min(25, ‖q − m_24‖)，m_24 是 24 s 后的口部位置（6.3 m × 端口轴，恒角速度外推；`env: potential`）。

**报告指标一律用真实回报 R**（`return_true`）：
- R = −c_t · 用时 − c_f · Δv + 终局项；
- 终局项：捕获 +100，超时或燃料耗尽 −100，不安全 −150；
- 紧急任务 c_t = 0.10 /s、c_f = 10 /(m/s)；经济任务 c_t = 0.02 /s、c_f = 40 /(m/s)；预算 3 m/s（`env: T2Mission`）。

**命题 T1（执行模式决定动作后果）：** 宏转移核 P_ℰ(x', R, τ, m | x, a) 由执行器的模式转换（阶段完成、hold、入口打开、窗口重定时、入口丢失）决定。两个数值相近的意图，可能一个在本阶段打开入口（τ 短、终局 +100），一个错过过顶（再等约 150 s，紧急任务超时）。因此 Q 的动作地形在模式边界附近陡变，而在同一模式内较平滑。这是执行信息影响长期价值的起点，也是 U1 要解决的价值表示难点。

**核对项（`evidence/final_pretest/precheck/`）：** 固定开局与固定动作序列下，新旧版本的观测、回报、终止事件与模式轨迹逐步一致；同种子短程训练的策略参数逐位一致。

## 2. C1：旋转同步意图与可执行规划

**自旋坐标系**（`env: spin_frame`）：
- 视线 e_r = q/‖q‖；
- e_pol 指向自旋轴（垂直于视线）；
- e_az = −(ŝ × e_r)，指向迎面而来的端口，然后与 e_pol 正交化；
- 端口相对自旋轴的锥半角 β = ∠(端口轴, ŝ)，视线极角 λ = ∠(e_r, ŝ)，纬向误差 Δλ = λ − β；
- 相位 φ：端口还需扫过多少角度才到达视线所在子午面；过境时间 t_pass = φ/ω。

**目标速度**（`env: target_velocity`；`CLOSING_M_S = (0.05, 0.15)`、`AZIMUTH_M_S = 0.15`、`LAT_GAIN_PER_S = 0.02`、`LAT_SPEED_M_S = 0.12`）：

  v* = −v_c e_r + v_l e_pol + v_z e_az，

其中：
- v_c = 0.05 + 0.15 a_p ∈ [−0.10, 0.20] m/s；
- v_z = 0.15 a_z；
- v_l = clip(0.02 · r · (λ − β)[rad], ±0.12) m/s。

v_l 是固定的几何调节，不是学习动作。消融 `geometry = false` 时 v* = −v_c e_r（不感知旋转的标准分层）。

**阶段目标**（`env: stage_goal`、`_safe_stage_end`；h = 16 s）：
- Δv = v* − v，按 ‖Δv‖ ≤ 2d/h 限幅，d = 0.70 · (1.6 N / m) · h² / 2；
- 再做安全投影：阶段末距离 ≥ 6.8 m，径向接近速度不超过阶段末距离处的制动包络减 0.02 m/s；
- q_goal = q + h (v + v_goal)/2。

**执行：**
- 局部阶段规划器（1.6 N，16 节点）给出 16 s 参考；
- 远场（> 7.5 m）为惯性跟踪律加 PD 指向，近场由冻结 MPC 执行；
- 规划被拒，或跟踪偏离 > 3 m，进入 hold（`STAGE_DEVIATION_HOLD_M`）。

**入口（窗口进入；`env: _try_bridge`）：**
- 前提：距离 ≤ 12 m，且径向制动裕度 ≥ 0.02 m/s；
- 对 τ ∈ {15, 20, 25, 30, 40, 50, 60} s 依次检查：预测端口与视线夹角 ≤ 35° 的 τ，交给条件 G★（80% 力界，`make_conditional_gstar`；截止余量 45 s）规划；
- 第一个可行的计划开启 bridge。

**窗口承诺（`env: WindowGStar.decide`）：**
- 触发条件：正在执行的入口计划，在固定到达时刻重规划失败；
- 在同一次过顶内依次尝试：τ + 2 / 4 / 8 s（规划力界），再用 95% 力界的备用规划器尝试 τ + 0 / 2 / 4 / 8 s；
- 都不超过截止时间。新的入口请求不受影响。

**之后：** bridge → descent，由冻结 MPC 完成捕获（6-DoF，RK45 真值）。

C1 的理论（扫掠锥机会集、窗口可行集包含、16 s 的论证）见 `C1_THEORY.md`。

## 3. U1：执行状态证书与价值表示（理论 T2）

**定义：** z_E = φ_ℰ(o)，即执行器由当前几何与动力学约束算出的判据。在当前实现中，critic 的后 24 维是完整工程观测（`env: observe`），其中相对 Actor 新增的只有三个分量（`PLANNER_FEATURES`）：
1. 过境时间 t_pass/150（索引 8）；
2. 入口窗口可达角：对 τ ∈ 入口时刻集合，预测端口与视线夹角的最小值 /180（索引 17）；
3. 过境后截止余量 clip((T_deadline − t − t_pass − 60)/100, ±3)（索引 19）。

其余分量（距离、速度、相位正余弦、纬向误差、制动裕度、执行残差、任务与资源）Actor 也能读到。

**学习目标**（`learner: T2SAC.train`，`feedback = None`、`model_beta = 0`）：
- Critic：L_Q = E[(Q_ψ(o, z_E, a) − y)²]，其中 y = R̃ + γ_d (1 − d)(min_i Q̄_i(o', z_E', a') − α log π(a'|o'))，a' ~ π(·|o')；
- Actor：最大化 E[min_i Q_i(o, z_E, ã) − α log π(ã|o)]，ã ~ π(·|o)；
- 固定 α = 0.05；双 critic；目标网络 τ = 0.005；
- 没有模型生成的 Q 目标，没有反事实、偏好或模仿项。

**命题 T2a（信息不变）：** z_E 是 o 的确定函数（重构误差约 1e-7），所以对任意策略，以 (o, z_E) 为条件的价值等于以 o 为条件的价值：Q^π(o, z_E(o), a) = Q^π(o, a)。增强输入不改变可用信息，也不使 critic 有偏（Baisero & Amato 2022 的非对称 critic 无偏条件）。改变的只是网络使用的特征坐标。

**命题 T2b（表示能力不降）：** 设基础 critic 函数类 𝒬_o = {f(o, a)}，增强类 𝒬_{o,z} = {g(o, z_E(o), a)}，且 g 的第一层对 z 的权重可以置零。那么 𝒬_o ⊆ 𝒬_{o,z}，最佳逼近误差 inf_{g} ‖Q − g‖ ≤ inf_{f} ‖Q − f‖。

**例（边界复杂度）：** 设价值在入口可达判据 w(o) = 1{θ_min(o) ≤ 35°} 的两侧取不同的平滑函数：Q = w·Q₁ + (1 − w)·Q₀。
- 用 z_E 中的 θ_min 作输入，一个 ReLU 单元的组合即可近似阶跃；
- 只用 o 时，网络必须先从 (r, Δλ, sin φ, cos φ, ω, …) 学出 θ_min(o) = min_τ arccos(cos λ cos β + sin λ sin β cos(φ − ωτ))，即在 7 个到达时刻上做 min 与 arccos 的复合，再在其上做阈值。

这说明 U1 降低的是表示与优化难度。它**不是**有限样本下必然优于任何 SAC 的保证；实际收益由学习曲线和等宽对照（`DUP`：48 维 critic，后半重复精简观测）检验。

**命题 T2c（真实转移锚定的误差隔离）：** U1 的 z_E 只作为输入，TD 目标全部来自真实宏转移，所以执行器的规划误差不会作为 Bellman 目标注入。对照：若把模型预测值作为目标，误差 ε 经自举最多放大到约 ε/(1 − γ_d)（约 125 倍）。开发期实证见 `ABLATION_MATRIX.md` 的历史表：T2.11–T2.14 的标签路线全部变差，T2.19 的历史依赖校准输入形成了自我印证的循环。后者说明 T2a 的条件"z_E 是 o 的确定函数、不依赖学习策略的历史"是必要的。

## 4. 训练与评估协议

**学习器**（`learner: make_model`）：
- 网络 [256, 256]，学习率 3e-4，经验池 10⁵，批量 256，learning_starts 200；
- 每条存储转移 2 次梯度更新；固定熵系数 0.05；
- 两个异步采集 worker（`learner: worker`、`train`）。

**训练开局：** 1,000,000·(seed + 1) + 100,000·worker + 回合序号；任务（紧急 / 经济、截止期限）由开局号确定（`env: T2Mission.sample`）。

**评估：** 确定性策略（均值动作），按开局串行仿真（`experiments.t2 eval`）；执行器配置（窗口、几何）读自训练 manifest。

**训练曲线：** 每个训练回合一个点，横轴为该回合结束时的存储决策数，纵轴为其真实回报，按最近 50 个回合平滑（`experiments.t2_curves.run_curve`）。曲线 AUC 为平滑曲线在 250、300、……、预算处的均值。这些是行为策略的统计，不等于部署性能。
