# 08 仿真实验结果（第一版）

**范围：** 时限约束下的动态捕获，即紧急任务；论文不写经济任务和混合任务。第二版 ECC 与第二轮实验完成后整体替换。

**数据：** `evidence/FORMAL/ROUND1_READOUT/`，由 `python -B -m experiments.round1_readout --output evidence/FORMAL/ROUND1_READOUT` 生成。

| 文件 | 内容 |
|---|---|
| `READOUT.json` | 全部统计数字 |
| `MAIN_TABLE.csv` | 各方法逐种子的结局构成（取 condition = urgent 的行） |
| `PAIRED.csv` | 各比较的配对差：估计值、95% 区间、逐种子、翻转（取 urgent 的行） |
| `URGENT_EPISODES_WIDE.csv` | 逐种子、逐初始条件：每个方法的结局、真实回报、完成时间、Δv（288 行），可画配对散点、翻转矩阵、分布图 |
| `TRAINING_CURVES.csv` | 训练期紧急回合的滑动捕获率、真实回报、认证介入次数（每组 × 3 种子，横轴为累计阶段决策数） |
| `VALIDATION_CURVES.csv` | ECC、SAC–MPC 在 24 个验证初始条件上的检查点曲线（1k–5k） |
| `DEV_REFERENCES.csv` | 参考线：纯 MPC、固定意图、截止规则、直接入口规划、不带旋转引导的接近（48 个初始条件） |

## 8.1 设置

- **方法：** ECC、SAC–MPC、ECC w/o screening（去掉认证）、ECC w/o execution feedback（评价器不读执行反馈）。
- **训练：** 每组 3 个种子 × 5000 次高层决策，从零训练，训练设置见第 06 节。
- **测试：** 紧急任务，期限 140–200 s，预算 3.0 m/s；96 个初始条件 × 3 个种子 = 288 回合；确定性策略；同一初始条件在各方法间配对。
- **统计：** 配对差的 95% 区间由自助法得到：在每个种子内按初始条件重采样，10,000 次。
- **参考线：** 纯 MPC、固定意图 (1, 0)、截止规则、直接入口规划，在同一任务分布的 48 个初始条件上运行。

## 8.2 主结果

| 方法 | 捕获 / 288 | 捕获率 | 种子 20 / 21 / 22 | 超时 | 不安全 | 平均真实回报 | 成功回合时间 / Δv 中位数 |
|---|---|---|---|---|---|---|---|
| **ECC** | **236** | **81.9%** | 81 / 81 / 74 | 52 | 0 | **36.4** | 132.4 s / 1.32 m/s |
| ECC w/o execution feedback | 225 | 78.1% | 65 / 81 / 79 | 62 | 1 | 28.5 | 133.1 s / 1.31 m/s |
| ECC w/o screening | 211 | 73.3% | 68 / 74 / 69 | 76 | 1 | 19.1 | 133.4 s / 1.25 m/s |
| SAC–MPC | 204 | 70.8% | 69 / 60 / 75 | 84 | 0 | 14.8 | 131.0 s / 1.23 m/s |

**ECC 对 SAC–MPC（配对）：**

- 捕获率 +11.1 个百分点 [6.6, 16.0]；
- 翻转：只有 ECC 捕获 43 次，只有 SAC–MPC 捕获 11 次；
- 真实回报 +21.6 [12.2, 31.4]；
- 双方都捕获的 193 对中，完成时间与 Δv 基本相同（中位差 −0.2 s、+0.019 m/s），提升来自捕获更多。

## 8.3 机制归因

| 比较 | 捕获率差 [95% 区间] | 翻转 | 回报差 |
|---|---|---|---|
| ECC 对 ECC w/o screening | +8.7 [4.5, 12.8] | 33 / 8 | +17.3 [8.7, 26.1] |
| ECC w/o execution feedback 对 SAC–MPC | +7.3 [2.8, 11.8] | 36 / 15 | +13.7 [4.4, 23.2] |
| ECC 对 ECC w/o execution feedback | +3.8 [0.3, 7.3] | 21 / 10 | +7.9 [0.6, 15.3] |
| ECC w/o screening 对 SAC–MPC | +2.4 [−1.7, 6.6] | 24 / 17 | +4.3 [−4.1, 12.7] |

**事实：**

- 认证带来约 +7 到 +9 个百分点；
- 执行反馈在有认证时再带来 +3.8 个百分点；
- 两者组合（ECC）最好，2 × 2 四格依次为 204、211、225、236。

**训练期认证介入（`TRAINING_CURVES.csv`，每 100 个紧急回合一个窗口）：**

- ECC 三个种子从第一个窗口的 0.86 / 1.20 / 1.35 次降到最后一个窗口的 0.68 / 0.62 / 0.94 次；
- ECC w/o execution feedback 为 0.99 / 1.04 / 0.94 到 1.08 / 0.70 / 0.87 次，全程在 0.63–1.29 之间。

**训练期捕获率（同一文件，最后一个窗口的三种子均值）：** ECC 0.76，ECC w/o execution feedback 0.71，ECC w/o screening 0.71，SAC–MPC 0.67。

## 8.4 RWG 的作用

- **入口重定时：** 同一 ECC 模型关闭重定时，捕获 228/288，比 ECC 少 8 次。差值 +2.8 个百分点 [0.3, 5.6]，三个种子都为正，翻转 11 / 3。
- **旋转引导：** 同样的接近意图，带旋转引导时捕获 35/48，只沿视线接近、不利用扫掠锥几何时捕获 21/48（`DEV_REFERENCES.csv` 中的 `c_10_0` 与 `b_10`）。

## 8.6 学习曲线

- **训练曲线（`TRAINING_CURVES.csv`）：** 四组 × 3 个种子，紧急回合的滑动捕获率与真实回报。带认证的两组从训练初期起捕获率就较高。
- **验证曲线（`VALIDATION_CURVES.csv`）：**
  - ECC 三个种子从 17 / 18 / 15 升到 19 / 19 / 20（满分 24）；
  - SAC–MPC 从 13 / 12 / 17 到 13 / 12 / 18。
