## 4. 方法最终形态（一句话 + 结构）

> **SAC 学一个长期任务策略；训练后分别学"学习策略一直走下去"和"Pure MPC 一直走下去"的长期价值；
> 部署时每 2 s 比较两者，只有另一方有把握地更好才切换分支；MPC 始终是唯一执行者。**

```
训练（与 V2 只差 T0 接口）： SAC，学习分支始终执行 → π_L
训练后：                     π_L 回合 + Pure MPC 回合 + 交回探针 → V_L、V_b（固定策略评估，各 5 头）
部署：                       V_L(s) vs V_b(s)，对称保守切换 → 分支 → MPC
```

**核心消融不需要重训**：同一组网络，仲裁关 = 修好接口的普通层级 SAC→MPC；仲裁开 = 完整方法。

**与主问题的对应**：P2 / P2′ 本身就是"长短时域不匹配"的实测证据——学习层的价值只在长时程上存在，截短后交给短时域 MPC 就拿不到。
所以仲裁必须比较长期价值，而不是在动作层做短偏离修正。

**创新定位（收窄后）**：策略选择定理、固定策略评估、集成不确定性都是已有方法。
我们的贡献是：把"约束 MPC 作为基策略"与"学习的长期任务策略"放到策略层价值仲裁下，在 Λ > 1 的快速翻滚预捕获中实现；
并且借助确定性高保真仿真，用**精确 rollout** 验证仲裁对象的正确性（P2 / P2′）和学到价值的校准（M6）。
必须引用并区分：Lu 2025、Zeng 2026、Wu 2024、Bertsekas（rollout / MPC）、SPIBB。

## 6. 已知风险

1. **P2′ 是精确价值下的结果。** 部署靠学到的价值，误差由 M6 把关；M6 不过就不做正式评估。
2. **P1 的局限**：临近时限的完成可能被停在抓取点的超时压过。仲裁会因此偶尔偏向 Pure MPC。
3. **样本都在评估块 262000–262047 内**（来自 V2 模型），正式论文数字要换新的、更大的种子块，最后干净重跑。
4. **V_b 的覆盖**：交回探针每种子 2 个，若 M6 显示 V_b 在学习策略的状态上误差大，要加探针数量，不改方法。
5. **死种子风险仍在**：若新训练仍有死种子，仲裁应把它退回 Pure MPC（P2′ 中死种子 12/12 正确退回），但这不算学习层有效。

## 8. 审查后更新（同日，采纳审查窗口意见）

以下内容取代第 3 节第 4、6 条和第 5 节中的对应描述，两份执行单已同步改为 v2：

1. **仲裁改为"开局选择 + 学习分支上单向交回"**：交回 Pure MPC 后本回合不再切回。
   理由：P2′ 只验证过这两种判断，没有验证 Pure MPC 运行一段后再切回。
   相应地，T0 去掉"baseline → learned 连续初始化"，改为执行过 baseline 后请求 learned 直接报错；观测不加分支位。
2. **V_L、V_B 改为完整折扣回报的监督回归**，不用 TD(0)：环境确定、轨迹完整，回报可直接算。
   补充一条审查意见没提到的细节：**交回探针中交回之前的学习段不能作 V_L 样本**（它的回报里含 Pure MPC 段）；
   集成按回合做自助采样。
3. **M6 除总体一致率外，必须单独报"关键状态"的正确率和"选了失败分支而另一分支本能完成"的次数**。
4. **正式评估分两层解读**：第一层基线保护（完成 ≥ 36/48、destroyed ≤ 2、违约不增、学习分支占比 ≥ 5%）；
   第二层净改进（rescued > destroyed）。只过第一层时，如实写"保住了基线但无净改进"。
