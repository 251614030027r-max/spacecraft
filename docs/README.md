# 文档入口

当前文档只保留五个入口，避免历史文件名冒充现行状态：

1. 仓库根 `CLAUDE.md`：唯一权威；
2. 仓库根 `HANDOFF.md`：当前暂停状态和执行闸门；
3. `PROBE_RESULTS.md`：四个 hybrid 缺口探针；
4. `EVIDENCE_INDEX.md`：日志、模型与论文证据；
5. `REPRODUCIBILITY.md`：解释器、依赖和回归方式；
6. `HISTORY.md`：被后续结果取代的历史演进摘要。

原 `docs/history/` 的逐轮报告、旧总览、旧实验索引和旧清理清单已整合进上述文件。原文仍存在于 Git 历史，但不得直接支持当前主张。
