# T12 / S10 正式评估结果

核验日期：2026-09-15 JST。本文报告六个 T12 `final_model.zip` 在固定种子块 262000–262047 上的 48 局确定性评估。训练使用完整真值状态 `perception=None`；结果只能支持 full-state SAC-MPC 调度结论，不能包装为局部视觉/EKF结果。

## 结论

预登记判据落入**分叉 2**：`arrival_condition` 明显改善了相对 `radial_local` 的可学性，但没有稳定超过 Pure MPC，且燃料显著更高，因此**不支持“学习控制优于固定设定点”**。三个 arrival 训练种子的完成数为 16/48、34/48、28/48，均值 26.0/48、总体标准差 7.48、范围 16–34；只有 262401 略高于 Pure MPC 的 32/48，但其成功平均燃料 273.776 N·s，高于 Pure MPC 的 187.721 N·s，且另外两个训练种子落后，不能择优宣布成功。radial 三个种子均为 0/48，与训练期全程零成功一致。

下层执行已到预登记终点，不建议在裁决前继续重训、挑种子、改奖励或补做 Pure SAC。请上层审查并裁决：一是接受分叉 2、将本轮结论冻结为当前 full-state T12 基线，还是提出有独立假设的新控制问题；二是并行评估产生的 compute 数据继续排除，还是另行定义独占串行的 compute-only 协议；三是感知方案仅先做与控制器解耦的 P1/P2 测量链验证，还是在控制层未证明稳定净增益时仍进入 P3 闭环耦合。无论选择哪条路线，本轮六种子结果均应整体保留，不得用 262401 单种子替代三种子分布。

## 训练与正式评估的边界

训练监视记录中 arrival 三种子的全程探索回合成功率为 50.4%、46.1%、42.8%，末 100 回合为 50%、69%、59%；正式固定块确定性评估则为 33.3%、70.8%、58.3%。训练统计包含不同种子、探索动作与训练过程中的旧策略，不能直接和 Pure MPC 32/48 比较。正式结果显示 262401/262402 的后段改善能部分泛化，但 262400 明显不稳定，方法仍具有较强训练种子敏感性。

## 完整性与复现核验

- 六个结果均为 48 个唯一种子 262000–262047，horizon 35；arrival 使用 `arrival_condition`，radial 使用 `radial_local`；均启用 phase/time observation、关闭 execution feedback。
- 首轮 288 局发现评估器只检查七类累计真值违约而未序列化。最小修复后用独立目录完整复测 288 局；除新增七类字段外，六个运行的逐局结果与首轮在 seed、完成、时间、燃料、入口、QP、零推力及全部轨迹记录上确定性一致。

- 两轮结果评估均并行，期间采集的 compute 数字全部从结果型主表副本中移除，不能作为实时性证据。当前没有独立 compute-only CLI；未为得到耗时列而第三次重复 288 局。若上层仍要求实时性证据，应先明确独占串行的采样入口与样本规模。
