## 5. 什么算"明显缺陷"（出现任何一条就停下报上层，不进入 60k 完整评估）

| 检查 | 缺陷标准 |
|---|---|
| 训练健康 | 参考跳变违例 > 0，或 QP 回退率 > 1 × 10⁻³ |
| Pure MPC | 不是 37/48（沙箱结果：完成回合逐位不变、262034 变为完成） |
| 评估求解 | v3e learned-only 的 QP 零推力回退步数明显多于 Pure MPC（例如每个模型 > 50 步） |
| 安全 | v3e learned-only 有真值违规的回合数明显多于 Pure MPC |
| 试运行 | 第 3 步任一命令报错 |
| 训练曲线 | 任一种子在 40–50k 完成率为 0 且超时比例持续上升（悬停吸引子） |

**以下不是缺陷，照常进入 60k**：learned-only 单独运行时完成数低于 Pure MPC、比 Pure MPC 慢或更费燃料。V3 本来就靠仲裁取长补短，这些正是仲裁要处理的情况。
