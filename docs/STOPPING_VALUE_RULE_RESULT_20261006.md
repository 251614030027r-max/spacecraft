## 结论

按预注册，交接 / 停止这条协调线在本任务的名义工况下收口：

- 交接相对学习策略有显著、安全的增益（正式轮 +25 / +10 / +19，0 违规）；
- 但在强 Pure MPC 基线上没有净收益（−3 到 −1 个开局）。
