## 0. 一句话

**SAC 学一个长期任务策略；再单独学"一直用 Pure MPC"的长期价值。部署时每 2 s 比较两者各自继续下去的价值，
只有有把握更好时才切换分支。** 两个价值都是长时程的，比较发生在策略层，不在动作层。

### 为什么是这个结构（实测，不是推断）

| 做法 | 救回保住 | 基线完成丢掉 | 产物 |
|---|---:|---:|---|
| 学习层偏离 2 s 后交回 Pure MPC | 0 / 9 | 0 / 18 | `eval/adp/v3_p1_p2_readout.json` |
| 学习层偏离 10 s 后交回 Pure MPC | 2 / 9 | 0 / 18 | 同上 |
| 两个策略各自继续，按价值选（s_0/s_1/s_5，事后） | 8 / 9 | 0 / 18 | 同上 |
| 同上，66 个新回合 + 新检查点 k=10/20（预注册确认） | **9 / 9** | **0 / 66** | `eval/adp/v3_p2prime_readout.json` |

学习层的价值是长时程的，截短了再交给短时域 MPC 就拿不到；而且学习策略带到的某些状态上，Pure MPC 接手会直接失败
（262412/262005 硬约束失败，262412/262027 飞出）。所以仲裁必须比较**两个策略各自继续到底**的价值。

### 理论依据（现成定理，不是我们的发明）

策略选择定理（Lu 2025 定理 1；广义策略改进，Barreto 等 2017）：若在每个状态选"自己继续下去价值更高"的那个策略，
所得策略的价值不低于其中任何一个。精确价值下即：**不劣于 Pure MPC，也不劣于学习策略本身**。
价值有误差时，只能写成"误差受控条件下的有界退化"，不写"高概率保证"。

## 1. 组成

```
训练期（与 V2 相同，只换 T0 接口）： SAC，学习分支始终执行              ──→ π_L
训练后（固定策略评估，两者完全对称）： π_L 的回合 + 交回探针              ──→ V_L（5 头集成）
                                      Pure MPC 回合 + 交回探针尾段        ──→ V_b（5 头集成）
部署期：  每个决策比较 V_L(s) 与 V_b(s)，保守切换（M4）→ 选分支 → T0 的 step_with_branch → MPC 执行
```

**SAC 训练和 V2 相比只差 T0 接口一个因子。** 仲裁用的两个价值都是在训练结束之后，对两个**固定**策略做评估，
方法相同、结构相同，比较才公平。**同一组网络，仲裁开 / 关就是两行结果**，不需要重训，这是本方法的核心消融。

> 为什么不直接用 SAC 自己的 critic 做仲裁：
> (1) SB3 的 SAC 用 critic 集成的最小值做训练目标，把 critic 数从 2 改到 5 会改变训练本身，混进第二个因子；
> (2) SAC 的 critic 评估的是**带熵项的随机策略**，部署用的是确定性动作；
> (3) 仓库有 critic 过估计的历史。训练后对确定性 π_L 单独做固定策略评估，这三个问题都绕开了。

## M1｜SAC 训练（与 V2 相同，只换接口）

- 参数化 `task_state_v3`（T0），观测同 T0.5，训练时分支恒为 `learned`；
- 超参与 V2 完全相同（γ 0.99、`ent_coef` 0.005 固定、`n_critics` 2、网络、学习率、batch 都不改）；
- 从零训练 60,000 决策 × 3 种子（262420 / 421 / 422）；manifest 记录 `parametrization=task_state_v3`；
- **这一步的产物同时就是"修好接口的普通层级 SAC→MPC"对照行。**

## M2｜数据收集（训练后，每个模型分别收集）

训练种子块 **270000–270047**（48 个，与评估块 262000–262047、校准块 262100–262111 都不重叠）。每个种子跑：

| 回合 | 用途 |
|---|---|
| Pure MPC 全程 | V_b |
| π_L（确定性）全程 | V_L |
| π_L 跑到第 k 个决策，然后交回 Pure MPC（k 在 [0, 回合长度) 里均匀抽 2 个） | V_b 在学习策略到过的状态上的数据 |

每个模型 48 × 4 = 192 回合，可并行（任务级数字与进程数无关）。

**为什么必须有交回探针**：P2 证明 Pure MPC 在学习策略带到的状态上可能失败（硬约束失败、飞出）。
V_b 没见过这些状态就会高估，仲裁就会把系统交回一个接不住的 Pure MPC。

逐决策记录：策略观测、分支、决策奖励（env 已在决策内求和）、终止标志、下一观测。

## M3｜固定策略评估：V_L 与 V_b

- **网络**：每个价值 5 个独立 MLP（与 SAC critic 同宽），输入为策略观测（去掉 mode 位），输出标量；
- **目标**：决策级 TD(0)，`V(s) ← r + 0.99 · V⁻(s')`，终止时不自举；
  - V_b 只用 `baseline` 分支的转移（Pure MPC 全程回合 + 探针尾段）；
  - V_L 只用 `learned` 分支的转移（π_L 全程回合 + 探针的前段）；
- 奖励与 SAC 训练完全相同（同一个 env 奖励）；
- 每个头用不同的随机初始化和不同的自助采样（bootstrap）；
- 另外对 5 个头报一次蒙特卡洛回报的拟合误差，作为健康检查。

## M4｜仲裁：保守切换（部署期）

每个决策：
```
μ_L, σ_L = V_L(s) 5 个头的均值与标准差
μ_B, σ_B = V_b(s) 5 个头的均值与标准差
当前在 baseline：  若 μ_L − z·σ_L > μ_B + z·σ_B，切到 learned
当前在 learned：   若 μ_B − z·σ_B > μ_L + z·σ_L，切回 baseline
否则保持当前分支
```
- **初始分支为 baseline**，第 0 个决策就做判断；
- learned 分支执行确定性动作 `π_L(s)`；
- z = 1.0，是保守的工程判据，**不宣称概率含义**；
- 两个方向对称：都要求对方"有把握地更好"才切换。这同时起到驻留作用，并防止在 V_b 没见过的状态上贸然交回；
- 切到 baseline 时按 T0.4 调用 `controller.reset()`；切到 learned 时按 T0.4 连续初始化 z；
- 额外在线计算只有 10 次小网络前向（每 2 s 一次），**不增加 MPC 求解**。

## M5｜正式评估（M6 通过后才跑）

`experiments/evaluate_hybrid_policy.py` 增加 `--arbiter {off,conservative}`、`--learned-value <path>`、`--baseline-value <path>`。
每个种子、评估块 262000–262047，跑两行：
- **learned-only**（`--arbiter off`，即普通层级 SAC→MPC）；
- **arbitrated**（`--arbiter conservative`）。

每回合额外记录：逐决策分支、μ/σ 四个量、切换次数、学习分支占比。

## M6｜正式评估前的校准检查（P3，必须先过）

用评估块之外的 12 个种子（262100–262111），对每个训练好的种子：
- 在第 0、10、20 个决策的状态上，用精确 rollout 得到"学习策略继续到底"和"交回 Pure MPC"的真实回报（沿用 `experiments/probe_base_policy_rollout.py` 的做法，学习策略继续时用模型）；
- 与 μ_L、μ_B 比较，报：两者差的**符号正确率**、平均绝对误差，以及 σ 与误差的相关系数。

| 观测 | 动作 |
|---|---|
| 符号正确率 ≥ 80% | 进入 M5 正式评估 |
| < 80% | 停，报上层；不做正式评估 |

## 6. 预注册判读（正式评估，每个种子分别看，不合并）

| 指标 | arbitrated 行的通过条件 |
|---|---|
| 完成 | ≥ 36/48（不低于 Pure MPC） |
| destroyed | ≤ 2 |
| rescued | ≥ 1 |
| 学习分支占比（回合平均） | ≥ 5%，否则记为 **coupling inactive**，不得解释为方法成功 |
| 真值违约 | 不多于 Pure MPC |

- **≥ 2 个种子通过**：方法成立，写结论；第三个种子如实报告；
- **死种子**（learned-only 为 0/48）：arbitrated 行应退回 Pure MPC（约 36/48），记为"仲裁保住了基线"，**不算作学习层有效**；
- learned-only 行是普通层级对照，不设通过条件。

## 7. 不做的事

- 不做动作层残差 / β 分级（P2 已证明短偏离拿不到价值）；
- 不把 MPC 预测塞进价值（Q = M + D）：等本方法跑通后作为改进项；
- 不改奖励、MPC、任务参数；
- 不加干预惩罚、课程、双 critic 以外的机制。

M5 的三个数；所有产物路径与 SHA-256；提交号。
