# 07 对比方法与消融：各自改动了什么

所有学习方法共用同一执行层、同一策略观测、同一动作空间、同一训练分布与交互预算（5000 次决策 × 3 个种子），只在下表列出的地方不同。

| 方法 | 评价器读 z_E | 训练时认证 | 执行时认证 | 旋转引导 | 学习算法 |
|---|---|---|---|---|---|
| ECC（本文） | 是 | 是 | 是 | 是 | SAC |
| SAC–MPC | 否 | 否 | 否 | 是 | SAC |
| TD3–MPC | 否 | 否 | 否 | 是 | TD3 |
| ECC w/o 认证 | 是 | 否 | 否 | 是 | SAC |
| ECC w/o 执行反馈 | 否 | 是 | 是 | 是 | SAC |
| ECC w/o 旋转引导 | 是 | 是 | 是 | 否 | SAC |

- **2 × 2 归因：** "执行反馈 {无, 有} × 认证 {无, 训练与执行都开}"四格，对应 SAC–MPC、ECC w/o 执行反馈、ECC w/o 认证、ECC。四个组都从零训练。
- **ECC w/o 旋转引导：** 阶段目标只沿视线接近，去掉纬向调节与沿扫掠分量（第 03 节第 3.6 节）。认证的模式预测用的是同一个执行层。
- **容量：** 评价器读 z_E 时输入层更宽，即 48 维对 24 维。开发期做过一个等宽对照（评价器后半段重复策略观测），正式实验不再单设，论文如实说明这一混杂。

## 不训练的方法与只评估的对照

| 名称 | 内容 | 性质 |
|---|---|---|
| 纯 MPC | 同一近场 MPC 从初始时刻起以固定终端设定点直接控制，没有高层与阶段层 | 传统控制基线，确定性，每个初始条件一次 |
| 直接入口规划 | 入口规划器从远场直接规划最早可行入口，丢失时重新规划 | 动作空间外的参照，不要求 ECC 胜过它 |
| ECC 执行时关认证 | 同一 ECC 模型，评估时关闭认证 | 检验认证在执行时的作用 |
| ECC w/o 认证 + 执行时认证 | 同一模型，只在评估时加认证 | "事后加认证"的边际作用 |
| SAC–MPC + 执行时认证 | 同一模型，只在评估时加认证 | 认证对无反馈策略的作用 |
| ECC 关闭重定时 | 同一 ECC 模型，入口固定原到达时刻 | 检验入口重定时。该开关同时作用于模式预测，属于系统层面的敏感性 |

只评估的对照是固定策略上的执行对照，不等同于从零训练的归因。

测试条件（紧急 U、经济 E、自然混合 N）、终点、统计方法与图表见 `../EXPERIMENTS.md`。
