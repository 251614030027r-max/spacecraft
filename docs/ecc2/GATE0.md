# ECC 第二版：设计要点与第 0 关离线可行性审查（规格与判据）

**状态（2026-11-18）：** 方向经用户认可，进入离线审查；不实现新学习器、不训练。本文件先于审查结果入库，判据不因结果修改。第一轮正式实验（四个训练组）此后视为开发证据，剩余的组不再运行（用户 2026-11-17）。

## 1. 设计要点（待第 0 关检验）

**执行后果门控的选项价值学习。** RWG、规划器、MPC、模式预测都不动。

- **选项：** 每次决策（模式 S / H），执行器对 3 × 3 意图网格 𝔅 做 48 s 模式预测。每个候选 b 是一个可中断选项（保持 b 一个阶段，16 s 后重新决策），后果为 c_b = (ê_b, τ̂_b, Δv̂_b, 事件类型)。
- **评价器：** Q(x, b) = ê_b · H(o, τ̂_b, Δv̂_b, 类型) + (1 − ê_b) · G(o, b, Δv̂_b)。
  - H 不读意图本身，后果相同的选项共享价值；
  - G 读意图；
  - 价值只从真实转移学习，执行器预测从不作为学习目标。
- **策略：** π(b | x) ∝ exp(Q(x, b)/α)，执行时取 argmax，没有单独的认证规则。
- **唯一消融：** 同一选项集、同一训练预算、同一学习框架（离散软 Q），评价器只读 (o, b)、不读后果，执行时套用现有认证规则。新方法与消融的唯一差别是"是否利用执行器预测的后果"。

**设计依赖三个假设，第 0 关逐一检查：**

1. 现有认证器还留有可改进的空间，而且这个空间能用后果信息识别出来；
2. 后果相近的候选，真实长期价值相近（H 不读意图不会造成价值混淆）；
3. 3 × 3 网格能覆盖有效的控制动作。

**理论边界（写作时以此为准）：**

- 能说：后果特征是 (x, b) 的确定函数；理想化、可表示的情形下，不动点是闭环真实的价值，预测误差不进入学习目标；H 的不动点是真实结局在后果类上的条件期望（需要后果充分性）；同一选项集上，任何"策略加认证规则"都属于新方法优化的策略类。
- 不能说：神经网络训练无偏、收敛，或者实际性能必然优于认证规则。

| 读数 | 定义 | 用途 |
|---|---|---|
| A1 失败构成 | 每个失败回合按顺序归类：F0 整回合没有任何候选预测事件；F1 认证介入过；F2 执行过原意图自带的事件；F3 有事件候选但未利用（再按是否有关键窗口候选拆分） | F0 是选项层面救不回的部分；F1–F3 是可改进空间的上限 |
| A2 网格的后果覆盖 | 未被认证修改、且原意图预测有事件的决策中，网格里存在同类型、事件时刻相差 ≤ 4 s 的候选的比例 | 预测层面的网格覆盖 |

## 3. 第 0 关 B 部分：分支重放（开发初始条件，不训练）

- **基准策略：** 第一轮 ECC 的三个模型（种子 20–22），按训练时的设置带认证器飞行，确定性动作，强制紧急任务。
- **初始条件：** 开发段 294000–294063（不使用正式段）。
- **分支：**
  - 范围：所有失败回合的全部"机会决策"（至少一个候选预测事件），以及 294000–294009 中成功回合的机会决策；
  - 做法：在该决策处分别强制 9 个网格选项（认证器照常运行，只替换实际飞行的意图），之后由同一策略加认证器飞到终局；
  - 确定性检查：每个回合第一个分支决策另做一条参考分支，强制原执行意图，必须复现原回合。

**读数与判据（事先固定）：**

| 编号 | 读数 | 通过线 | 不通过时 |
|---|---|---|---|
| B0 | 参考分支全部复现原回合（结局相同，回报差 ≤ 1e-6） | 全部复现 | 读出作废，先查原因 |
| B1 可改进空间 | 失败的基准回合中，至少一个单决策选项分支能转为捕获的比例 | ≥ 25% | **停止**：认证器留下的空间不足，保留认证器，重新设计 |
| B2 后果充分性 | 同一决策内的事件候选两两比较：后果相近（同类型、Δτ̂ ≤ 4 s、ΔΔv̂ ≤ 0.05 m/s）的配对捕获不一致率 D_same，与后果不同的配对 D_diff 对比 | D_same ≤ 15% 且 D_same ≤ D_diff / 2 | **调整**：H 改为读粗粒度意图（沿扫掠分量的符号），用同样的数据重新检查 |
| B3 后果选择的价值 | 按初始条件三折交叉：用其余两折的分支结局，估计"事件类型 × 事件时刻分档"的捕获率表；在本折每个机会决策中，按表选事件候选，与原策略加认证器的实际选择比较捕获 | 捕获差的 95% 区间下界（按初始条件自助）> 0 | **停止**：后果信息不足以改进现有选择 |
| B4 网格覆盖 | 原策略飞了网格外的意图并捕获的决策中，至少一个网格选项也捕获的比例 | ≥ 90% | **调整**：换成更细的网格（4 × 3），先用 A2 检查预测层面的覆盖 |

- **B3 的意义：** 它是新方法"策略改进一步"的离线模拟，不是学习结果。通过只说明杠杆存在。
- **结论：** B0、B1、B3 都通过，第 0 关通过，进入第 1 关（开发期小规模训练，另立规格）；需要调整时，按上表调整后只复查对应项。

## 4. 成本与产物

- **成本：** 基准 3 × 64 个回合；每个回合约 4 个机会决策，分支约 2,000–2,500 条，每条是一次完整重放。沙箱实测一回合约 42 s（开发初始条件 294000，固定意图 (1, 0)），8 个进程约 4–8 小时，以下层实测为准。
- **沙箱验证：** 参考分支逐位复现原回合（294000，回报 79.8507654954925）；读出逻辑由 `tests/test_ecc2_gate0.py` 在合成记录上检查。
- **脚本：** `experiments/ecc2_gate0.py`（`logs` / `branch` / `report`），只读，不修改方法代码。
- **证据：** `evidence/ECC2_GATE0/`，包括 A、B 两部分的读数 JSON、基准与分支结局的汇总表、SHA256SUMS。
