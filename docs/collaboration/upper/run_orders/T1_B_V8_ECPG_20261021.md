## 0. 一句话

ECPG 按研究层方案实现（A：MPC 偏好经事件感知 CE 进入 Actor，critic 只用真实 TD；B：≤3 logits 的掩码分类意图头；C：训练分布状态的全候选 V7 标签；`verify_at_deploy` 开关，同协议公平消融）。上层预检表明：**不加部署核验时，任何学习选择器在留出状态上都不超过“总是最早”**（即使用真值标签做 CE 上界也是 −3 左右），原因是学习空间是稀有事件：79 个有真值的状态里，oracle 增益 75 % 来自 2 个“最早耗尽、最晚成功”的救援状态，其余是 ±5 的小差，而在最早能成功的状态里，约 20 % 的非最早候选是灾难（24/123）。能学会、且已经学会的是**风险**：真实 TD 的 critic 对“最早会失败”的排序（开发块 AUC 1.0；离线分类器在确认/独立块 0.83/0.98）。因此 V8 的可交付结果走研究层预留的阶段 III 路线，并把它做成预登记的主方法：

> **学习的意图策略提议 + 真实 TD critic 判定风险 → 只在“偏离最早”或“Q(提议) < 0”时调用全时域 MPC 核验 → 执行预测成功中回报最高的候选。**

论文主张随之收窄为“计算受限的学习—预测混合意图决策”：学习决定**何处**花 MPC 计算，MPC 决定**选什么**。性能主要来自模型推演，必须如实写明。λ（训练期 CE）的独立贡献照常报告，不作为通过条件。
