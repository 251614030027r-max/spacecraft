## 1. 算法

**设定。** 高层每 16 s 给出意图 a；受约束执行器 E 有离散模式（阶段、保持、入口、下降），由自身门槛与规划器决定何时切换到入口模式。E 的预测模型 Ê 包括：阶段规划器、恒角速度姿态预报、2 s 入口门槛、条件 G★。

**执行机会函数。**
- 定义：ω(s, a) = (σ, τ, c)。从 s 出发保持意图 a，Ê 在时域 H（3 个阶段）内：
  - σ：是否切换到入口模式；
  - τ：何时切换；
  - c：到切换为止的规划 Δv，以及入口规划 Δv。
- 性质：只由执行器模型计算，不学习，不用训练历史，不估计回报。它回答"换一个意图，执行会怎样"，只回答执行事件，不回答长期价值。

**机会证书。**
- 探测集 B 固定（实现：动作盒上均匀的 3 × 3）。
- 过顶约束 β(s, τ)：t + τ + 2π/|ω_target| > T_d − Δ_m。即错过这次切换，期限前不再有可接受的入口；Δ_m 为条件 G★ 的期限余量。
- 资源条件 ρ(s, b)：已用 Δv + c ≤ 预算。
- **认证集：** A★(s) = { b ∈ B：σ(s, b) = 1，β(s, τ_b) 成立，ρ(s, b) 成立 }。
- **证书：** Ω(s) 由两部分组成：
  - 认证集指示与最早可认证切换时刻（动作层）；
  - 执行器对当前过顶的判断（过顶层：过境时机、窗口可达、截止余量）及执行状态。

**认证映射。**
- σ(s, a) = 1 或 A★(s) 为空时，C(s, a) = a；
- 否则 C(s, a) = A★(s) 中离 a 最近者，距离相同取切换更早者。

**闭环（训练与部署相同）。**
1. 意图提出：a ~ π(·|s)，actor 只读决策层观测。
2. 执行反馈：E 出具 Ω(s)。
3. 决策协调：执行 C(s, a)。
4. 真实执行：真值 RK45、冻结 MPC。
5. 价值更新：经验池存提出的 a，critic Q(s, Ω(s), a) 只用真实转移做 TD。

**信息边界。** 所有配置的决策层观测都不含：
- 规划答案（过境时间、窗口可达、截止余量）；
- 执行器内部执行状态（上一段位置 / 速度残差、保持标志）。

执行器知识只经证书进入学习，经认证进入决策。

## 2. 性质（假设写明；与代码一致）

**P1 闭环一致、无价值标签。**
- C 与 Ω 都是状态（与意图）的确定函数。智能体学习的是认证 MDP：M_C 的转移为 P(·|s, C(s, a))，奖励为真实奖励。
- Ω 是状态函数，作为 critic 输入不改变 M_C 的 Bellman 不动点。
- 目标全部来自真实执行，没有模型生成的长期价值标签。
- 训练与部署使用同一个 M_C。

**P2 局部执行知识决定长期价值的断崖（引理）。**
- 条件：在 β 成立的状态，错过这次过顶期限前不再有可接受的入口。
- 结论：本回合终局（捕获 / 超时）取决于时域 H 内是否发生入口切换。因此执行器 H 内的局部知识，确定了跨多个决策周期的长期价值断崖在动作空间中的位置；Ω 把它交给 critic，C 去掉断崖坏的一侧。
- 证据：两批开局、所有配置，失败全部是紧急任务超时。

**P3 认证的条件性改进。**
- 条件：Ê 在 H 内对 a 与 b 准确，且 β 成立。
- 结论：若 C 介入，"保持 a"错过最后一个可接受的过顶，C(s, a) 在期限前切换到入口。
- 只保证入口切换，不保证捕获或安全：入口后的结局由冻结 MPC 与真值决定。
- 模型不准时，误判（预测切换而未切换）由实测精度约束：阶段 A 为 0.80。

**P4 可迁移。** 算法接口只有四样：执行器预测模型（含模式门槛）、探测集 B、时域 H、约束判定（任务期限与机会复现周期）。换任务或换规划器时只替换 ω 的实现，P1 不变；P2、P3 在相应假设下成立。

**不主张：** 预测可行即真实回报改善；安全保证；超过动作空间外的直接 G★。

## 3. 本轮（阶段 `ecc`）

**训练。** 三个配置 × 种子 10、11 × 2000 决策，从零训练，统一信息边界：

| 配置 | 决策层 | critic | 认证 |
|---|---|---|---|
| `SAC_C` | 24 | 24 | 关 |
| `EACH_C` | 24 | 48（含过顶层证书） | 关 |
| `ECC` | 24 | 58（另含动作层证书） | 训练与部署均开 |

**评估。** 新开局 294320–294367，按种子、按开局配对，共 96 对：
- 三个配置按训练方式各评估一次；
- ECC 另评一次认证关闭；
- EACH_C 另评一次部署认证。

**判定顺序（`experiments/ecc_readout.py`）：**
1. ECC 对 SAC_C 通过 G1–G5，且 ECC 对 EACH_C 不退化（均值差 ≥ −8.3、捕获 ≥ EACH_C − 4、unsafe 0）→ 最终方法 **ECC**。
2. 否则，若 EACH_C + 部署认证 对 SAC_C 通过 G1–G5 → 最终方法为**部署认证的 ECC**（critic 只读过顶层证书），并如实报告完整 ECC。
3. 否则 → 如实报告，不追加。

**只报告：** 同一 ECC 模型认证开 / 关、EACH_C 对 SAC_C、训练曲线、介入次数。

**G1–G5**（`experiments/u2_readout.py`）：
- G1：均值 ≥ 8.3，或捕获 ≥ +4；
- G2：去掉每种子最大的两个正差后 > 0；
- G3：两个种子都 > 0；
- G4：捕获不少于对照；
- G5：unsafe 为 0。

**通过后：** 冻结，进入正式实验（另行写执行书）。
