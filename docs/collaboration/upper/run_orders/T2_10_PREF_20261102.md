## 方法与接口（研究层 2026-11-02 意见）

**新反馈：执行器校准的机会偏好（arm `e_pref`）**
- **信号：** 每个阶段决策上，对 3 × 3 意图网格和实际执行的意图，各算一个"机会价值"：从该意图的阶段目标末态出发，执行器在剩余时间内最早可行的条件 G★ 入口，用入口结果模型（历史真实执行偏差重放）判断捕获或超时，以及时间与燃料。
- **用法：** 价值差 ≥ 5 的候选对，要求 critic 按同样顺序排开，间隔不小于价值差的一半（上限 100）。这是单边铰链损失，权重 10。
- **不做的事：** 不回归执行器给出的数值，也不替策略执行动作（不同于 T2.7 引导）。
- **与 P4 的关系：** 信号与 P4 验证的 `opp2` 完全相同，有测试保证。

**接口 `reduced`（两组相同）：** 只去掉三个直接给出规划答案的量：到下次过境的时间、入口窗口是否可达、过境后的截止余量。相对运动、目标几何、时间、燃料、制动余量与执行状态全部保留。

**对照：** SAC（`e_sac`）与 SAC + 机会偏好（`e_pref`），同一接口、同一执行器，均从零训练，各种子 0、1，每条 2000 步。

## 1. 训练与评估（变量名不与路径变量重名）

```powershell
$T0 = Get-Date
$jobs = @()
foreach ($armName in "e_pref","e_sac") { foreach ($seedNo in 0,1) {
  $runDir = "$Out\B\TRAIN_${armName}_s$seedNo"
  $jobs += Start-Process -FilePath $py -WorkingDirectory "D:\py\DRL2" -WindowStyle Hidden -PassThru `
    -ArgumentList "-B","-m","experiments.t2","train","--arm",$armName,"--seed",$seedNo,"--steps","2000","--workers","2","--urgent-deadline","140,200",
                  "--obs","reduced","--checkpoints","500,1000,1500","--output",$runDir `
    -RedirectStandardOutput "$runDir.out.log" -RedirectStandardError "$runDir.err.log" } }
while (@($jobs | Where-Object { -not $_.HasExited }).Count -gt 0) { Start-Sleep -Seconds 300 }
"training done $(((Get-Date) - $T0).TotalHours) h" | Out-File -Encoding utf8 "$Out\timeline.log"
foreach ($stepNo in 2000,1000,1500,500) { foreach ($runName in "e_pref_s0","e_pref_s1","e_sac_s0","e_sac_s1") {
  & $py -B -m experiments.t2 eval --checkpoint "$Out\B\TRAIN_$runName\checkpoints\step_$stepNo.zip" --label "${runName}_step_$stepNo" `
    --openings 294000-294047 --urgent-deadline 140,200 --workers 10 --output "$Out\C\$runName\step_$stepNo" *>> "$Out\eval.log" }
  "eval step_$stepNo done $(((Get-Date) - $T0).TotalHours) h" | Out-File -Encoding utf8 -Append "$Out\timeline.log" }
& $py -B -m experiments.t2_readout curve --eval-root "$Out\C" --train-root "$Out\B" --screen "$Out\A_none" --expected 48 --output "$Out\READOUT.json" *> "$Out\readout.log"
& $py -B -m experiments.t2_decide --criteria t28 --checkpoints 1000,2000 --readout "$Out\READOUT.json" --train-root "$Out\B" --output "$Out\DECISION.json" *> "$Out\decide.log"
$ckList = @()
foreach ($runName in "e_pref_s0","e_pref_s1","e_sac_s0","e_sac_s1") { foreach ($stepNo in 500,1000,1500,2000) {
  $ckList += "${runName}_${stepNo}=$Out\B\TRAIN_$runName\checkpoints\step_$stepNo.zip" } }
& $py -B -m experiments.t2_keyscore --states "C:\Users\35884\Documents\Spacecraft\过程文件\T2_8_P4_INFO_20261102\info" --checkpoints $ckList --output "$Out\KEYSCORE_T210.json" *> "$Out\keyscore.log"
```
