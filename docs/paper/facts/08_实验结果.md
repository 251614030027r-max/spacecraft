# 08 仿真实验结果（第二轮正式实验，论文最终数据）

数字都来自 `evidence/R2_FORMAL/`，由 `python -B -m experiments.formal_r2_readout` 生成。作图数据：

| 文件 | 内容 |
|---|---|
| `TRAINING_CURVES.csv`、`runs/*/tb/` | 学习曲线（决策数为横轴，每 100 回合窗口）：捕获率、真实回报、修正与直接入口次数 |
| `traj/`、`CASES.json` | 两个案例的真值轨迹与每次决策的协调记录（每 2 s） |
| `MAIN_TABLE.csv`、`PAIRED.csv` | 各组结局（逐种子与合计）；配对差、区间、翻转数 |
| `EPISODES_WIDE.csv` | 逐种子、逐初始条件的结局、回报、时间、Δv、期限、初始自旋率 |
| `STRATIFIED.csv`、`COORDINATION_USAGE.csv`、`COMPUTE.csv`、`SAFETY.json` | 分层、协调构成、协调耗时、不安全回合 |

第一稿的结果在 `docs/archive/facts/08_实验结果_第一稿.md`，不与本节混用。

## 8.1 设置

- **训练：** 每组 3 个种子 × 6000 次高层决策，从零训练（第 06 节）。
- **测试：** 192 个训练中未出现的初始条件；学习方法每组 3 个种子 × 192 = 576 个任务，评估最终模型、确定性策略；非学习策略各 192 个任务。各方法在同一批初始条件上配对。
- **指标：** 捕获率与失败原因（超时、不安全、燃料耗尽）；双方都捕获的任务上的完成时间与 Δv；真实回报。
- **统计：** 配对差的 95% 区间用自助法：在每个种子内按初始条件重采样 10,000 次。非学习策略与每个种子分别配对。

## 8.2 训练过程（`TRAINING_CURVES.csv`）

训练捕获率，前 1/5 训练 → 后 1/5：

| 方法 | 种子 30 | 种子 31 | 种子 32 |
|---|---|---|---|
| ECC | 0.72 → 0.78 | 0.80 → 0.93 | 0.81 → 0.86 |
| SAC–MPC | 0.61 → 0.85 | 0.41 → 0.69 | 0.56 → 0.77 |
| TD3–MPC | 0.66 → 0.74 | 0.56 → 0.63 | 0.48 → 0.65 |

ECC 每回合的修正次数，前 1/5 → 后 1/5：1.23 → 1.17、0.72 → 0.39、0.70 → 0.53。直接入口次数：0.17 → 0.17、0.14 → 0.18、0.14 → 0.17（全程每回合 0.10–0.26 次）。

- ECC 从训练初期起捕获率就更高，三个种子更一致。
- 按决策计（修正次数 / 阶段决策数，由 `runs/*/episodes.json` 计算）：0.275 → 0.276、0.171 → 0.119、0.190 → 0.146；每回合决策数同时减少（4.5 → 4.3、4.2 → 3.3、3.9 → 3.6）。修正比例在种子 31、32 下降，种子 30 不变，只作观察描述，不作为"策略已学会"的证据。
- 训练捕获率含探索噪声，与确定性评估的捕获率不是同一个量。

## 8.3 案例（种子 30 的最终模型；轨迹 `traj/`）

选取规则事先确定：A 为 ECC 全程无修正、SAC–MPC 也捕获的典型任务；B 为 ECC 有修正且捕获、SAC–MPC 超时的任务。

**案例 A（301001，期限 176.2 s）：完整捕获过程**

| | ECC | SAC–MPC |
|---|---|---|
| 协调 | 2 次决策都保持（自己的意图预测能触发入口） | — |
| 入口转移开始 | 32 s（距离 10.8 m） | 26 s（11.9 m） |
| 入口重定时 | 3 次（50、62、80 s，各 +4 s） | 4 次 |
| 末段下降开始 | 94 s | 96 s |
| 捕获 | 143.6 s，Δv 1.84 m/s | 142.8 s，Δv 2.03 m/s |

**案例 B（301025，期限 147.8 s，初始纬向偏差约 −50°）：关键窗口**

| | ECC | SAC–MPC |
|---|---|---|
| 0 s | 保持（预测 40 s 后入口） | 意图直接执行 |
| 16 s | 自己的意图 (0.67, 0.10) 在 48 s 内无事件；修正为 (1, 1)，预测 24 s 后入口 | 意图直接执行 |
| 32、48 s | 保持 | 继续阶段飞行，共 7 次决策，始终没有形成入口 |
| 入口转移 | 50 s（8.6 m）开始；78 s 重定时一次（+2 s，备用力界） | 无 |
| 末段下降 | 96 s | 100 s 由阶段飞行直接进入下降区 |
| 结局 | 133.0 s 捕获，Δv 1.20 m/s | 147.8 s 超时（已接近捕获点） |

**案例 B 的补充（轨迹读数）：** 端口–视线夹角 ψ 降到入口门限 35° 以下，ECC 约在 81 s（80 s 时 36.7°，82 s 时 32.3°），SAC–MPC 约在 95 s（94 s 时 37.0°，96 s 时 33.2°；100 s 时 26.6°）。SAC–MPC 超时时距捕获点 0.33 m；ECC 捕获时 0.19 m。

**逐控制周期记录（`evidence/R2_ASSETS/traj_fine/`）：** 上面四条轨迹的逐 0.1 s 重放（`trace`：本体系推力 / 力矩、碰撞间隙、走廊、相机视场裕度（视场角 = 50° − 裕度）、径向 / 轴向制动包络与总速度裕度（只在各自适用区域有值）、四类误差、累计 Δv）。结局、时间、Δv 与 `traj/` 完全一致。

模式切换时刻取决策记录中的事件时刻（`true_mode_event_t`）；轨迹每 2 s 一行，某行的 `mode` 是该时刻模式检查之前的模式，所以新模式首次出现在切换后的下一行。两个案例的 ECC 与 SAC–MPC 是各自训练的模型。

## 8.4 主结果

| 方法 | 捕获 | 捕获率 | 种子 30 / 31 / 32 | 超时 | 不安全 | 燃料耗尽 | 平均真实回报 |
|---|---|---|---|---|---|---|---|
| **ECC** | **492 / 576** | **85.4%** | 156 / 169 / 167 | 83 | 1 | 0 | **45.4** |
| SAC–MPC | 425 / 576 | 73.8% | 149 / 131 / 145 | 151 | 0 | 0 | 21.4 |
| TD3–MPC | 368 / 576 | 63.9% | 135 / 124 / 109 | 206 | 2 | 0 | 0.7 |
| MPC | 85 / 192 | 44.3% | — | 48 | 31 | 28 | −53.8 |

**配对比较：**

| 比较 | 捕获率差 [95% 区间] | 逐种子（个数） | 仅前者 / 仅后者捕获 | 回报差 [95% 区间] |
|---|---|---|---|---|
| ECC 对 SAC–MPC | **+11.6 [+8.3, +15.1]** | +7 / +38 / +22 | 90 / 23 | +24.0 [+17.0, +31.1] |
| ECC 对 TD3–MPC | **+21.5 [+17.7, +25.3]** | +21 / +45 / +58 | 142 / 18 | +44.8 [+36.6, +52.9] |
| ECC 对 MPC | **+41.1 [+35.8, +46.4]** | +71 / +84 / +82 | 289 / 52 | +99.2 [+87.6, +110.4] |

**效率：**
- 成功任务的完成时间 / Δv 中位数：ECC 119.5 s / 1.22 m/s，SAC–MPC 120.9 s / 1.19 m/s，TD3–MPC 123.4 s / 1.21 m/s，MPC 129.1 s / 1.55 m/s。
- 双方都捕获的 402 个任务上（ECC 减 SAC–MPC）：完成时间均值差 −1.6 s [−3.1, −0.1]（逐种子 +0.7 / −2.6 / −2.7），中位差 +0.3 s；Δv 均值差 +0.006 m/s [−0.010, +0.023]，中位差 +0.001 m/s。效率相当（时间相差不到 2%，Δv 无差别），提升来自按期捕获的任务更多。
- 对 MPC（双方都捕获的 203 个任务）：完成时间均值短 28.0 s [23.3, 32.6]（中位差 27.2 s），Δv 均值少 0.44 m/s [0.38, 0.50]（中位差 0.35 m/s）。

## 8.5 RWG 检验

| 旋转同步意图：固定意图 (1, 0) 带 / 不带旋转引导（192 个任务） | 103 / 64 | **+20.3 [+14.6, +26.0]** | 39 / 0 |

## 8.6 闭环的表现

**期限分层（`STRATIFIED.csv`）：** 前三档增益 13.3、15.9、13.4 个百分点，最宽一档 3.1：紧迫任务上增益明显大于宽松任务，但不是严格单调。

| 期限 | ECC | SAC–MPC |
|---|---|---|
| 140–155 s | 70.0% | 56.7% |
| 155–170 s | 79.7% | 63.8% |
| 170–185 s | 95.5% | 82.1% |
| 185–200 s | 97.0% | 93.9% |

初始自旋率三档（2.11–2.29、2.29–2.50、2.50–2.70 °/s）的捕获率：ECC 84.4% / 87.0% / 84.9%，SAC–MPC 72.4% / 74.0% / 75.0%，对自旋率不敏感。

**评估时的协调构成（`COORDINATION_USAGE.csv`，占全部决策）：**

| ECC 种子 | 保持 | 修正 | 启动直接入口 | 不动 |
|---|---|---|---|---|
| 30 | 33.0% | 26.7% | 5.8% | 34.5% |
| 31 | 55.0% | 14.9% | 5.7% | 24.3% |
| 32 | 58.4% | 12.1% | 6.0% | 23.5% |

"不动"指意图预测不能触发事件、也没有关键机会，照原意图执行。

**计算（`COMPUTE.csv`）：** 每次协调的墙钟耗时中位数 1.50 s，95 分位 3.75 s，最大 10.36 s（2042 次决策），均小于 16 s 的决策周期。ECC 的评估在一台 Windows 11 台式机上并行运行，耗时在并行负载下测得；CPU 型号未记录，论文写"桌面计算机、并行评估负载下的墙钟时间"即可，不写型号。

## 8.6a 鲁棒性（`evidence/R2_ASSETS/`，只评估，正式最终模型，同一批 192 个测试初始条件）

每次只改一项分布，其余与正式实验相同。

| 条件 | ECC | SAC–MPC | ECC 对 SAC–MPC [95% 区间] | 逐种子 | 仅 ECC / 仅 SAC–MPC |
|---|---|---|---|---|---|
| 正式（自旋 2.1–2.7 °/s，自旋轴偏离 10–20°） | 492/576（85.4%） | 425/576（73.8%） | +11.6 [+8.3, +15.1] | +7 / +38 / +22 | 90 / 23 |
| 低自旋 1.5–2.1 °/s | 493/576（85.6%） | 364/576（63.2%） | **+22.4 [+18.6, +26.2]** | +22 / +67 / +40 | 146 / 17 |
| 强章动：自旋轴偏离 20–40°（恒角速度预报失配更大） | 498/576（86.5%） | 415/576（72.0%） | **+14.4 [+10.8, +18.1]** | +16 / +45 / +22 | 106 / 23 |

- ECC 在两种条件下都不退化；SAC–MPC 在低自旋下降 10.6 个百分点。
- 失败几乎都是超时：低自旋 ECC 超时 81、不安全 2，SAC–MPC 超时 211、不安全 1；强章动 ECC 超时 77、不安全 1，SAC–MPC 超时 159、不安全 2。
- 双方都捕获的任务上，时间与 Δv 的均值差区间都含 0。

**本稿不写的内容（数据在 `evidence/R2_ASSETS/`，见 `工程附注.md` 第 8 节）：** 高自旋 2.7–3.3 °/s（留待第三轮）、短期限 120–140 s（受任务时间限制）、终端误差统计（学习方法在判定捕获的瞬间误差贴近容差，是"连续满足 1 s 即结束"的判定方式所致，不是精度结论；论文只写"满足四项捕获容差并保持 1 s"）。

**安全（`SAFETY.json`）：** ECC 1 次不安全（种子 32，初始条件 301145），TD3–MPC 2 次，MPC 31 次，SAC–MPC 0 次。

## 8.7 范围与局限（供结论）

1. 只在仿真中验证；相对状态按完全可测处理，没有感知噪声。
2. 执行层只用恒速姿态预报和各向同性惯量估计。
3. 每组 3 个训练种子；区间反映的是初始条件间的差异。
4. 192 个测试初始条件中，191 个至少被某一方法或种子捕获；ECC 三个种子都捕获 152 个，都未捕获 19 个（由 `EPISODES_WIDE.csv` 计数）。剩下的差距主要在学习的一致性上。只用于结论的局限与未来工作，不进第 V 节结果。
