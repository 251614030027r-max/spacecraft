## 方法：EACC-A（执行信息增强的执行校准反事实耦合）

**依据：** `evidence/T2_8_P4_INFO_UPPER/`、`evidence/T2_11_SELFCHECK/`。P4 显示三点：
- 原 EACC 让 critic 的关键排序更准（截止窗口 0.65–0.75 对 0.52–0.68），但动作选择没有因此变好；
- 原接口里的 3 个规划答案已经替 SAC 判断了能否赶上窗口，反馈没有可补的余地；
- 规划器判断与真实执行不一致（221 对中有 210 对），用决策级执行校准后，留出块捕获预测从 0.70 提到 0.93。

**设计（两臂接口相同，部署相同）：**
- **接口：** 策略只看去掉 3 个规划答案的观测（到下次过境的时间、窗口是否可达、过境后的截止余量）。几何、运动、时间燃料、制动余量与执行状态保留。
- **执行器信息上传（主路）：** 每个真实状态和每个反事实预测状态，都附带执行器自己的判断（过境时间、窗口可达、截止余量、制动余量、执行残差与保持）。
  - EACC-A 的 critic 在训练中读取这些判断；
  - 反事实标签末端的价值估计因此带上执行器的窗口判断，补上原 EACC "超过 32 s 就看不见"的缺口；
  - 策略不读这些判断，部署时只用策略本身。
- **原 EACC 反事实标签（不变）：** M1 / M2 / M3、两阶段、截止终止。
- **决策级执行校准与可信优势（辅路）：**
  - 用本训练自己已执行决策的真实结局，在线拟合"机会特征 → 是否真的捕获"；
  - 先预测后观察的准确率 ≥ 0.8（至少 200 个结局）后才启用；
  - 对策略当前意图和更优候选的校准捕获概率差 ≥ 0.4 时，critic 加顺序约束，策略向更优候选拉近。
- **SAC 基线：** 同一环境进程、同一接口，critic 只读策略同样的观测，没有任何执行器信息。

## 1. 一次性脚本

把下面整段存为 `$Out\run.ps1`，文件须为带 BOM 的 UTF-8，用 `powershell -ExecutionPolicy Bypass -File "$Out\run.ps1"` 运行。变量名都不与路径变量 `$Out` 重名。

**时间规则（从脚本启动算起）：**
- 第 8.5 小时仍未训练完，就整树结束训练进程；
- 第 10.75 小时之后不再开始新的评估；
- 第 12 小时是硬上限。

**中途止损（四条训练都写出 1000 步检查点后，自动执行一次）：**
- 用 24 个开发开局（294000–294023）做一次快速评估，并作 `t28` 判定；
- 若 EACC-A 臂均值比 SAC 臂均值低 10 分或更多，立即停训；
- 若 EACC-A 任一条训练到 1000 步时反事实标签计数为 0（机制没有启用），也立即停训；
- 停训后照常评估已有检查点并交付。

```powershell
$py  = "D:\py\DRL2\.venv\Scripts\python.exe"; $Out = "C:\Users\35884\Documents\Spacecraft\过程文件\T2_11_EACCA_20261102"
Set-Location "D:\py\DRL2"; $env:OMP_NUM_THREADS = "1"; $env:MKL_NUM_THREADS = "1"; $env:OPENBLAS_NUM_THREADS = "1"
$T0 = Get-Date; $hours = { ((Get-Date) - $T0).TotalHours }
$runNames = @("e_acc_s0", "e_acc_s1", "e_sac_s0", "e_sac_s1")
"start $T0" | Out-File -Encoding utf8 "$Out\timeline.log"
$jobs = @()
foreach ($armName in "e_acc","e_sac") { foreach ($seedNo in 0,1) {
  $runDir = "$Out\B\TRAIN_${armName}_s$seedNo"
  $jobs += Start-Process -FilePath $py -WorkingDirectory "D:\py\DRL2" -WindowStyle Hidden -PassThru `
    -ArgumentList "-B","-m","experiments.t2","train","--arm",$armName,"--seed",$seedNo,"--steps","2000","--workers","2","--urgent-deadline","140,200",
                  "--obs","reduced_priv","--checkpoints","500,1000,1500","--output",$runDir `
    -RedirectStandardOutput "$runDir.out.log" -RedirectStandardError "$runDir.err.log" } }
$quickDone = $false; $stopped = ""
while (@($jobs | Where-Object { -not $_.HasExited }).Count -gt 0) {
  if ((& $hours) -ge 8.5) { $stopped = "8.5 h cap" }
  if ((-not $quickDone) -and (@($runNames | Where-Object { Test-Path "$Out\B\TRAIN_$_\checkpoints\step_1000.zip" }).Count -eq 4)) {
    foreach ($runName in $runNames) {
      & $py -B -m experiments.t2 eval --checkpoint "$Out\B\TRAIN_$runName\checkpoints\step_1000.zip" --label "${runName}_q1000" `
        --openings 294000-294023 --urgent-deadline 140,200 --workers 3 --output "$Out\Q\$runName\step_1000" *>> "$Out\quick_eval.log" }
    & $py -B -m experiments.t2_readout curve --eval-root "$Out\Q" --train-root "$Out\B" --screen "$Out\A_none" --expected 24 --output "$Out\QUICK_READOUT.json" *> "$Out\quick_readout.log"
    & $py -B -m experiments.t2_decide --criteria t28 --checkpoints 1000 --readout "$Out\QUICK_READOUT.json" --output "$Out\QUICK_DECISION.json" *> "$Out\quick_decide.log"
    $qd = Get-Content "$Out\QUICK_DECISION.json" -Raw | ConvertFrom-Json
    $labelsOff = @("e_acc_s0","e_acc_s1" | Where-Object { ((Get-Content "$Out\B\TRAIN_$_\heartbeat.json" -Raw | ConvertFrom-Json).replay.with_candidates) -le 0 }).Count
    "quick check at $(& $hours) h: arm_diff=$($qd.values.arm_diff) labels_off=$labelsOff" | Out-File -Encoding utf8 -Append "$Out\timeline.log"
    if (($qd.values.arm_diff -le -10) -or ($labelsOff -gt 0)) { $stopped = "mid-run stop at 1000" }
    $quickDone = $true }
  if ($stopped) {
    foreach ($job in $jobs) { if (-not $job.HasExited) { taskkill /T /F /PID $job.Id | Out-Null } }
    "training stopped: $stopped at $(& $hours) h" | Out-File -Encoding utf8 -Append "$Out\timeline.log"; break }
  Start-Sleep -Seconds 300 }
"training end $(& $hours) h" | Out-File -Encoding utf8 -Append "$Out\timeline.log"
$have = { param($stepNo) @($runNames | Where-Object { Test-Path "$Out\B\TRAIN_$_\checkpoints\step_$stepNo.zip" }).Count -eq 4 }
$evaluated = @()
foreach ($stepNo in 2000,1000,1500,500) {
  if ((& $hours) -ge 10.75) { "eval stop before step_$stepNo" | Out-File -Encoding utf8 -Append "$Out\timeline.log"; break }
  if (-not (& $have $stepNo)) { continue }
  foreach ($runName in $runNames) {
    & $py -B -m experiments.t2 eval --checkpoint "$Out\B\TRAIN_$runName\checkpoints\step_$stepNo.zip" --label "${runName}_step_$stepNo" `
      --openings 294000-294047 --urgent-deadline 140,200 --workers 10 --output "$Out\C\$runName\step_$stepNo" *>> "$Out\eval.log" }
  $evaluated += $stepNo; "eval step_$stepNo done $(& $hours) h" | Out-File -Encoding utf8 -Append "$Out\timeline.log" }
& $py -B -m experiments.t2_readout curve --eval-root "$Out\C" --train-root "$Out\B" --screen "$Out\A_none" --expected 48 --output "$Out\READOUT.json" *> "$Out\readout.log"
$dk = @(1000) + @(@(2000, 1500) | Where-Object { $evaluated -contains $_ } | Select-Object -First 1)
& $py -B -m experiments.t2_decide --criteria t28 --checkpoints (($dk | Where-Object { $_ }) -join ",") --readout "$Out\READOUT.json" --train-root "$Out\B" --output "$Out\DECISION.json" *> "$Out\decide.log"
$ckList = @()
foreach ($runName in $runNames) { foreach ($stepNo in 500,1000,1500,2000) {
  $zip = "$Out\B\TRAIN_$runName\checkpoints\step_$stepNo.zip"; if (Test-Path $zip) { $ckList += "${runName}_${stepNo}=$zip" } } }
& $py -B -m experiments.t2_keyscore --states evidence/T2_8_P4_INFO/info --checkpoints $ckList --output "$Out\KEYSCORE_T211.json" *> "$Out\keyscore.log"
"all done $(& $hours) h; decision checkpoints $($dk -join ',')" | Out-File -Encoding utf8 -Append "$Out\timeline.log"
```
