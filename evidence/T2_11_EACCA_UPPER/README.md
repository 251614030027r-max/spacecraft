## 结论边界

- **增益来源：** 主要是去掉 3 个规划答案后，普通 SAC 在紧急任务上学得慢。
  - 部署时紧急捕获 6–11/25（engineered SAC 为 18–20），训练中紧急捕获率约从 35% 升到 57%，经济任务 23/23。
  - EACC-A 在同一接口下回到 engineered SAC 的水平（AUC 25.79 对 25.78），策略不需要这 3 个特征。
- **论文主张：** 执行层训练期反馈替代人工设计的规划特征，而不是超过拿到全部特征的 SAC。
- **未拆分的部分：** "执行器判断输入 critic"与"反事实标签 + 校准"各自的贡献。不做消融就无法回答"是否只是非对称 actor-critic"。
- **证据性质：** 两个种子、开发开局，属开发验证，不是论文正式结果。
