## 一、事实定位，不要误判

1. 七个阶段动作全部由局部 SCP 采纳；真值终点两两间距最低 0.71m，中位 1.01m；影子与实际阶段位置误差 0.010m、速度误差 0.0013m/s，CF 能进入 critic，PBRS 与单测成立。**动作及训练机制接口可运行，不要推翻。**
2. 现有 SAC 阶段目标以零力惯性漂移为中心，\`d_max=0.70·(1.6/106)·12²/2≈0.761m\`，最大额外速度意图约 0.127m/s；而共模终点跟踪偏差 0.43–0.65m、速度 0.05–0.12m/s。中性动作名义 Δv=0，实际 MPC 消耗 Δv≈0.094m/s（292000），长 G★ 在同段也有相似方向的偏差，说明**固定单段计划缺少对真实跟踪误差的反馈补偿**，并非简单的 SCP 最优性失效。不得把“共享 MPC 固有偏差”误写成已证明 MPC 内核必有 bug：同时检查控制饱和/约束松弛/参考速度坐标、是否受执行器姿态 LOS 约束影响。
3. 预设 292001 从 13.9m 接近到 t≈40s 时 9.98m，但桥接仅在 \`r≤9m\` 测试且 \`angle≤25°\` 预过滤，后续远离并触发 30m unsafe。**未启动桥接不等于从未具备局部接入机会。** 292000/002 另有外漂问题。
4. 当前 \`geometric_rule\` 对 3 个需求分量**分别 clip 后再归一化**，可能把强烈径向制动需求和横向需求同时压到相近幅值。此规则只是非学习基线和通路诊断，不修改 SAC 动作语义来掩饰规则缺陷。

## 二、唯一修复包：只改局部阶段的执行闭环、桥接和冻结规则

**A. 局部 G★ 加入同一阶段内的条件重规划，不给它长期任务权。**
保留 SAC 审议每 12s、动作 3D、单一惯性阶段目标 \`(q_goal,v_goal)\`、原 SCP 安全约束/力限、真实 MPC 与 300s 任务奖励不变。某个审议动作一旦采纳，其**绝对阶段终点和绝对阶段结束时间**必须固定到下一 SAC 审议，不得在 continue 步重新采样 SAC 子目标。每 2s 继续步比较**真值当前**的 \`(q,v)\` 与当前局部计划对应时刻的 \`(q_plan,v_plan)\`；建议在位置偏差 >0.20m 或速度偏差 >0.03m/s 时，从**实际当前状态**、对剩余 \`T_remaining=12−elapsed\` 秒、对**同一个原目标**重新求解剩余局部 SCP（2、4、6、8、10s 变时域/步长）。一次 stage 内局部重规划次数记录；绝不把剩余计划时限重置成新的 12s，也不能让 G★ 自己选最终 6.3m 入口或100s时机。预留安全余量，若剩余时限/规划可行性不满足则登记 \`stage_replan_failed\`，按已有保守恢复并及时触发下一 SAC 审议，不硬追不可达终点。改动在影子分支、参考路径、Replay 事件语义必须相同；参考在重规划时不得出现不安全跳变。由于这一变更跨到真实动态预测语义，先用少量固定开局验证有效，不能只靠单测。

**B. 恢复 SAC 的实际推进幅度，但只一次物理校正。**
保留 \`u=(-a_r e_r+a_t e_t+a_b e_b)/max(1,||a||)\`、H=12s、3D 三轴和全臂同一作用；SCP 合力上限仍 1.6N，真值仍单轴2N。若 A 后首段最大径向制动仍不足，将原 \`d_max\` 系数统一由 0.70 调到 **0.90**（约0.978m、最大 Δv≈0.163m/s、名义等效合力1.44N <1.6N），只调一次，按力限/安全检查；不得调 actor 初始化、目标惯量、MPC 真值或奖励以压低 0k。记录调幅原因。**先核验 A 的闭环，再决定 B 是否必需，禁止多系数网格搜索。**

**C. 让入口桥接按实际 SCP 可行性启动，取消容易错过时机的启发式角预筛。**
在 \`r≤10.5m\` 且真实径向制动包络有原定 \`≥0.02m/s\` 余量时，尝试既定 \`{20,30,40}s\` 的**近端** G★ 入口 SCP；去掉原 \`angle≤25°\` 硬预过滤，由 SCP 的真实安全/入口目标约束判断可行性。\`10.5m\` 严格小于主工况最小初距12m，不允许从开局自动由 G★ 全程规划。近球6m、碰撞、走廊、最大距离和时间判据不改；若所有时间点都不可行，SAC 阶段继续，绝不越界强入。桥接起点、SCP结果与未启动理由进入日志。不要扩充时间搜索网格去挑高分规则。

**D. 一次修复同接口非学习几何规则（诊断规则，不是主算法）。**
设 \`delta=mouth_point(t+24s)−q_coast\`，先在冻结阶段正交基转为需求向量，**整体按欧氏范数归一/限幅，而非先三轴各自 clip**，使向内制动与横向需求比例不因独立饱和而失真。在径向外漂明显或预测外边界接近时，规则优先给出合法的径向制动目标，横向绕行不得占满有限加速度方向。此变更只准在未看正式评估前冻结一次，保持同接口与合法安全界，不得用多个固定规则择优。重点是验证完整物理通路，不得拿它低分制造 SAC 优势。

**E. 保护训练机制、避免隐性改变主张。**
远场 CF 事实/替代影子都必须重现 A 的 stage 内条件重规划，固定 same-action stage 承诺，实际区间封账时间、模式与预测一致。PBRS、SMDP、四臂 \`R1/R3/D1/TCPF\`、原 MPC 模型、网络、初值分布、训练步数、纯 MPC/旧完整 G★ 参照不动。所有继续动作不能偷偷改成新 SAC 审议。不得降低预测可信度阈值使影子看起来更有用；CF 权重无效时按真实 TD 继续，但不能声称已有独立耦合增益。
