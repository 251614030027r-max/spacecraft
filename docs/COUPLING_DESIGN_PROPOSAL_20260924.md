**读法**：毁掉的回合很大一部分由接口造成，所以"学习层净有害"不成立，与第一轮不能说"耦合无效"同理。

## 2. 主问题：长短时域不匹配

- **MPC 只看 3.5 s**（35 步）。它把眼前飞得安全最优，但看不到"现在进去会不会非法进入""暂存
  会不会在几十秒后更划算"。这些后果在 10–150 s 尺度上（翻滚周期 152.4 s，回合上限 300 s）。
- **RL 理论上看长期**，但实测独自扛整个长时程的信用分配太难：第一轮 5k 时 4–6% 崩塌到 60k 的 0%；
  本轮毁多救少、末段停不住。
- **现在的上下层是硬拼的**：两层对"未来值多少"的估计互不相通。MPC 每决策解 20 次、每次预测
  3.5 s，只执行第一步其余全扔；RL 的价值 MPC 也不用。

**论文要回答的问题：**
> 如何把短时域最优控制与长时域学习决策在数学上接成一个整体，使每一方只负责自己擅长的时间段，
> 并以高概率保证整体不劣于 Pure MPC。

这是主线级问题，不是某个小众的点。

## 3. 候选方法：按 MPC 时域分解价值的双向耦合

### 3.1 核心式子

上层每 2 s 决策一次（= 20 个控制步），MPC 时域 N = 35 步。对状态 s、任务意图 a：

```
Q(s,a) =  Σ_{k=0}^{19}  γ^k r(x_k^truth)          已执行的 2 s：真值
        + Σ_{k=20}^{34} γ^k r(x̂_k^MPC)            MPC 已算、未执行的 1.5 s：预测
        + γ^35 V_long(x̂_35^MPC)                    MPC 视野之外：RL 学
```

前两项为短时域段（模型给出，方差小，不用学）；**RL 只需学 MPC 视野之外的价值**。
这就是两层分工的数学依据：MPC 负责 [0, 3.5 s]，RL 负责 [3.5 s, 回合结束]。
（折扣按决策步还是控制步计，需在实现时统一，属于细节。）

### 3.2 三个机制都从这一个式子引出

| 机制 | 做什么 | 复用自 | 针对的实测问题 | 额外在线求解 |
|---|---|---|---|---|
| **① 短→长** | 上式作 critic 的多步训练目标，用 MPC 本来就算好、现在被扔掉的预测 | 核心三 | 长时程信用分配弱（第一轮崩塌、本轮学得慢） | 0（只在训练时用存下的预测） |
| **② 长→短** | 上层输出**有界残差** Δ，叠加在 Pure MPC 参考上；Δ = 0 严格等于 Pure MPC，Δ 可连续微调 | 核心一 | 缺陷 1、3（开关式抖动、基线不可表达） | 0 |
| **③ 何时偏离** | 部署时只在 `LCB[Q(s,Δ) − Q(s,0)] > 0` 时采用 Δ，否则 Δ = 0。不确定性只需对 V_long 做集成（短时域段由模型给出） | 核心二 | 救回 7 个、毁掉 17–36 个 | 0（2 s 一次的网络前向） |

缺陷 2（方向插值翻转）作为 bug 在接口里修掉：插值不跨反向点，限速按前后两次决策在惯性系的
实际位移算。不列为创新。

### 3.3 结构

```
             ┌──────── 同一个价值分解 Q = 短段(MPC) + 长段(V_long) ────────┐
上层 SAC (2 s)：  输出有界残差 Δ                         ②
                  critic 目标用 MPC 预测，V_long 用集成    ①
部署判断：        LCB[Q(s,Δ) − Q(s,0)] > 0 才用 Δ，否则 Δ=0 (= Pure MPC)    ③
下层 MPC (0.1 s)：不变，每步一解；预测回传给上层，只用于训练
```

### 3.4 为什么不是堆模块

- 三者出自同一个式子，互相依赖：
  - 没有 ①，V_long 学不好，③ 的判断不准；
  - 没有 ②，锚点不在动作空间里，③ 的"退回基线"只是架构外的旁路；
  - 没有 ③，就是本轮"救得回也毁得掉"。
- 额外在线求解为零，与算力约束一致（实测余量约 23%）。
- **数学上可说的两点**：
  - 价值分解本身是恒等式；
  - "以高概率不劣于 Pure MPC"来自置信下界门控，加上 Δ = 0 逐位等于基线（已有测试钉住）。

  后者可作为论文第三条贡献（保证 / 稳定性）的候选。

## 5. 必须诚实说清的边界

1. **MPC 只多贡献 1.5 s 预测**（3.5 s 减已执行的 2 s）。它改善短时程段的估计与学习速度，
   长时程仍靠 V_long。**不得写"MPC 解决了长时程问题"**，只能写"把长时程问题收缩到 MPC 视野之外，并分工明确"。
2. **MPC 预测模型与 RK45 真值有偏差**，会使训练目标有偏。缓解：已执行段一律用真值，只对未执行段用预测，
   必要时与单步 TD 目标加权混合。**预测与真值的偏差需先测一次**（沙箱可做，不需重训）。
3. **"高概率不劣于基线"的前提**：critic 不确定性要校准。仓库有 critic 校准不良的历史（`ent_coef` auto 导致过估计），
   集成只能缓解，不能保证。论文中的保证须写明前提，不写成无条件定理。
4. 三个方法单个都不是我们发明的。创新在于：在 Λ > 1 的快速翻滚预捕获任务中，以"按 MPC 时域分解价值"
   把三者统一成一个双向耦合机制。
5. 数字边界：救回 7 个是两模型并集，n = 2 个有效种子（262410 死种子不丢弃）；
   仲裁的 oracle 上界 41/48（262411）、40/48（262412）**是上界不是成绩**。
