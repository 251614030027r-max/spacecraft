## 0. 用途与读法

[HANDOFF](HANDOFF.md) 讲"现在是什么、要求是什么"；本文件讲"怎么走到这里"。它的作用是让新窗口知道每一步为什么这样走、结果怎样改变了认识、哪些坑已经踩过，从而**不走偏、不回坑**。

**读法：**
- 按实际时间叙述，不把后来才知道的结论写成当时的认识（历史不倒灌）。
- 每个阶段按"起点 → 做了什么 → 结果 → 认识怎样改变 → 用户决定"组织。
- 区分四类信息：用户已明确的诉求；已有证据的事实；研究层的待证解释；提过但未采纳的构想。
- 数字只保留对论证有意义的关键值；完整数据、SHA 和逐开局记录在科学分支证据与 collab 审查里。
- 不同任务（F01、T1、T1-L、T1-O、T1-N、T1-B、T2）的物理、奖励与分数**不能混用**；同一任务的不同版本（T2.0 / T2.1 / T2.2）之间的回报差只说明系统总体变化。

## 二、按阶段的演进

### 阶段 1｜早期：纯 SAC、低维任务动作与 MPC 分工（≤ 9 月中）

**起点：** 项目始终关注快速翻滚非合作目标的六自由度近距离安全预捕获，同时要可靠捕获、合理时间与推进剂，并保留可解释性和以后做理论分析的余地。

**做了什么、结果：**
- 让 SAC 直接承担高维连续控制：复杂约束、旋转目标、长时域终端奖励使学习几乎拿不到稳定的成功经验（三个种子完成 3/1/0，D01）。
- T6–T12 用过四维、二维等任务级接口。旧接口上 SAC–MPC 并未自动胜过 Pure：部分实验中学习耦合约 26/48，Pure 约 32/48（D18）。四维接口三个种子几乎学不会（D04）。

**认识：** 形成分工——**学习侧处理较长时间尺度的任务意图，MPC 处理高频动力学、输入与局部安全约束。** 强约束任务要先证明高层动作确有有效自由度、MPC 闭环能兑现意图，才谈通过训练学到它。把 MPC 求解结果拼进观测、凭经验设定参考调节幅度，都不能证明训练内创新。

### 阶段 2｜V2 / V3 / V3e / F01：动作权限受限、价值仲裁与单向交接（9 月下 – 10-10）

**发现的接口问题：**
- 有些 SAC 动作经裁剪、饱和、参考平滑后，几乎不再改变真实执行（第一轮残差耦合的有效介入只有 0.1%–0.5%，D06）；
- 旧 V3 每 2 s 约 0.4 m 的参考位移预算与 6.5 m 近场参考半径下限，让"学习策略跑不快"混进了接口强制限速（D07）；
- 旧评估还出现过执行反馈观测不同步，相关读数不能作为有效训练证据。

**尝试：** 为了不让学习分支破坏局部安全，探索过价值比较、切换仲裁、停止头、把任务交给 Pure 的单向交接。直觉是合理的：翻滚目标有接近阶段差异，某些时机交给约束控制器可能更好。

**结果：** 后验挑选的最佳交接不等于在线可判断；学习分支基础能力弱、价值误差大；切换后的状态也未必在 Pure 的可恢复域内（D19–D23）。F01 多种子重训最终被用户判定不能支撑论文（271000 三模型结论 METHOD_DOES_NOT_HOLD；272000 缺失 118 份等缺口保持缺失，不拿其他阶段数据补齐）。

**认识与用户决定：** 被否决的是"**把什么时候切换 / 交接作为主要创新**"，而不是 SAC + MPC 本身。不再无限调迟滞、阈值、独立停止头。用户希望保留六自由度仿真与已有 MPC 积累，改为**同一个 MPC 全程执行、训练过程中有真实的信息反向交互**。思想从"哪个控制器接管"转向"长期任务意图怎样与约束执行协同"。

### 阶段 3｜10-10：先重新核准研究问题与任务，不替算法制造困难

**用户的质疑：** 为什么非要 SAC？Pure 失败是否来自人为门控、弱参考或学习接口的额外限速？是否把多种约束堆成了"障碍挑战大全"，却没有一个鲜明的长期决策问题？

**确定的研究顺序：** 先查物理问题和经典方法能力 → 再审查动作能否表达真正不同的合法行为 → 最后才设计学习机制。

**理论关注点：** 局部约束可行与剩余时域内可捕获、可经济完成之间的差异；不是宣称有限时域 MPC 必定失效。

**任务（T1）：** 快速三维翻滚目标、随目标转动的捕获入口、有限推力。对旧任务里的阶段锁存、重复速度边界、无效相位门（D09）和不公平参考限速做"减法"；不把更窄视场、更多危险物、硬燃油额度、极端翻滚、强估计误差一起塞进首版。名义条件：106 kg 追踪星、225 kg 目标、2.1–2.7°/s、初距 9–15 m、每轴 ±2 N / ±0.6 N·m、6 m 操作球、35° 端口锥、300 s；RK45 真值、0.1 s MPC / 35 步预测、2 s 高层决策。

当时讨论过把"入口方向 / 到达速度 / 同步程度"作为连续任务变量，甚至让 MPC 与意图变量联合优化。这些是**任务未验证时的候选构想**，不是后来采用的算法。

**思想收获：** 不预先要求 Pure 失败 70% 或新方法提高指定成功次数。物理上存在不同的合法意图、且能被同一执行器实现，才是讨论长期决策的前提；即使经典引导能解决多数开局，也要如实面对，不能临时换任务直到学习模型看起来占优。

### 阶段 4｜10-11：质疑"Pure 为什么总赢"，用离线轨迹与真值找回物理证据

**问题拆分：** Pure 强、学习 / 参考生成器弱，可能是因为固定终端 MPC 本来就够好，也可能是新参考或动作空间被额外限制、根本表达不了好轨迹。不再凭直觉说"短时 MPC 看不远"，而是要求在**同一真实动力学、同一 MPC、同一捕获与安全裁判**下证明存在可兑现的更好行为。

**结果（R0，少量开发开局）：**
- 独立探索中出现了比 Pure 更快、更省 Δv 的离线候选轨迹；
- 上层发现 T1 真值径向速度在不同坐标系间混算，修复后撤回了不合理的容差调整，重新生成并复核合法轨迹；
- 290000：Pure 135.3 s、1.30 m/s → 改进参考 94.9 s、1.01 m/s；290002：129.5 s、1.63 m/s → 84.2 s、0.86 m/s。

**认识：** 对特定的固定终端参考 MPC，**存在真实、可执行的经济性改进空间**；这不是全局最优，也不是 SAC 学会的结果。

**接口的由来：** 三维翻滚使端口及其安全到达位置随未来姿态移动。在已研究的轨迹族内，用**到达剩余时刻 τ** 表达长期交会安排，比让网络猜入口经纬度更紧凑；**下降节奏 κ** 补充近场的时间—燃耗调节。G★ 按预测的目标运动与追踪星能力生成最小 Δv 参考，共享 MPC 跟踪。这是**从物理轨迹反推出的低维接口**，没有证明 τ 唯一决定最佳几何，也没有证明 SAC 能学会 τ。用 G★ 安排远场会合构成架构收益，但也让"到底还需要学什么"成为必须回答的问题。

### 阶段 5｜10-11 – 10-12：R1 显示 G★ 很强——架构收益 ≠ 学习收益

**结果（R1，32 个视线纬度 × 端口相位分层开发开局）：**
- 第一遍发现悬停锚点错误跟随、下降代价模型等执行问题，不能作最终统计；
- 修复后第二遍：Pure 23/32；无学习 G★"最早可行到达"32/32，T300 中位约 131 s、平均 Δv 约 1.43 m/s；Pure 中位 176 s、约 2.42 m/s；
- 其他择时行在个别开局失败，预注册整体登记为 `REVIEW_EXECUTOR`；不能用最好的一行掩盖失败，第二遍也不是独立测试。

**认识：**
- G★ 已经做了目标转动预测、长时域交会与燃耗规划。它的改善**不能归功于尚未训练的 SAC**。
- 比较框架：Pure = 定义明确的固定终端 MPC；M0 = SAC + 同一 G★ + 同一 MPC，标准 SAC 更新；M1 = M0 + 训练期 MPC → SAC 信息通道。只有 M1 − M0 才隔离耦合训练增量；M0 优于 Pure 不证明学习有增量，必须面对无学习 G★ 规则。
- 当时已担心规则过强会压缩可学空间，但不能预设"任务不值得学"，也不能为了让规则失败而引入估计误差或提高翻滚。**先确认高层存在状态相关、实际可区分的长期选择，再验证网络能否提取；若收益确实很小，论文应收缩主张，而不是人为制造差距。**

### 阶段 6｜10-12：从双向耦合候选走向唯一可实现的 M1

**讨论过的候选：** 可微 QP / 联合任务变量、规划锚定 Q 残差、实际生效动作 Q、学习终端代价（D15）、风险过滤等。

**关键反证：** 在"提出任务动作 → G★ 决策 → MPC 真实执行"这个复合环境里，只要观测足够、转移记录正确，**基于提出动作的标准 SAC Bellman 目标本来就有合法语义**。不能声称"MPC 改变了动作，所以常规 Bellman 失效"。用实际生效动作代替提出动作，若计划记忆不闭合，反而会造成另一种误建模。

**选定的 M1（很克制）：** 保持真实 SAC TD 目标与 Actor 更新；每个 2 s 宏步对一个未执行的候选意图，用隔离的一次 MPC QP + 2 s 名义动力学预测替代奖励与下一观测；用真实动作的预测误差校核和全窗物理 / 模式检查得到门控 w；通过门控的反事实样本作为 critic 的辅助回归：

L_Q = L_Q^real + λ · mean_B[ w (Q(z, ã) − (r̂ + γ V̄(ẑ′)))² ]

**10-12 功能验收：** 325 个开发状态中 136 个反事实通过全窗门控；影子 / 真实一步 325/325 逐位一致；Replay、终止合同、w = 0 等价、梯度均有测试；额外成本约 20%–28%。

**认识：** 这证明"物理预测可信、训练信息链可执行"，**不证明 critic 学会了长期比较**。当时缺少"训练后会不会破坏成功策略""辅助信息有没有独立的长期纠偏能力"的早期验证，后来证明这是方法审查的盲点。

### 阶段 7｜10-12 – 10-13：正式训练把"能运行"与"会学习"彻底分开

**第一轮（接口 v1，`f36ac77`）：** M0 / M1 种子 0 在约 13.1k / 10.7k 时被操作中断，M0 10k 开发仅 5/16；不作对照（数据后按用户要求删除）。行为诊断：到达动作很快饱和，非零偏移频繁触发重规划，破坏已形成的计划。

**升级：** 经用户许可，G★ v0.4 加入"提前不可行时保留旧计划"；接口 v2 为两维 (τ, κ)：无计划时 τ = 80(a₀ + 1) s，有计划时 |a₀| ≤ 0.5 为保持带，超出后相对剩余时间最多 ±30 s，κ ∈ [0.3, 1]；每转移 4 次更新、6 环境并行、固定熵 0.005。物理、奖励、Pure、共享 MPC 不变。v2 方法代码 `78eb63c`，训练证据 `818fcd8`，根因证据 `09d6406`（不要把后来的证据提交误当 v2 训练代码）。

**结果（v2 M1 种子 0，16 开发开局）：**
- 0k 随机初始化：16/16、81.02，几乎等于无学习最早规则 16/16、81.09；
- 5k：7/16、−31.95；15k / 20k：16/16，但回报约 78；25k / 30k：10/16、11/16；
- 32,088 步按预注册平台期规则停止。Pure 同口径 11/16、0.91。

**一次错误归因及其撤回：** 曾用"R1 六条 κ = 0.7 固定择时规则的逐开局最好只比最佳单规则多 0.66"推断"整个任务没得学"，又把总体 TD 误差约 4 分当作动作排序噪声。后来正式撤回：0.66 只是这六条规则的差，不是全部反馈策略的上界；总体 TD 损失不是动作价值排序的置信界。即使长期择时空间不大，也解释不了网络为什么把能成功的行为更新成超时。

### 阶段 8｜10-13 – 10-14：根因诊断——从"猜训练问题"到因果证据

**策略干预（冻结 20k / 30k 检查点，8 个开发开局）：**
- 30k 原策略 3/8；
- 保留首次 τ 与 κ、只在有计划时强制保持：8/8、75.27；
- 只把首次改成最早：仍 3/8；
- 最早 + 途中保持：8/8、80.41（规则 8/8、80.09）。

→ 对这些样本，**途中重规划，尤其是被执行的连续推迟，是直接失败通道**；首次择时偏晚只增加时间成本。

**价值审查（10 个预选状态）：**
- 30k critic 在 7/10 状态把"推迟 15 s"排在保持前，规则接管的闭环真值只有 3/10，方向一致 4/10；
- 保持带内执行等效动作的 Q 起伏中位 0.94，约等于真正动作间回报差中位 0.95（**保持带让执行等效动作仍带伪梯度**）；
- Actor 10/10 选推迟一侧，9/10 局部梯度继续往更晚推；
- G★ 对提前 / 推迟不对称：不可行的提前通常保留旧计划，推迟可能被采纳，**且没有保证"预计到达 + 余下下降"仍在 300 s 内**，于是价值排序误差被反复兑现、累积成超时；
- 20k 虽然能成功，critic 也有错，只是 Actor 多落在受 G★ 保护的提前侧。

**M1 的局限：** 2 s 动作奖励差最多约 0.112，而反事实目标的长期部分仍是同一目标 critic 自举，排序只有 5/10；短期模型可信，却缺少能独立纠正长期高估的监督。但**没有同接口的 M0 对照，不能认定 M1 造成退化**。4 个失败状态 critic 给保持的 Q 约 91–100，确定性后续实际回报约 −105 至 −111；soft-Q 与确定性接管回报不完全同义，200 分差不能直接当精确误差。

**认识：** 纯 SAC 时代是拿不到成功样本；T1 + G★ 已经有很多成功样本，困难转为 **critic 分不清计划保持与反复推迟，Actor 沿错误梯度改坏可行计划**（D26）。这是 SAC–MPC 主线上的具体学习难题，**不是改写成一篇通用 critic 修复论文**。根因诊断只做了第一阶段（P1–P3），不自动扩展到第二阶段。仍未决、未再检验的问题：观测混叠程度、随机策略 soft-Q 校准、25k 前后的失效转折、t ≥ 120 s 的期限状态、4 次更新与固定熵的影响。

### 阶段 9｜10-14 – 10-15：训练前筛选的边界与 v4 修复

**起点：** v2 证明训练不稳定，但不能说明 MPC 反事实项造成退化。反复用少量固定规则否定尚未训练的状态反馈策略，逐渐形成"训练前验证替代训练"的停滞风险。

**做了什么：**
- T1-S1：8 开局 × 5 种固定策略都是 7/8，共同失败开局 296006，没有找到状态相关优势；
- G★ 参考整形 β（力平滑）：8 开局 × 4 档没有达到预注册的执行影响门槛（最好 3/8，要求 4/8），停止（D25）；
- 执行侧 η（让 SAC 调执行权衡）路径被停止，非默认——给 SAC 执行侧优化权不等于动态调 MPC 权重（D16 的同类）；
- 修复（科学 `1282464`）：G★ v0.5 期限一致性（预计到达 + 下降 ≤ 300 s）；观测加计划跟踪误差；M0 / M2 共用的完整回合 MC 回报校准与保持带动作等价约束；
- 回应"G★ 太强，SAC 还能优化什么"：G★ v0.6 + 接口 v4，SAC 在 τ、κ 之外还选**新建计划的入口径向速度** v_in ∈ [0.02, 0.10] m/s；M2 的影子反事实也覆盖这一维。科学冻结 `1d432c8`。

**有限准入：** 8 开局 × 三速度共 24 个规则回合全部捕获；入口速度在下降切换前改变真实轨迹与控制；34 个入口速度反事实中 27 个通过门控。但最优统一速度 80.29，逐开局最优 80.62，只差 0.33：**动作物理有效 ≠ 动态 SAC 有价值。**

**用户决定：** 批准一次性 v4 40k（M0 / M2 种子 0），不再按 10k / 20k 短期成绩止损。同时确立效率纪律：训练前只排除会让实验无效的错误；SAC 是否胜过强规则、M2 是否胜过 M0、是否收敛，交给完整训练回答。

### 阶段 10｜10-15 – 10-16：v4 40k——修好的接口仍在 2 s 重新决策下退化

**结果（种子 0，16 开发开局）：**
- 40k：M0 10/16、−3.73；M2 11/16、4.83；零点约 16/16、80.17；强固定规则 82.47；

**认识：** critic 修复与期限保护没有挡住每 2 s 重新决策带来的推迟漂移和高估（D26）。M2 的预测反馈独立优势未证明。问题指向**决策频率与承诺机制**。

### 阶段 11｜10-15 – 10-17：T1-L 三臂与 T1-L-S——稳定了，但任务没给学习留空间

**T1-L 设计（`166244b`）：** 初距 12–18 m，λ_f = 5；审议接口 `t1l-review-1`：
- 首次延迟以可行锚点参数化：τ = τ_min_feasible(v_in) + 延迟（0–60 s）；
- 6 s 审议 + 计划事件审议，审议之间 continue；Actor 只在审议态训练；Replay 记实际执行的动作；
- 三臂单因素：B2（每 2 s 审议）、N0（6 s 审议）、NΔ（N0 + 真实锚定的局部 MPC 相对价值项）。

**结果（种子 0，40k，16 开发开局）：**

| 臂 | 0k | 40k |
|---|---|---|
| B2 | 16/16、79.74 | 14/16、49.42（20k 时 16/16、80.26） |
| N0 | 16/16、79.73 | 16/16、81.37（相对 0k +1.64 [0.69, 2.59]） |
| NΔ | 16/16、79.73 | 16/16、81.86（相对 0k +2.14 [0.89, 3.39]） |
| 强固定规则（延迟 0、κ 1.0、v_in 0.02） | 16/16、82.45 | — |
| Pure | 11/16、2.50 | — |

- NΔ − N0 = +0.50 [−0.04, 1.03]，不能宣布 MPC 反馈有独立净收益；
- NΔ 权重在 3000 步一次冻结（7.16），之后每次更新相对梯度上限 10%；实际批内有效反事实只有 4.1%，梯度份额 4.9%（截断 29%）；
- B2 在 35–40k 段 Replay Q − G 约 +70，"later"0.34；N0 / NΔ 没有同型退化；

**认识：**
- 6 s 审议 + continue 是目前唯一稳定的接口形式（单种子证据）：高频 MPC 滚动与高层任务改写不应共用同一频率。但 B2 与 N0 的审议频率和目标时距同时不同，差值不能严格归于单一机制；
- N0 / NΔ 学到了朝强固定角点靠近的偏好，但没有超过它；
- 0.21 只是这一规则族与开发集上的经验上限，不是所有连续策略的理论上限；但它说明"让 SAC 学这三维以压过强 G★"缺少明显可兑现的空间。继续几十小时训练或只改 critic 损失，很可能只是更快逼近已有角点。

**T1-L-S（`672ba79`）：** 10-15 至 10-16 计划对 T1-L 做稳定化升级——审议样本用真实区间多步 Bellman（continue 保留一步 TD）、影子 MPC 只做局部 2 s 替代预测并辅助相对 Q、两档训练器（A：旧 T1-L；B：UTD 1、Actor 降频、余弦学习率）、64 开局与 T1-R 评估、预注册训练器选择规则。这是统一机制 **TCPF** 的技术深化。代码落地并通过技术核验，但**正式三臂长训被用户取消，从未启动**。

**取消的原因要写对：** 不是技术失败或训练失败，而是 T1-L 40k 与审查表明强规则差距与可学空间本身不足；在这样的任务上做训练器升级无法回答论文问题。用户同时强调：**高层决策与 MPC 的训练内双向耦合才是核心创新**，SMDP、降 UTD、重规划抑制、critic 修复都不能单独标榜为创新。

**研究顺序由此纠正：** 从"先扩大训练、设法稳定 critic"改为"**先验证真实物理任务的状态选择价值**，再谈让 SAC 学会，再验证 MPC 反向监督是否有用"。这个转向不接受削弱 Pure、给 RL 加人为专属能力、随结果改回报或场景，也不意味着造出一个状态规则就完成了论文。

### 阶段 12｜10-17：T1-O 物理筛选——加难远场先暴露的是 G★ 的问题

**动机：** 在不改共享 MPC 与 G★ 规划质量的前提下，扩大初距、提高翻滚，看能否打开任务选择空间。

**结果：**
- 原 T1-O 工况（15–19 m、2.4–3.0°/s）：20 个未登记试探开局中 6 个远场外漂 unsafe，搁置；
- P1（15–19 m、2.1–2.7°/s）：F1 31/32 捕获，1 次同类外漂，FAIL；
- P2（14–18 m、2.1–2.7°/s）：F1 32/32、0 unsafe、无 recovery / hold，但按原 S3 判据（F7 闭环区分 11/16 < 12）FAIL。**原判定保留不改**。

**机理（D28）：** 失败全部是 30 m 距离违约，集中在低纬度视线（|纬度| ≤ 20°）。MPC 跟不上 G★ 计划 → 偏差 > 1 m 重规划 → 全推力恢复 → `hold:infeasible`，hold 期间向外速度未被刹住 → 越界。换候选多半救不回。

**认识：** 加难远场首先暴露的是 **G★ 的跟踪、恢复与保持问题**，不是学习问题。修 G★ 需要单独论证，不能混进算法消融；也不能靠剔除低纬度开局"通过"。

### 阶段 13｜10-17 – 10-18：T1-O V2 门控——动作有用，但状态自适应价值不成立

**用户的纠偏方案（`T1O_V2_20261017.md`）：**
- 适度扩大任务难度，要求真实的状态相关选择；审计 G★ 的职责；固定规则不必全部成功；不得靠事后 oracle 和阈值凑收益；
- P1 / P2 旧物理筛选判据原样保留，P2 只作诊断起点；
- 首次延迟放宽到 0–90 s（在途 ±30 s）；燃耗权重 λ_f 在 {5, 10, 15, 20} 中预先约定选择，不能跨 λ 混用分数；
- 考察时间—Δv 的真实 Pareto、途中任务修订、近场 κ、可观测状态规则，以及强的非学习 G★ 代价策略；
- 设计公平的 2×2 四臂（O-R1 / O-R3 / O-Δ1 / O-TCPF），但先过 Gate；
- 原 T1-L-S 正式长训取消。

**预注册：** 判据、候选与开局在 Gate A 第一个回合之前冻结（`89b779a`，`experiments/t1o_v2.py`）。诊断（`DIAGNOSE.md`）：P2 上 F1 在四档 λ 下都最强；延迟代价随端口相位变化（Spearman −0.55）。

**Gate A（发现集 16 开局 × 10 候选 = 160 回合，上层沙盒）：** 机械 PASS。
- 只有 λ_f = 20 通过（λ = 5 / 10 / 15 分别为 1.46 / 1.68 / 2.12，门槛 2.5）；最强统一候选 U = A15（延迟 15 s、κ 1.0、v_in 0.02）；

**Gate C（独立确认集 32 开局）：** 机械 FAIL，链条按规则停止。
- 状态规则（发现集拟合，≤ 2 个观测特征）：sin(相位) ≤ −0.660 → A45；否则 cos(相位) > 0.888 → A0；否则 A15。确认集上选 A15 20 个、A0 6 个、A45 6 个；

- 零步检查（O-R3 0k 与状态规则差距 ≥ 3 分或 3 次捕获）、Gate E（MPC 反事实真值可信度）、Gate D（12k 单臂试学）、正式四臂均未运行。

**解读：**

- **瓶颈可能是任务决策价值的来源与职责划分，而不只是动作范围不够大**（待证的结构解释）。
- 证明与未证明的边界（原载 2026-10-18 版 HANDOFF 第 5 节）：不证明所有连续策略无空间，不证明 G★ 已优化完整任务，不证明 TCPF 无效，没有测过 0k 训练曲线；也不能说 C"接近通过"，不能归结为"决策树不够复杂"。
- G★ 预测代价规则差，是因为规划 Δv 只含转移段，系统性偏向长等待。
- Gate A 里"κ 有影响"不足以成为保留 κ 的学术理由；Gate B 的单边偏好也说明 κ / v_in 是否保留为 SAC 动作需要研究层另行确认。

### 阶段 14｜10-17 – 10-18：用户诉求的转变与当前认识

**转变的原因：** 原 T1 架构的 0k 已接近强固定规则，固定规划规则几乎完成了任务，学习曲线增幅极小甚至退化。即使修好后期退化，也只是逐渐逼近"延迟 0、κ 1、v_in 0.02"这个角点。所以**这个实验载体可能不适合验证已基本实现的 TCPF 训练内耦合机制**。

**用户的明确意见：**
- 在真实、有解释力的航天任务范围内，适度增加物理 / 任务难度，或调整任务定义与资源权衡；
- 重新分配 SAC 与 G★ 的权力，让学习策略承担更重要、可变化的长期任务决策；

- 论文需要清楚的性能增长、有效消融和可解释轨迹——这是论文诉求，不是要求伪造曲线或故意压低初值；
- 希望**尽快把基本完备的机制放到有意义的任务上验证**，同时不靠未论证的物理困难强行制造差距。

**协作上的纠偏：** 研究层窗口（当时称协作窗口）曾因丢失部分中间聊天，过度强调"不准动场景"和"必须先用简单规则过数道门"，又在 Gate C 失败后立刻主张改成非合作估计 / 不确定性任务，都没有完整接续用户当时的思路。**后续窗口不得以助理意见覆盖用户意图。**

**门控的两面经验（并不矛盾）：** 早期上层把每个研究不确定性都变成训练前硬门，导致反复的场景、动作、β 筛选，方案过长；而 T1-O V2 的严格 Gate 在不存在可学价值时避免了四臂大训练白耗算力，确实在 C 提前发现了问题。结论不是"不再验证"，而是**技术正确与风险性物理辨识要做足，收益、收敛和算法净贡献不能完全靠小型规则与门槛替代真实训练**。今后是否做小规模试学、做到什么程度，由用户决定。

**下一步由谁决定：** 下一任务版本与实验路线由用户与研究层在新窗口讨论；本文件不替用户提前选择。

### 阶段 15｜10-18：T1-N R2 与 T1-P——只挑时刻信息太少，阶段链在远场断开

**起点：** T1-O V2 在 Gate C 失败后，研究层先尝试"让 SAC 选中性的到达时刻、条件 G★ 正好按该时刻规划、MPC 2 s 影子配对进入 critic"（T1-N R2），以及"SAC 给三维阶段运动"（T1-P）。

**T1-N 结果（上层可行性审查与排序项诊断，未开训）：**
- 物理与接口无阻塞：t = 0 合法 2000/2000；中性请求真实改变计划与闭环。
- MPC 配对预测准确（h = 2 误差中位 0.021），但 6 s 奖励差与长期差同号仅 2/11（G★ 计划级 9/11）。
- 加排序项后，排序信号与真实长期差同向 15/25；纯计划同为 15/25；MPC 校正把前 2 s 误差从 0.166 降到 0.006，但 0 次改变排序。

   - *注（10-18）：* 原文"不能为演示算法临时添加传感器误差、极端翻滚、额外障碍"仍然有效；但"任务完全不能动"不再绝对化——允许为给 SAC 一个真实的长期决策责任，有物理依据地适度调整任务难度与 SAC / G★ 职责（HANDOFF 3.3）。

## 四、踩过的坑（新窗口最该记住的教训）

**关于"学习空间"：**
1. **事后余量是乐观的。** R1 的 0.66、T1-L 的 0.21、T1-O Gate A 的 2.62，都是特定规则族在已观察样本上的事后差。前两个曾被错用成"任务没得学"或"学习上限"，第三个大半来自样本内选择和单个开局。要在独立开局上检验。
2. **"统一最强候选"本身也是在发现集上选出来的。** Gate C 中确认集上更强的统一策略是 A0，而不是发现集选出的 A15。
3. **动作有作用 ≠ 有学习空间。** 要看"随状态翻转的偏好"，并且在独立开局上看（v4 的 v_in 0.33，T1-O 的 κ 15:1、v_in 27:4、keep 10:1）。
4. **离散候选网格 + 简单规则只是下界。** Gate C 不排除更复杂的观测策略；但与"总是最早"完全打平，说明没有迹象表明存在大量余量。
5. **先证明学习空间，再训练。** 两次 40k 级训练（v4、T1-L）都在任务本身缺少决策余量时展开。"物理筛选 → 发现集 → 确认集"能在一个工作日内零训练给出结论。

**关于训练与价值：**
6. **总体 TD 误差 ≠ 动作排序误差**；soft-Q 与确定性后续闭环回报不是同一个真值。
7. **每 2 s 重新决策会退化**（推迟漂移 + critic 高估）；6 s 审议 + continue 是目前唯一稳定的形式（单种子）。
8. **保持带会让执行等效的动作仍带伪梯度**；G★ 对提前 / 推迟的不对称处理会把价值误差反复兑现。
9. **训练日志里的完成率是行为策略统计**，不是部署性能，不能当门槛。
10. **MPC 一跳反事实的短期可信 ≠ 长期纠偏能力**：长期部分仍是同一 critic 自举（M1 排序 5/10；NΔ 批内有效反事实仅 4.1%）。
11. **TCPF 训练机制本身从未被检验**：区间 Bellman 与 MPC 反馈只完成了实现与技术核验，所有停止都发生在训练之前。

**关于场景与规划器：**
12. **G★ 的规划 Δv 只含转移段**，系统性偏向长等待；不能把规划代价当总代价。
13. **更难的远场暴露的是 G★ 的跟踪、恢复、保持问题**，不是学习问题。
14. **"G★ 吞没学习空间"是待核对的假说**，不是已证根因；`τ_min_feasible` 是可行性计算，不是全任务最优。
15. **提高翻滚、加估计误差都不是捷径**：更快翻滚让 Pure 因距离超限失败（D11）；简单 EKF 对真值几乎无差（31/48 对 32/48，D12）。

**关于数值与工程：**
16. **求解器缓存数值：** 长时间运行的 MPC 的 CVXPY / CLARABEL 缓存带有自身求解历史，影子克隆无法与它逐位相同（约 1e-8）。分叉一律 `sync(fresh_solvers=True)`，与原延续的差异报告为数值重复性。
17. **换燃耗权重要重标定**反事实门限 e_r = 0.06（在 λ_f = 5 标定）；回报从逐步 Δv 精确重算，不重跑物理。
18. **跨机器只比较判定**，不比较逐位数值；同一 Gate 的比较在同一台机器上做。
19. **运行中不要改被导入的模块**：评估进程池每个阶段都重新导入工作树。
20. **不同任务的基线不能互换**（T1-L Pure 2.50 ≠ 旧 T1 Pure 0.91；T1-O λ_f = 20 的回报 ≠ T1-L 的 82.45）。

**关于协作：**
21. **助理的意见不能覆盖用户意图**；丢失上下文时先读本文件与 HANDOFF，再发言。
22. **执行单要写清楚当前任务状态**，否则下层会按历史执行单重建旧环境（如已退役的 `DRL2_T1*` 克隆）。
23. **训练前门控既不能无限加，也不能完全不做**（阶段 14）。

**T1-N 至 T2.2（10-18 至 10-23）新增：**
24. **均值收益要做集中度检验：** 去掉最大一例、两例后仍成立吗？T1-B V7 / V8、T2 筛选的 +26.6（90% 来自一个开局）、T2 B 段 MVE − SAC 的 +10.52（去掉两例后为 −2.40），都是靠救援开局撑起的均值。
25. **反馈必须覆盖真正决定成败的那一步：** T2.0 的阶段层模型在打开入口的阶段没有候选，MVE 的收益只出现在经济任务。
26. **事实门不要比对刀口式的离散事件或随机结局：** 比对的是"模型交给执行规则的状态"，再加事件一致性。入口事件一致率要以全部适格预测为分母，不能拿子集当总准确率。
27. **基线行要测"没有分层控制介入"：** `b597521` 的 pure 行被远场 PD 接管（`e8a96cf` 修复）。
28. **执行缺陷与学习失败要分开：** 冻结 MPC 远场保持惯性点会外推；修复它是工程更正，不是 SAC 的创新，也不能说是所有历史失败的唯一根因。
29. **训练吞吐看锁步采样中最慢的环境：** 近场入口加下降约 50 s 墙钟时，三个环境的 CPU 只有约 38%；加核没用，要异步采样。沙盒吞吐不能代表本机。
30. **跨版本比较只说明总体：** T2.2 同时改了入口模型、更新次数和远场执行；耦合因果只看同版本、同种子的配对。
31. **作废的数据：** 某次"延迟扫描"脚本对所有延迟给出完全相同的结果，已作废，不得再引用。
32. **副创新不得把学习层的决策自动化掉：** 修好执行层的同时也会抬高固定策略，学习空间可能被压缩回 T1 的状态；每次改执行层，都要用固定策略筛选核对余量。
