# 05 执行机会感知与协调（ECC）

**要解决的问题：** 同一个高层意图，在动态窗口下可能被执行层兑现为入口，也可能被推迟或根本形成不了入口。能否兑现，取决于执行层的规划、门限与跟踪，只有执行层在短时域内看得清；而策略要在 16 s 一次的决策中判断能否赶上一次只持续 26–33 s 的经过。机会稀缺时，相近的意图可能就是捕获与超时之别。

**做法：** 在每次高层决策处，执行层用自己的模型预测有哪些可执行的入口机会，按一条规则在"保持策略意图、修正意图、启动直接入口"之间选择；策略在这个协调后的真实闭环上学习。

## 5.1 短程机会：模式预测

**问题：** 在决策状态 x（模式 S / H），对一个意图 b，执行层回答："如果接下来一直保持 b，会不会、什么时候、花多少燃料转入入口转移或末段下降？"

**计算：** 完全按执行层自己的规则：
1. 从当前状态出发，按阶段层规则（扫掠锥目标速度、阶段权限限幅、安全投影）与阶段规划器逐阶段生成名义轨迹，至多 3 个阶段（H_p = 48 s）；规划被拒的阶段按原地保持处理；
2. 沿名义轨迹每 2 s 做与实际执行相同的检查：是否进入下降区；入口判定（距离、制动裕度、35° 夹角、到达不晚于 L），通过的到达时刻调用入口规划器，第一个可行者即入口事件；
3. 目标姿态用恒速预报，惯量用估计值；
4. 达到预测时域、期限，或计划燃料用完剩余预算时截止。

**输出：** ê(x, b) ∈ {0, 1}（是否发生模式事件）、τ̂(x, b)（事件时刻）、Δv̂(x, b)（到事件为止的规划燃料，入口事件含入口规划的燃料）。

预测的是执行层模型下的模式切换，不是捕获；它不计算回报或价值，同一状态得到同一回答。

**短程机会集：** 对提议 a 和 3 × 3 网格 𝔅 = {−1, 0, 1}²，

  Ω_S(x) = { b ∈ 𝔅 ∪ {a} : ê(x, b) = 1，Δv_used + Δv̂(x, b) ≤ B_max }。

## 5.2 远场机会：直接入口

入口判定只在距离 ≤ 12 m、到达 ≤ 60 s 时尝试入口。若接近节奏使末次经过时仍在 12 m 外，或 60 s 内的到达都不可行，短程机会就为空。直接入口用同一个入口规划器、更长的到达时刻，从当前距离直接规划入口：

  Ω_L(x) = { τ ∈ 𝒯_L : t + τ ≤ L，入口规划器从当前状态在到达时刻 τ 可行 }，

取最早可行者。执行与普通入口转移相同（MPC 跟踪、偏离时重规划、丢失时转为保持并回到高层）。

直接入口是一条执行指令（启动入口转移），不是二维意图。

## 5.3 机会协调：一条规则

**最后机会：** 一个在 t_e 发生的机会，若 t_e + P > L，即错过它在 L 前不再有下一次经过。

**关键机会：**
- 关键意图 O_I(x) = { b ∈ 𝔅 ∩ Ω_S(x) : t + τ̂(x, b) + P > L }；
- 直接入口 O_L(x)：处于末次可用经过（下一次经过在本阶段内，且其后的下一次经过已晚于 L）且 Ω_L(x) 非空时，含最早的直接入口；否则为空。

**规则：** 𝒞(x, a) =
- a，若 ê(x, a) = 1（**保持**：策略自己的意图能触发事件）；
- 否则 argmin_{b ∈ O_I(x)} ‖b − a‖，若 O_I(x) ≠ ∅（**修正**：离提议最近的关键意图）；
- 否则直接入口，若 O_L(x) ≠ ∅（**启动**）；
- 否则 a。

**性质（由定义直接得到）：**
- 只在关键窗口干预：策略意图能自己触发事件时总被保持；接近节奏与相遇时机始终由策略决定。
- 改动最小、映射确定：修正时取离提议最近的关键意图（并列时取事件更早者）；直接入口只在没有关键意图时启动。
- 成功、安全与回报的判定不变，协调只决定执行哪个机会。

协调只作用于当前这一次宏决策，训练与测试相同。

## 5.4 在协调闭环上学习

- **闭环转移：** 记执行层的宏转移核为 P_ℰ，闭环核为 P_𝒞(x′, r | x, a) = P_ℰ(x′, r | x, 𝒞(x, a))。
- **经验存提议：** 经验池存策略提出的 a，回报与后继来自协调后的真实执行，即 (o, a, r̃, o′, d)。评价器学的是"提出 a 时，闭环系统真实会发生什么"，即 P_𝒞 下的价值，策略梯度也经由它作用于策略提出的 a。若改存协调后的动作，评价器学的是执行层本身的转移 P_ℰ，与策略实际面对的闭环 P_𝒞 不一致。
- **损失不变：** 执行层的预测只用于协调，不生成价值目标；SAC 的损失与标准形式相同（第 06 节）。
- Bellman 对象定义在完整状态 x 上，策略与评价器只读 o，属于部分可观下的函数逼近。

## 5.5 一次决策的流程（算法 1）

```
初始化标准 SAC（策略、双评价器、目标网络、经验池）
每次高层决策（模式 S / H）：
  a ~ π_θ(·|o)                         # 测试时取均值
  对 𝔅 ∪ {a} 做 48 s 模式预测；必要时求直接入口；按 5.3 得到 𝒞(x, a)
  执行：意图经 RWG（阶段目标 → 规划 / 跟踪 → 入口判定、入口规划与重定时 → MPC），
        或直接入口（入口规划 → MPC），直到宏步结束
  T: r̃ ← r + γ_d Φ(x′) − Φ(x)
  T: 存入 (o, a, r̃, o′, d)              # 存提出的 a
  T: 每条转移 2 次 SAC 更新（双评价器、策略）
```
T 标记只在训练中执行的行。

## 5.6 方法总图的内容

- 左：策略 π(a | o)，同一观测 o 也给双评价器；
- 中：执行机会与协调（短程模式预测、直接入口），输出执行对象；
- 右：RWG 执行链与近场 MPC，作用于六自由度真值；
- 下：真实转移 (o, a, r̃, o′, d) 回到经验池。
