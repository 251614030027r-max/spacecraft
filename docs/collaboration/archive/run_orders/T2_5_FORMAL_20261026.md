## 预先登记的判据（`t2_decide --criteria t25`，事后不得修改）

| 项 | 标准 |
|---|---|
| C0 完整 | 3 个种子 × 2 臂 × 7 个检查点（0、500…3000），全部 24/24，且没有 ERROR 文件 |
| P1 学习效率（主指标） | 500–3000 各检查点配对差的平均：三种子平均 > 0，且至少 2 个种子 > 0 |
| P2 紧急任务 | 同一指标只看紧急任务：三种子平均 > 0 |
| P3 最终性能 | 3000 步配对差的三种子平均 ≥ −3 |
| S 安全 | 每个种子：EACC 捕获 ≥ SAC − 1；EACC 不安全总数 ≤ SAC + 1 |
| C 收敛 | 每臂：\|R(3000) − R(2500)\| 的三种子平均 ≤ 10 |

判定结果：
- `pass`：全部满足；
- `partial`：P1、P3、S 满足，P2 或 C 不满足；
- `no_gain`：P1 不满足，P3、S 满足；
- `harmful`：P3 或 S 不满足；
- `incomplete`：C0 不满足。
