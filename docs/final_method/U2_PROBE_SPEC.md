# U2：执行器模式探询（Executor Mode Probing）——实现规格与预登记判据

> **非最终论文算法（2026-11-10）：** 本文件是研发记录。论文方法以 `docs/paper/METHOD.md` 为唯一源，对照见 `docs/paper/FACT_MAP.md`。

**状态：** 研究层与用户 2026-11-06 批准方向（唯一新增方向、一次完整验证）。本文件是实现规格，并在任何离线数据产生之前登记离线判据。训练阶段的判据见执行书 `RUN_U2`（collab）。正式实验配置与运行需另行授权。

**代码：** `env/t2_probe.py`（`u2-probe-1.0`）、`env/t2_stage.py`（env 0.14.0，观测配置 `reduced_probe` / `reduced_priv_probe`）、`train/t2_mve_sac.py`（learner 7.1，只是视图维度与日志）、注册表配置 `PROBE` / `EACH_PROBE` 与阶段 `u2`。

## 1. 要解决的问题

下层执行器知道"高层意图能否让它切换到下一执行模式"。U1 依靠研究者挑选三个物理量（过境时间、入口角、截止余量）把这类知识传给 critic。

U2 不再挑选物理量：在当前决策状态，用一组固定探测意图询问执行器本身，读取它的模式事件。

## 2. 机制

**探测集：** 动作盒上均匀的 3 × 3 网格，a_p、a_z ∈ {−1, 0, 1}，固定顺序，不可学习，不调参。

**对每个探测意图**，从真实决策状态出发，用执行器自己的规则推演，最多 3 段（48 s）：

| 环节 | 执行器规则（与真实执行同一函数或同一配置） |
|---|---|
| 阶段层 | `stage_goal`（扫掠锥目标速度、阶段权限、安全投影）+ 阶段规划器；目标姿态用决策时姿态与角速度的恒角速度预报。规划器拒绝的阶段按"原地保持"处理 |
| 飞行 | 标称规划轨迹（不加残差模型、不用本轮校准） |
| 模式检查（每 2 s） | 与 `_advance` / `_try_bridge` 同序：<br>① 下降区域（口部带、操作球内、锥内且 < 7 m）→ 事件；<br>② 距离 ≤ 12 m 且径向包络裕度 ≥ 0.02 m/s，则对 τ ∈ {15, …, 60} s 中预报口部夹角 ≤ 35° 且到达不晚于"截止 − 45 s"者，依次调用条件 G★ 规划器（同配置、执行器估计的各向同性惯量）；第一个可行者 → 入口事件。<br>不设每节点求解上限 |
| 终止 | 3 段到期、任务截止、或规划 Δv 用尽剩余预算 |

**每个探测意图输出三项**（共 27 维）：
- 事件标记 e ∈ {0, 1}；
- 时间 t / 48 s：事件时刻，或无事件时的推演终点（时域上限、截止或预算）；
- 阶段规划 Δv / 0.5 m/s：截至事件或终点，上限 3。

e = 0 只表示在该时域与模型内没有模式切换，不表示任务不可行；e = 1 是执行器模型的模式切换，不是捕获。

**使用方式：**
- 只作为训练期 critic 输入：`PROBE` = 24 维精简观测 + 27 维（替代 U1）；`EACH_PROBE` = 48 维（U1）+ 27 维。
- Actor 仍读 24 维；评估时探询关闭（填零，actor 不读）。
- 学习器、奖励、TD 目标、网络结构、更新次数与 EACH 相同（arm `e_priv`）。
- 不计算价值、回报或候选排序，不产生标签，不修正 Actor。

**独立实例：** 探询使用每回合单独构造的阶段规划器与 G★ 规划器实例，不触碰执行回合的求解器状态。有无探询，执行轨迹完全相同。

## 3. 理论边界（只主张两点）

1. **与训练历史无关：** 探测集、模型、规划器配置固定，同一状态得到同一输出。学习只以真实 RK45 宏转移为监督，不注入模型估计的长期价值（对照 D42：依赖本轮执行历史的输入会形成自我印证）。
2. **显式提供动作—模式结构：** 输出描述局部动作区域与执行模式切换的关系（哪些意图、多快、多少燃料能让执行器进入下一模式），有可能降低 critic 学习模式边界的表示难度。

**不主张：**
- 预测事件等于真实成功；
- 价值函数一定不连续；
- 探询天然给出正确的 Actor 梯度。

**信息性质：** 探询读取目标完整姿态、角速度的恒角速度预报与相对状态，不保证是 24 维策略观测的函数，因此按训练期特权信息讨论，与 U1 相同。

## 4. 阶段 A：离线预检（不训练；判据在数据产生前登记）

**数据：**
- 开局：开发块 294000–294047，以及新训练区块 13,000,000–13,000,047（种子 12 的区间，未被任何阶段使用）。不触碰预实验、u2、作图与正式开局。
- 策略（不学习）：三个已登记的固定意图 (1, 0)、(1, −0.5)、(0.6, 0.5)，以及每个决策均匀随机的意图（按开局播种）。共 4 × 96 回合。
- 工具：`experiments/u2_probe_audit.py`。

**记录（每个决策状态）：**
- 探询向量与逐探测明细（事件类型、时间、终点原因、求解次数）；
- 对实际执行意图同法推演一次（只用于审计，不进入任何输入）；
- 真实执行中此后第一次模式切换（G★ 接受入口或进入下降）的时刻；
- 探询耗时与真实一步耗时。
- 另外在每个真实的 2 s 入口检查处，用探询的同一判定函数重算，与 `_try_bridge` 的结果比较。

**判据：**

| 编号 | 内容 | 不满足时 |
|---|---|---|
| A1 确定性 | 每第 5 个决策用同一实例与全新实例各重算一次，输出逐位相同（100%） | 实现缺陷：修复后重跑，不算 U2 失败 |
| A2 规则一致 | 真实 2 s 检查处：下降判定、距离 / 包络门槛 100% 一致；G★ 接受与否一致率 ≥ 99.5%（只允许数值刀口，逐例列出） | 实现缺陷：修复后重跑 |
| A3 不塌缩 | 非终止决策状态中，九个探测的（事件，时间）不全相同的占比 ≥ 10% | **停止 U2** |
| A4 成本 | 全部回合探询耗时之和 ≤ 1.5 × 真实执行耗时之和 | **停止 U2** |
| A5 与真实执行的一致 | 固定意图回合中，"执行意图的推演在 48 s 内有事件"与"真实执行在 48 s 内发生模式切换"的平衡准确率 ≥ 0.6 | **停止 U2** |

**只报告、不设门槛：**
- 按距离分档（> 12、10–12、8–10、< 8 m）的 A3 / A5；
- 事件时间误差；
- 随机意图回合的 16 s 一致性；
- 小样本事件预测对照：按开局分组交叉验证的逻辑回归，比较观测、观测 + U1、观测 + U2 对"真实下一段内模式切换"的预测。

A3–A5 任一不满足即停止，不调探测网格、时域或维度后重试。
