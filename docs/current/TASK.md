## 1. 物理与执行（所有 T1 档案共用，`env/t1_env.py`、`env/t1_task.py`）

| 项 | 值 |
|---|---|
| 质量 | 追踪星 106 kg；目标 225 kg，均质盒，主惯量 diag(30, 39, 48) kg·m² |
| 轨道 | 500 km 圆轨道，倾角 45° |
| 真值 | RK45（rtol 1e-7、atol 1e-9）；中心引力 + J2；目标自由翻滚 |
| 控制 | 0.1 s 一步；每 2 s 一个决策（20 步）；共享 MPC h35 |
| 执行器限幅 | 每轴推力 ±2 N，每轴力矩 ±0.6 N·m |
| 期限 | 300 s |

**安全判据**（真值，任一违反即 unsafe）：
- 碰撞（追踪星包络球 0.95 m 对目标盒与抓杆）；
- 操作球 6 m 外可自由运动，球内必须在 35° 端口锥内；
- 视场 50°；
- 径向 / 轴向制动包络；
- 近场总速度；
- 距离 30 m。

**捕获：** 在锥内，且位置误差 ≤ 0.25 m、姿态误差 ≤ 10°、速度 ≤ 0.05 m/s、角速度 ≤ 0.02 rad/s，保持 1 s。

**奖励：** 每秒 −0.05；推进剂 −λ_f·Δv（T1 / T1-L 中 λ_f = 5，T1-O V2 选为 20）；捕获 +100、unsafe −150、超时 −100；γ = 0.999 / 2 s。
- success、unsafe、timeout 都是终止，不自举；只有数值失败是截断。
- `info["delta_v_step_m_s"]` 记录逐步 Δv，任何 λ_f 都可以精确重算。

## 3. G★ 参考生成器 v0.6（`env/t1_gstar.py`）

**规划方式：** 给定到达时间 τ 与入口内向速度 v_in，用 SCP 最小 Δv 规划到与端口共转的入口点。
- 规划半径 6.3 m；
- 规划力 = 0.8 × 2 N（2-范数）；
- 球外半空间、径向包络、20 m 范围罚、28 m 硬上限。

**计划管理：**
- 偏差 > 1 m 时重规划；
- 请求与剩余时间之差在 3 s 以内时保持计划（`T1GymConfig.keep_tolerance_s`）；
- 无可行计划时用全推力恢复，再不行则保持（hold）。

**期限：** 任何计划的到达时间不得晚于 240 s（300 − 60）。

**下降段：** 进入锥内 7 m 或球内后，按 κ × 制动包络（且受科氏力上限约束）沿端口轴下降。

## 4. 审议接口 `t1l-review-1`（`env/t1_task_review.py`）

**动作**（3 维，[−1, 1]）：

| 动作 | 无在役计划时 | 有在役计划时 |
|---|---|---|
| a0 | 首次延迟：τ = τ_min_feasible(v_in) + 延迟。延迟范围 T1-L 为 0–60 s，T1-O 为 0–90 s（`delay_max_s`） | \|a0\| ≤ 0.5 保持计划；超出则线性平移 ±30 s |
| a1 | κ ∈ [0.3, 1.0] | 同左 |
| a2 | v_in = 0.06 + 0.04·a2（0.02–0.10 m/s），只作用于新计划 | 同左 |

**审议时刻：**
- 每 `review_period_steps` 步审议一次：3 步即 6 s；B2 为 1 步。
- 计划事件（hold、recovery、无计划）后，下一步提前审议。
- 审议之间执行 continue：保持已接受的到达时间、已承诺的 κ 和计划自身的 v_in。

**观测：** 34 维（`REVIEW_OBSERVATION_NAMES`）。
- 几何与速率、计划记忆、跟踪误差；
- 审议标志与间隔、期限余量、目标系中的计划误差。

注意：最早可行锚点 τ_min **不在观测中**。

**反事实包装 `T1LReviewCFEnv`：**
- 每个审议点做一次影子 MPC 预测，候选动作是"另一个合法意图"；

## 6. T1-N（Research Plan R2）：中性到达时间与条件 G★

代码：`env/t1_n_task.py`（初值、条件 G★）、`env/t1_n_review.py`（接口 `t1n-review-1`）、`env/t1_n_cf.py`（配对影子）。物理、真值、MPC、安全判据、捕获条件与第 1 节相同。

**初值（`T1NInitialDistribution`）：**
- 初距 12–18 m；翻滚 2.1–2.7°/s，绕偏离本体 z 轴 10–30° 的轴（方位随机）；目标姿态 SO(3) 均匀；追踪星方向在 LVLH 球面均匀；
- **惯性**相对速度由视线构造：有符号径向分量 [−0.12, 0.12] m/s（正为外离），切向分量模长 0.03–0.20 m/s、方向在视线法平面内均匀；合速度最大 0.233 m/s（上限 0.25 不触发）；
- 追踪星姿态与角速度同 T1（瞄准端口，倾斜 ≤ 15°，随机滚转，每轴 ±0.005 rad/s）。

**条件 G★（`ConditionalGStar`）：** 同一 SCP 规划器（0.8 × 2 N、30 节点、球外半空间、制动包络弦、距离上限）只解**所请求的到达时刻**；不再做最早可行网格、顺延、期限裁剪或全推力最早恢复。
- 在役计划仍被跟踪（偏差 ≤ 1 m）且请求与剩余时间相差 ≤ 3 s：保持（`kept`）；
- 请求不可满足：有可用计划则保持（`kept:infeasible_request`，记为拒绝）；无可用计划则制动并保持当前惯性位置（`hold:rejected`），下一步提前审议；
- 请求超过期限（到达晚于 240 s）：拒绝，从不裁剪到期限；
- 偏差 > 1 m：按同一剩余时间重规划；不可行则丢弃计划（事件 → 审议）。
- κ = 1.0、入口速度 0.02 m/s 对所有计划、所有臂和所有基线固定。

**动作（1 维）：**
- 无在役计划：τ_req = 20 + (a + 1)/2 · (τ_high(t) − 20)，τ_high(t) = min(200, 240 − t) s；不锚定最早可行解；
- 有在役计划：|a| ≤ 0.5 保持，带外线性平移至 ±30 s；
- 6 s 审议，计划事件后下一步提前审议；审议之间执行 continue（保持）。Replay 存审议时的原始动作。

**观测（41 维，`T1N_OBSERVATION_NAMES`）：** 在每回合固定的角动量系 F_H（z = 初始角动量方向，x = 初始视线在其法平面的投影）中的相对位置、惯性相对速度、目标两根本体轴（端口轴、本体 z）、目标惯性角速度；距离、纬度、端口相位、视场裕度；时间与期限余量；模式标志；计划记忆与上次请求结果；带符号跟踪误差；**只读最早可行摘要**（无在役计划的审议态，决策前用同一规划器在 G★ 网格上求得；T1 旧线不得读取 τ_min 的规则在 T1-N 中由该观测替代，所有臂与规则共享）；审议时钟。

**奖励：** T1-O V2 的语义，λ_f = 20（R2 第 2.3 节：沿用的口径，不是独立推导的最优权重）。
