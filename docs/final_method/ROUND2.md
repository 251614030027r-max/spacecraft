## 2. ECC 的收敛表述（实现与第一稿 ECC_LE 的执行逐位相同）

在决策状态 x（模式 S / H），策略提出意图 a。执行层给出两类机会，两类都只在"最后机会"时由协调使用。

- **意图机会：** 对候选网格 𝔅 = {−1, 0, 1}² 与 a 做 48 s 模式预测，得到 (ê, τ̂, Δv̂)。
- **直接入口机会：** 入口规划器从当前状态按到达时刻 𝒯_L = {20, …, 220} s 求解，取第一个可行者。

**最后机会：** 一个在时刻 t_e 发生的机会，若 t_e + P > L（P 为自旋周期，L = T_d − 45 s 为最晚到达时刻），即错过它在 L 前不再有下一次经过。

**关键机会集** O_c(x) = O_I(x) ∪ O_L(x)：
- O_I(x) = { b ∈ 𝔅 : ê(x, b) = 1，t + τ̂(x, b) + P > L，Δv + Δv̂(x, b) ≤ B }；
- O_L(x)：端口在本阶段内经过（t_pass ≤ h）且 t + t_pass + P > L 时，直接入口可行则含它，否则为空。

**协调规则（一条）：**
1. 若 ê(x, a) = 1，执行 a（保持）；
2. 否则在 O_c(x) 中执行对 a 改动最小的机会：
   - 意图 b 的改动为 ‖b − a‖，并列时取 τ̂ 小者，再按网格固定顺序；
   - 直接入口完全替换意图，改动视为大于任何意图，所以只在 O_I 为空时被选；
3. O_c(x) 为空时执行 a。

这正是第一稿的"保持 / 修正 / 启动远场入口"，只是写成一个机会集加一条规则。

**开关：**

| 开关 | 含义 | 默认 |
|---|---|---|
| `coordination` | 协调开 / 关 | 开 |
| `correction` | O_I 是否参与（关闭即"无核心"：只剩保持与直接入口） | 开 |
| `long_entry` | O_L 是否参与（评估时关闭即"无副机制"） | 开 |

`correction` 关闭时只预测 a 本身，不预测网格。

**学习：** 回放存提出的 a，回报与后继来自协调后的执行（不变）。

**逐位判据：** 同一初始条件、同一组随机意图序列下，新代码（协调全开、旧势函数 `lead24`）与旧代码（科学 `72a8d41`，`certify` + `long_entry`）逐步比较以下各项，必须全部一致：
- 执行层轨迹：时间、Δv、事件、模式、阶段规划状态、规划 Δv；
- 真实回报与塑形回报；
- 每次决策的协调结果：原意图是否自带事件、是否修正、修正后的意图、是否启动直接入口；
- 回合统计与重定时记录；
- 新观测的 17 项等于旧观测中对应各项。

至少覆盖一次修正和一次直接入口；若随机意图没有触发，就加用会触发它们的初始条件或意图序列。

## 3. 奖励：机会可达性势函数

**动机：** 第一稿的势函数 Φ = −min(25 m, ‖q − m(t + 24 s)‖) 用固定提前 24 s 的口部点。它与端口何时经过、期限前还剩几次经过、制动包络都没有关系。第一稿失败几乎都是超时，弱种子是节奏偏慢的策略（成功任务完成时间中位数更长、超时更多）。

**定义：** 用执行层自己的常数和恒速预报（与观测、规划器同一信息边界）。

1. **名义接近时间 t_m(x)：** 从当前距离按名义闭合速度 min(0.20 m/s, v_b(ρ − 6 m) − 0.02 m/s) 接近到口部半径 6.3 m。其中 v_b 为任务的径向制动包络，0.20 m/s 为意图盒的最大闭合速度，0.02 m/s 为入口判定的包络裕度。同时纬向偏差按 RWG 的固定纬向律收敛，要求 |δ_lat| ≤ 35°。以 0.5 s 步长积分。
2. **经过窗口：** 端口经过视线子午面的时刻 t_k = t_pass + kP（k = −1, 0, 1, …）。窗口半宽 w = φ_hw / Ω，φ_hw 由引理 1 在扫掠锥上（λ = β）、门限 35° 时给出。
3. **最早可赶上的入口时间：**

   T_go(x) = min_k max(t_m, t_k − w)，约束 max(t_m, t_k − w) ≤ t_k + w 且 t + max(t_m, t_k − w) ≤ L。

4. **势函数：** Φ(x) = −min(Φ̄, c · T_go(x))；没有可赶上的窗口时 Φ = −Φ̄。
   - c = 0.10 /s，即任务自身的时间代价；
   - Φ̄ = 25，与旧势函数的界相同；
   - 终局 Φ = 0。

**含义：** c·T_go 是"到下一个可兑现入口还要付出的时间代价"的乐观估计，可以看作价值的一个时间分量。
- 由距离限制时（还没接近到位），Φ 随名义接近时间稠密变化：接近得越快，势越高；
- 由窗口限制时（已到位、等端口经过），Φ 只随时间均匀变化，等待既不奖励也不惩罚；
- 错过一个窗口时，T_go 跳到下一次经过，Φ 下降约 c·(P − 2w)；
- 期限前已无可用窗口时，Φ 落到最低。

**性质：**
- 标准的基于势函数的塑形 r̃ = r + γ_d Φ(x′) − Φ(x)，γ_d 与学习用的相同，终局 Φ(x′) = 0；最优策略不变（Ng 等 1999）。
- 不改成功、安全与超时的判定，评估只报告真实回报；所有组用同一奖励。
- 只用到任务已有的常数（时间代价、旧势函数的界、意图盒、制动包络、入口门限与裕度、期限余量），没有新增可调权重。
- 不调用模式预测，每次计算是毫秒级的解析运算。

**旧势函数保留为开关** `potential = 'lead24'`，只用于第 4 节的对照，以及第 2 节的逐位核对。
