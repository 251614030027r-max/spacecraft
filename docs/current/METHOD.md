# 方法规格：基于价值的单向交接（当前有效，2026-10-10）

## 问题

学习层（SAC 任务策略）先飞，Pure MPC 是强基线。每个决策点只问一个问题：**继续用学习策略（保留之后再交接的选项），还是现在把控制交给 Pure MPC？**

交接是单向的，不交回。这是一个最优停止问题：
- 在 k = 0 交接，就等于 Pure MPC；
- 始终不交接，就等于学习策略单飞。

## 组成

| 组成 | 定义 | 代码 |
|---|---|---|
| 任务策略 μ | V3e 的 2D 任务动作（`task_state_v3` 接口，旋转一致、限速的参考），SAC | `train/stopping.py` 中的 `StoppingSAC` |
| 继续价值 Q_C | SAC 双评论家，V_C(s) = min Q_C(s, μ(s)) | 同上 |
| 交接价值 Q_H | 回归 Pure MPC 从该状态接管后实际得到的折扣回报；使用 31 维、与策略无关的特征 | `stop.q_handoff_min` |
| 停止规则 | `stop_rule="value"`：β(s) = σ((Q_H − V_C)/0.005) | `stopping_values`、`handoff_probability` |
| 部署 | 第一个满足 β ≥ 0.5（即 Q_H ≥ V_C）的决策点交接 | `experiments/v3_stopping.py`，`--row stopping` |

## 训练

- **Bellman 目标**：Q_C 的目标为 r + γ·V(s′)，其中 V = β′·Q_H + (1 − β′)·V_C^soft + α·H(β′)。
- **`bellman_stop_value="soft"`（2026-10-07 起）**：β′ 用与继续项相同的 SAC 软继续价值计算。目标因此是 Q_H 与 V_C^soft 的熵正则最大值。部署规则不变。
- γ = 0.999。熵系数固定为 0.005（自动温度在历史上导致评论家高估，见 `docs/DEAD_ENDS.md` D02）。
- **训练期行为交接**：每个决策点以 clip(β, 0.002, 0.01) 的概率随机交接。这个截断只在训练时使用。
- **预算按外层决策点计。** Pure MPC 接管后的后缀只用来给 Q_H 打标签，不产生更新。
- 每次训练从零开始，至少 3 个种子，训练 60k 外层决策。

配置为 `train.stopping.STOPPING`。旧配置保留在同一文件中：`STOPPING_VALUE_20261006`（确定性停止值，对应作废的 262450–262452）、`STOPPING_HEAD_20261002`（独立停止头，对应 267000 正式轮）。

## 有意不做的事（2026-10-02 冻结，2026-10-07 重申）

不加新的分类器、安全集、迟滞、交接门槛、残差锚点，不改奖励，不改任务。

理由见 `docs/DEAD_ENDS.md`：D20 分类器、D22 独立停止头、D19 价值仲裁。

## 理论表述

写成累积停止遗憾，而不是"错误决策只发生一次"：

J* − J^π̂ ≲ E[ Σ_{k<τ̂} γ^k |A(s_k)| · 1{d̂_k ≠ d*_k} ]，其中 |A| ≤ ε_H + ε_C。

ε_H 和 ε_C 由确定性重放加反事实回放测量（`experiments/stopping_replay.py`）。
