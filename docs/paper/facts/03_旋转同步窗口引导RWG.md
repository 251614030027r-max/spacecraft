# 03 旋转同步窗口引导（RWG）

RWG 是面向快速翻滚目标的执行链，处理场景问题：端口周期性扫过、可进入的时间窗口是动态的。它包括三部分：

1. 把二维意图变成跟着扫掠锥走的三维运动；
2. 在端口经过时判定并规划入口；
3. 入口执行受阻时，在原到达时刻附近重定时。

## 3.1 自旋坐标系与扫掠几何

在恒速预报下，端口方向绕自旋轴 ŝ 匀速转动，扫出一个半角为 β 的圆锥，称为扫掠锥。在当前相对位置 q（距离 r）处定义局部正交基：

- **e_r：** 视线方向 q/r；
- **e_pol：** ŝ 在垂直于视线平面内的投影方向，即指向自旋轴的方向；
- **e_az：** 与端口扫过视线的方向相反，即迎着端口转来的方向。

**几何量：**

- 视线极角 λ = ∠(e_r, ŝ)；
- 端口锥半角 β = ∠(端口方向, ŝ)；
- 纬向偏差 Δλ = λ − β；
- 相位 φ ∈ [0, 2π)：端口在绕 ŝ 转动中，还要转多少才到达视线所在的子午面；
- 下一次经过时刻 φ/ω。

**端口–视线夹角**（球面余弦定理）：τ 秒后，端口与视线的夹角满足

  cos θ(τ) = cos λ cos β + sin λ sin β cos(φ − ωτ)，

相位差取到 [−π, π]。在 τ = φ/ω（经过时刻）取最小值 θ_min = |Δλ|。

**命题（扫掠窗口）：** 给定入口夹角门限 θ_g = 35°，在 sin λ sin β > 0 时令

  c* = (cos θ_g − cos λ cos β)/(sin λ sin β)。

- **c* > 1：** 无窗口，等价于 |Δλ| > θ_g；
- **c* ≤ −1：** 整圈都在门限内；
- **其余情形：** θ(τ) ≤ θ_g 当且仅当 |φ − ωτ| ≤ Δφ，其中窗口相位半宽 Δφ = arccos c*，持续时间 2Δφ/ω；
- **Δλ → 0 时：** 半宽最大。β ≈ 90° 时 Δφ ≈ θ_g，即一次经过约 26–33 s（ω = 2.7–2.1 °/s）。
- **sin λ sin β = 0：** 视线或端口与自旋轴共线，夹角与相位无关。

**几何机会集：** 入口只在离散到达时刻 𝒯 = {15, 20, 25, 30, 40, 50, 60} s 上尝试，所以名义几何机会集为

  𝒲_geo = {(Δλ, φ) : ∃τ ∈ 𝒯, |φ − ωτ| ≤ Δφ}。

它只是"几何上可进入"。实际可执行的入口还要满足第 3.4 节的距离、速度条件，以及入口规划的可行性，所以实际可执行入口集是 𝒲_geo 的子集。在一个典型目标状态下的扫描结果：

- 几何窗口约占 (Δλ, φ) 平面的 23%；
- 入口规划真正可行的区域只在 |Δλ| ≤ 30° 内，距离 8 / 10 / 12 m 时约占 17% / 14% / 13%。

**错过一次窗口的代价：** 下一次经过约在一个自旋周期 P = 2π/ω ≈ 133–171 s 之后，已接近或超过紧急任务的全部期限（140–200 s，还要扣 45 s 末段余量）。

## 3.2 二维意图 → 三维阶段目标速度

阶段末的目标速度为

  v* = −v_c e_r + v_l e_pol + v_z e_az，

其中各分量为：

- **接近速度：** v_c = 0.05 + 0.15 a_p ∈ [−0.10, 0.20] m/s，由学习决定；
- **沿扫掠速度：** v_z = 0.15 a_z ∈ [−0.15, 0.15] m/s，由学习决定；
- **纬向速度：** v_l = clip(k_λ r Δλ, ±0.12 m/s)，k_λ = 0.02 s⁻¹。这是固定的几何调节律，不是学习动作。

**局部运动学**（已数值核对）：

- 距离：ṙ ≈ −v_c；
- 纬向：Δλ̇ = −v_l/r，未饱和时 Δλ̇ = −k_λ Δλ。以 50 s 时间常数把视线拉到扫掠锥上，从而增大窗口半宽 Δφ；
- 相位：φ̇ = −‖ω‖ − v_z/(r sin λ)：
  - v_z > 0（沿 e_az，迎击）：端口更早经过；r = 10 m 时一个阶段多转约 14°；
  - v_z < 0（伴飞）：经过推迟，对准时间拉长；
  - v_z = 0（等待）：一个阶段内端口自然扫过 ωh ≈ 34–43°。
  - r ≈ 10 m 时，沿扫掠速度可把经过时刻提前或推迟约 ±35%。

**两个学习自由度的分工：** a_p 管接近节奏，a_z 管与旋转端口的相遇时机。迎击、伴飞、等待是同一个连续动作的不同取值，没有人为划分的离散类别。该用哪一种，取决于剩余时间、任务类型和燃料，这正是交给策略学习的状态相关决策。

## 3.3 阶段目标：限幅与安全投影

给定当前相对惯性状态 (q, v) 与 v*：

1. **阶段权限限幅：** 速度变化 v* − v 的模长限制在 2d/h 以内。其中 d = 0.7 × (1.6 N / m) × h²/2 ≈ 1.35 m，h = 16 s，即 16 s 内约 0.17 m/s。超出时按比例缩放到边界上，得到 v_goal。
2. **阶段末位置：** q_goal = q + h (v + v_goal)/2。
3. **安全投影：** 只减小向内的径向分量，做两遍：
   - 阶段末距离不小于 6.8 m（操作球 6 m + 口部带 0.5 m + 0.3 m）。操作球只由入口转移和末段下降进入；
   - 阶段末的径向接近速度不超过该距离处制动包络减 0.02 m/s。
4. **规划与执行：** 阶段规划器（第 04 节）以 (q_goal, v_goal) 为软目标，规划 16 s 轨迹，由执行链跟踪。

**参数依据：**

- **阶段时长 16 s：** 一次经过约 26–33 s，16 s 内端口扫过 34–43°，约半个窗口，所以经过前有 2–4 次决策机会。同时 16 s 恒速预报误差约 1°，而 30 s、60 s 时分别约 3°、9°。阶段再长，预报误差增大，且一个阶段就跨过整个窗口；再短，阶段内可改变的速度（∝ h²）太小。
- **纬向律时间常数 50 s：** 约 3 个阶段把纬向偏差减半以上。
- **阶段权限只用 70% 规划推力：** 给跟踪留出余量。

## 3.4 动态入口（入口判定）

阶段飞行或保持时，每 2 s 检查一次。依次要求：

1. 距离 ≤ 12 m；
2. 径向制动裕度 ≥ 0.02 m/s；
3. 对 𝒯 中每个到达时刻 τ（从小到大）：若恒速预报下 τ 秒后端口–视线夹角 ≤ 35°，且到达不晚于 L = T_d − 45 s，就调用入口规划器（第 04 节）。第一个可行的 τ 即开启入口转移。

**门限的性质：** 12 m、35°、0.02 m/s 是执行层的预筛门限，不是安全边界；安全仍由真值约束判定。入口规划真正可行的区域约在 20° 以内，35° 是可行区的外包络。

## 3.5 入口重定时

入口转移中，跟踪偏离 > 1 m 时，入口规划器按剩余时间对原到达时刻 τ₀ 重规划。若失败，依次尝试：

1. τ₀ + s，s ∈ {2, 4, 8} s，用规划力界 F₀（每轴力界的 80%）；
2. τ₀ + s，s ∈ {0, 2, 4, 8} s，用备用力界 F₁（95%）。

所有候选都要求到达不晚于 L，第一个可行者被采用。都不可行时，入口丢失，转为保持并回到高层决策。

**性质（可行候选不减）：** 同一状态与判据下，固定到达时刻的候选集是扩展候选集的子集，而且扩展机制先按原时刻尝试，所以"存在可行入口计划"在扩展下不会变弱。同一 τ 下，放宽力界只会扩大可行集（凸规划约束放宽）。

**准确含义：**

- 实现不显式检查相位窗口，被采用的候选由入口规划器按端口在该到达时刻的位姿核验；
- 最大重定时 8 s 内，端口扫过 ω·8 ≤ 21.6°，小于 Δλ ≈ 0 时的窗口全宽（约 70°）；
- 只有原到达时刻离窗口边缘的相位余量 ≥ ω·s 时，才能断言重定时后仍在同一次经过内。论文写"在原到达时刻附近、面向窗口的重规划"即可；
- 这条性质不蕴含捕获率单调提高，后者由实验检验。

**为什么重定时比放弃这次窗口划算：** 放弃意味着等待约一个自旋周期；重定时最多多花 8 s。开发期配对测试（固定策略，同一批初始条件）中，重定时使入口丢失从 110 次降到 3 次，捕获从 92 增至 96。这是开发期数据，正式实验另行检验。

## 3.6 w/o 旋转引导消融中被拿掉的内容

在ECC w/o 旋转引导中：

- 阶段目标速度只沿视线接近，v* = −v_c e_r；
- 没有纬向调节律，沿扫掠分量 a_z 不起作用；
- 入口判定、入口规划、重定时、认证都照常。

所以这个消融去掉的是"利用扫掠锥几何构造阶段意图"，不是只去掉某一个相位公式。
