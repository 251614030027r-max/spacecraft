# 07 对比方法：各自改动了什么（第二轮）

所有学习方法共用：
- 同一执行层（RWG、规划器、MPC）；
- 同一观测 o（17 项，策略与评价器共用）、同一动作空间；
- 同一网络、奖励（机会可达性势函数）与训练设置，只用限时捕获任务；
- 从零训练，6000 次决策 × 3 个种子。

各组只在下表列出的地方不同（用户 2026-11-19 确定的分组；正式阶段的种子与初始条件在正式实验设计中登记）。

| 方法 | 保持 | 关键窗口修正 | 直接入口（远场） | 学习算法 | 训练 |
|---|---|---|---|---|---|
| **ECC（本文）** | 是 | 是 | 是 | SAC | 从零 |
| 无反馈：SAC–MPC | — | — | — | SAC | 从零 |
| 无核心：ECC w/o critical-window correction | 是 | 否 | 是 | SAC | 从零 |
| 无副机制：ECC w/o long-range entry | 是 | 是 | 否 | — | 不训练：最终 ECC 模型在评估时关闭直接入口 |
| TD3–MPC | — | — | — | TD3 | 从零 |
| MPC | 只用冻结 MPC，没有阶段层与入口规划 | | | — | 非学习 |

- **主对比：** ECC 对 SAC–MPC（无反馈，即没有机会协调）、TD3–MPC、MPC。
- **附加归因：**
  - 无核心：去掉关键窗口修正，只保留"保持 + 直接入口"（原意图接不上、且处于末次可用经过时启动直接入口）；
  - 无副机制：只在评估时关闭直接入口，不单独训练，论文需注明这一点。
- **RWG：** 用开发期证据（旋转引导 35/48 对 21/48；入口重定时）说明，第二轮不重跑旋转引导消融。
