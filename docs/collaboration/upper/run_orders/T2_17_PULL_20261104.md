## 本轮做什么

**方法（执行反馈通道的动作级部分）：** critic 与 `e_priv` 完全相同（训练期读执行器判断，只用真实转移）。执行器对 8 个候选意图与策略自身意图作同一处理的预测，与 critic 的优势按逆方差融合，只修正策略这一步的方向，步长取 critic 自己的；没有证据时更新就是 `e_priv` 的。
- **局部形式：** 策略意图附近（半径 0.75）融合优势的斜率，转动 critic 的步（6.2）；
