# 01 问题描述与系统建模

## 1.1 场景

- **任务：** 追踪航天器对一颗自由翻滚、无合作标志的目标做预捕获，即在给定期限和燃料预算内，从十几米外进入目标端口前方的捕获位姿并保持住。
- **过程：** 目标绕近似固定的轴快速自旋，对接端口随之在空间中周期性扫过。追踪器只有在端口转到合适方位时，才能沿端口轴线安全进入近场，所以可用的进入机会是一段一段的时间窗口。
- **成败判定：** 由真值几何判定，包括碰撞、走廊、视场、速度包络和捕获条件。

## 1.2 坐标系与状态

- **惯性系：** 地心惯性系（ECI）。目标在 500 km 圆轨道、45° 倾角上运行。
- **本体系：** 目标与追踪器各自的本体系。目标本体系中，端口位于 p_port = (−1.5, 0, 0) m，端口轴（接近方向）n_p = (−1, 0, 0)，捕获点（预捕获位姿的位置）p_cap = (−3.0, 0, 0) m。
- **相对状态：** 追踪器相对目标的位姿与速度，用 SE(3) 的指数坐标描述：12 维，即相对旋转向量、相对位置、相对角速度、相对速度。
- **姿态参数化：** 两航天器都用旋转矩阵 R ∈ SO(3)，角速度在本体系表示。

## 1.3 动力学（真值）

- **刚体动力学：** 两颗航天器都按六自由度刚体在 ECI 中积分：
  - 平动：中心引力 + J2 摄动 + 有限尺寸引起的二阶质量矩修正；
  - 转动：欧拉方程 + 重力梯度力矩。
- **数值积分：** RK45 自适应，相对容差 1e-7、绝对容差 1e-9，最大步长 0.1 s。
- **控制输入：** 推力与力矩在本体系，按 0.1 s 零阶保持。无其他外部扰动。
- **目标：** 225 kg 均质长方体，主惯量 diag(30, 39, 48) kg·m²，半尺寸约 0.62 × 0.51 × 0.37 m；本体系中有一根从箱体到端口的抓取杆（半径 0.05 m）。自由翻滚，角速度大小 2.1–2.7 °/s，自旋轴与本体 z 轴相差 10–20°（方位随机）。
- **追踪器：** 106 kg，惯量约 diag(20.3, 19.9, 23.7) kg·m²（含小的交叉项）。每轴推力 ±2 N、每轴力矩 ±0.6 N·m。相机视轴为本体 +x 方向。
- **信息假设：**
  - 目标真实惯量未知，执行层用各向同性惯量估计（真实惯量的迹 / 3），即按"当前姿态 + 当前角速度恒定"外推目标姿态；
  - 决策和规划用的目标姿态预报都是这种恒速预报，只有真值积分用真实惯量；
  - 相对状态按完全可测处理，没有感知噪声模型。
- **燃料：** 用 Δv 计量，每个控制周期累加 ‖F‖ Δt / m（推力 2-范数）。

## 1.4 初始条件

- **目标：** 姿态在 SO(3) 上均匀随机，自旋如上。
- **追踪器位置：** 在目标 LVLH 系中方向均匀随机，距离 12–16 m。
- **追踪器速度：** 相对惯性速度大小 ≤ 0.05 m/s，方向随机。
- **追踪器姿态：** 相机视轴大致对准端口，偏差 ≤ 15°，滚转随机；角速度每轴 ≤ 0.005 rad/s。
- 每个初始条件由一个整数编号确定（可复现），训练、开发和正式测试使用互不重叠的编号段。

## 1.5 安全约束（真值判定，每 0.1 s）

距离、速度都在目标本体系或其惯性对应量上计算。

| 约束 | 适用区域 | 定义 |
|---|---|---|
| 碰撞 | 全程 | 追踪器包络球（半径 0.95 m）与目标箱体及抓取杆的间隙 ≥ 0 |
| 操作球 / 走廊 | 全程 | 在操作球（半径 6 m）之外，或在端口锥内：沿端口轴距端口 ≥ 1 m，且横向距离 ≤ 轴向距离 × tan 35° |
| 相机视场 | 全程 | 视轴与指向端口的视线夹角 ≤ 50° |
| 径向制动包络 | 口部区域之外 | 径向接近速度 ≤ v_b(r − 6 m) |
| 总速度 | 口部区域内 | 相对速度 ≤ 0.35 m/s |
| 轴向制动包络 | 口部区域内 | 沿端口轴的接近速度 ≤ v_b(到捕获点的轴向剩余距离) |
| 最大距离 | 全程 | 距离 ≤ 30 m |

- **口部区域：** 已在端口锥内且距离 < 6.5 m（操作球 + 0.5 m 口部带），从这里开始按锥内规则判定。
- **制动包络：** v_b(d) 是 √(v_f² + 2 a_b d) 的分段线性内近似（节点 0、0.25、0.5、1、2、4、8、16、32 m），其中 v_f = 0.05 m/s，a_b = 0.5 × 2 N / 106 kg ≈ 0.0094 m/s²。每段取弦，所以不比恒减速包络宽松。
- 违反任一项即"不安全"终止。推力、力矩限幅是执行器饱和，不算违反。

## 1.6 捕获条件

- **条件：** 处于端口锥内，且同时满足：
  - 位置误差 ≤ 0.25 m；
  - 姿态误差 ≤ 10°；
  - 相对速度 ≤ 0.05 m/s；
  - 相对角速度误差 ≤ 0.02 rad/s。
- **成功：** 以上条件连续保持 1 s 即捕获成功。

## 1.7 任务（期限、预算与偏好）

每个初始条件对应一个任务类型。

| 类型 | 期限 T_d | 燃料预算 B_max | 时间代价 c_t | 燃料代价 c_f |
|---|---|---|---|---|
| 紧急 | U(140, 200) s | 3.0 m/s | 0.10 /s | 10 /(m/s) |
| 经济 | U(280, 340) s | 2.0 m/s | 0.02 /s | 40 /(m/s) |

- **类型与期限的抽取：** 按初始条件编号确定性地随机抽取。强制某一类型时，期限仍按该编号原本的随机流抽取，所以同一编号在不同条件下的期限可以配对比较。
- **训练分布：** 紧急 3/4、经济 1/4。
- **燃料耗尽：** 已用 Δv 达到 B_max，即燃料耗尽，每 2 s 检查一次。
- **经济预算的来源：** 2.0 m/s 来自一次只用非学习策略的预筛：在这个预算下，燃料约束真实起作用（五个固定策略约 24% 的回合碰到约束），同时问题仍可解（逐个初始条件取最好的固定策略，可全部捕获）。

## 1.8 回报与终止

- **真实回报：** r = −c_t Δt − c_f Δv（每 0.1 s 累加）加终局项：捕获 +100，超时 −100，燃料耗尽 −100，不安全 −150。
- **终止：** 捕获、不安全、超时、燃料耗尽都是终止事件，不再自举。只有数值积分失败算截断，按未捕获统计，正式实验中未见。

## 1.9 优化问题的表述（供"问题描述"一节）

- **目标：** 在上述真值动力学与约束下，求一个以观测为输入的控制策略，使真实回报的期望最大。等价地说，在期限和燃料预算内尽可能捕获，并在捕获的前提下少用时间（紧急）或少用燃料（经济）。
- **难点：** 端口窗口随时间周期性出现，错过一次要等将近一个自旋周期（133–171 s），已接近或超过紧急任务的全部期限；而且燃料和时间同时受限。
